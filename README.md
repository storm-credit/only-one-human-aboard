# only-one-human-aboard

장편 SF 웹소설/IP 《우주선에는 인간이 한 명뿐이다》 Deep Design 저장소.

## 현재 단계

`DEEP DESIGN / NOT READY TO WRITE`

프롤로그·1화·샘플 장면·긴 대사·원고 집필은 `DESIGN FREEZE → CANON FREEZE → WRITING READY`를 모두 통과하기 전까지 금지한다.

## 핵심 콘셉트

세대우주선에는 약 30만 명이 살고 있다. 모두 자신을 인간이라 믿지만, 현재 우주선에 존재하는 생물학적 인간은 단 한 명뿐이다. 주인공 역시 자신이 그 한 명이라는 증거가 없다.

이 작품의 장편화 핵심은 ‘마지막 인간 찾기’를 오래 끄는 것이 아니라, 인간 여부를 확신할 수 없는 사회에서 가족·죽음·복원·신체·출생·법·정치·목적지를 둘러싼 사건들이 독립적으로 계속 발생하도록 만드는 것이다.

## 설계 우선순위

1. 실제 재미
2. 캐릭터와 관계
3. 반복 가능한 Story Engine
4. 100~200화 중반 지속력
5. Living World
6. 복선/회수
7. SF 논리
8. 결말 만족도
9. Anti-AI 자연스러움
10. 설정의 양

## 현재 작업 순서

`B Story Engine → C-lite Truth Architecture → D Living World → World Logic → C-full Narrative Architecture → A Canon Bible → Red Team → Stress Test → Freeze`

## 현재 핵심 성공조건

- 메인 미스터리를 제거해도 40개 이상의 사건이 만들어질 것
- 최소 4개의 독립 Story Engine이 작동할 것
- 20화의 Reader Promise가 100화·200화에도 유지될 것
- ‘병원 검사 한 번이면 유일한 인간을 찾을 수 있지 않나?’를 포함한 P0 논리구멍이 없을 것
- 모든 주요 세력과 인물이 주인공 없이도 움직일 것
- 100~200화가 비밀 미루기·회의·새 악역 추가만으로 유지되지 않을 것

현재 Canon은 아직 Freeze되지 않았다.
