# Prose Style — 4 Designs v0.1

Status: `EXECUTION STYLE DESIGN / NO SAMPLE SCENE`

Project:
《우주선에는 인간이 한 명뿐이다》

Purpose:
Story/Canon/POV가 잠긴 뒤 실제 문장이 어떤 속도·거리·밀도로 읽혀야 하는지 정한다.

No sample fiction prose is written here.

Hard inherited constraints:
- close-third single POV per episode
- one primary series anchor inside ensemble
- anti-AI naturalism
- no philosophy-lecture drift
- social/family/physical consequence before abstract explanation
- Korean webserial readability

---

# STYLE A — Fast Commercial Webserial

## Core
짧은 문장/문단, 높은 대화량, 빠른 정보전달, 매 화 강한 후킹.

## Execution Tendencies
- sentence center: short~medium
- paragraph: short
- dialogue: high
- scene transition: fast
- internal reflection: brief
- end hooks: sharp

## Strengths
- 초반 진입장벽 낮음
- 모바일 가독성 강함
- 법/기술 소재를 빠르게 넘길 수 있음
- 연재 리듬 명확

## Weaknesses
- 14년 관계변화가 얕아질 수 있음
- 모든 인물 말투가 비슷한 `효율적인 웹소설 대사`로 수렴
- Count/PR-H1 같은 복합 감정이 즉시 정답화될 위험
- 조용한 비용/생활감을 `전개 없는 구간`으로 취급할 위험
- 강한 훅을 반복하면 notification/cliffhanger 기계성 증가

## Verdict
`USE SPEED ELEMENTS ONLY`

---

# STYLE B — Contemplative Literary Social SF

## Core
세밀한 내면·장소·기억·사회적 의미를 길게 축적하는 절제된 문학 SF.

## Tendencies
- sentence: medium~long
- paragraph: medium~long
- dialogue: lower
- images/motifs: recurring
- internal ambiguity: high
- scene endings: often quiet

## Strengths
- 정체성/복원/가족의 미묘함에 강함
- 메리디언을 실제 고향처럼 느끼게 만들기 좋음
- PR-H1과 도착 이후의 상실을 깊게 만들 수 있음

## Weaknesses
- 웹연재 230화에서 초반 동력 약화 가능
- 작품이 사용자가 피하고 싶은 심오·형이상학 후반으로 미끄러질 수 있음
- 역사/법/정체성 문단이 에세이처럼 길어질 위험
- 정보량이 많은 Act5에서 독해부담 증가

## Verdict
`REJECT AS BASE`

Use:
selected quiet relationship/payoff moments only.

---

# STYLE C — Procedural / Institutional Drama

## Core
사건·증거·규칙·결정과 그 후폭풍을 매우 명료하게 보여주는 절차극 스타일.

## Tendencies
- precise observation
- scene objective very clear
- dialogue functional
- technical nouns concrete
- cause/effect foregrounded
- low decorative prose

## Strengths
- Continuity 심사관 직업과 잘 맞음
- SF 규칙을 행동으로 설명하기 좋음
- 복선/정보공정성 유지 쉬움
- Reader knows exactly what changed

## Weaknesses
- 사람보다 제도가 주인공이 될 위험
- 마렌/라울/토마스가 모두 똑똑한 회의실 인물로 들릴 위험
- Ella/Noah/Amara 일상이 subplot처럼 느껴질 수 있음
- Act5가 행정 시뮬레이션으로 변질될 위험

## Verdict
`USE STRUCTURAL CLARITY, NOT FULL TONE`

---

# STYLE D — Domestic / Character-Forward Drama

## Core
가족·직장·친구·생활동선의 작은 어긋남과 선택을 중심으로 SF를 간접적으로 체감시킨다.

## Tendencies
- concrete behavior before explanation
- moderate dialogue
- objects/routines carry emotion
- humor/awkwardness allowed
- SF enters through practical inconvenience

## Strengths
- P-S-N / Amara family autonomy에 매우 강함
- AI처럼 모두 철학을 토론하는 문제를 막음
- Living World가 실제 사회처럼 느껴짐
- Count 이후에도 작품이 무너지지 않음

## Weaknesses
- 제목/미스터리의 날카로움이 늦게 느껴질 수 있음
- 공학/법률 stakes가 지나치게 `생활문제`로 축소될 수 있음
- 대형 도착 클라이맥스의 규모가 작아질 위험

## Verdict
`STRONG BASE COMPONENT`

# Recommended Hybrid — STYLE-H1

Name:
# `Restrained Commercial Social SF`

Base:
**D Domestic/Character-Forward**.

Take from A:
- immediate scene pressure
- clean mobile readability
- episode-level momentum

Take from C:
- rule/consequence clarity
- precise concrete institutional/technical nouns only when needed

Take selectively from B:
- quiet emotional afterimage at major family/arrival payoffs
- place/memory texture when it changes character action

Do NOT take:
- A's constant hard cliffhanger
- B's essay-like metaphysics
- C's clean debate-machine dialogue
- D's tendency to shrink all civilization-scale stakes into household metaphor

---

# 1. Sentence Rhythm

Default:
short-to-medium Korean sentences with **meaningful length variation**.

Use longer sentence only when:
- one perception accumulates
- memory/social context bends current action
- physical process needs continuity

Use short sentence for:
- choice
- interruption
- physical realization
- emotional refusal

Do not machine-gun one-sentence paragraphs for fake intensity.

---

# 2. Paragraph Rhythm

Default mobile-friendly but cohesive.

Typical paragraph:
- 2~4 sentences when thought/action belongs together
- single-sentence paragraph reserved for actual turn/emphasis, not every beat

Avoid:
- every sentence on separate line
- giant expository blocks
- dialogue line + explanatory restatement cycles

---

# 3. Emotional Delivery

Priority:
**behavior / logistics / changed routine / object / delay / physical distance**
then explicit emotion.

Example functions, not prose:
- someone changes pickup permission instead of saying trust is broken
- someone keeps a shift instead of following a child to orbit
- someone gives up a room/block instead of delivering a speech about home

Do not make characters name their own arc accurately in real time.

---

# 4. Dialogue Texture

Dialogue should be:
- incomplete when people are defensive
- practical when stakes are immediate
- sharper only when character profession supports it
- occasionally funny/annoyed/trivial

Avoid repeated rhetorical structures:
- `그건 X가 아니야. Y야.`
- perfectly balanced three-point rebuttals
- every line serving plot/theme
- all speakers using equally clean technical vocabulary

---

# 5. Narrator Restraint

Narrator does not:
- explain the moral of a scene
- certify who is a `real human`
- summarize both sides after argument
- call an event `역사적` just because Blueprint knows it is important
- tell reader an ordinary detail is meaningful before payoff

POV attention decides what matters now.

---

# 6. SF Description

Describe technology through:
- task
- interface used
- waiting time
- maintenance
- bodily effect
- space it occupies
- what fails/changes

Avoid decorative lists of futuristic objects.

A device/system should usually enter because somebody needs it or it blocks them.

---

# 7. Institutional Scenes

Every institutional scene needs a concrete practical outcome.

Good execution functions:
- access opens/closes
- queue changes
- shift changes
- someone must move/wait
- appeal scope narrows
- status gets provisional expiration

Never let procedure exist solely to demonstrate worldbuilding sophistication.

---

# 8. Quiet Episodes

A quiet episode still changes baseline.

Allowed reward:
- trust shift
- new routine
- small personal success
- embarrassing failure
- ordinary place becoming emotionally different

Quiet ≠ filler.

No need to manufacture crisis every chapter.

---

# 9. Major Payoff Style

Count / PR-H1 / Final Approach / insertion:

Before payoff:
keep prose concrete and restrained.

At payoff:
- factual/event clarity first
- one immediate POV-specific consequence
- do not immediately unpack every philosophical implication

After payoff:
let later episodes carry interpretation.

---

# 10. Humor

Use low-key situational/character humor.

Sources:
- logistics
- work familiarity
- age difference
- wrong assumptions
- badly timed ordinary needs

Avoid Marvel-like constant quips or joke-after-trauma reflex.

---

# 11. Anti-AI Style Bans

Watch for overuse of:
- `문제는 ~였다`
- `그건 ~가 아니었다. ~였다.`
- `그리고 그 순간, 알았다`
- repeated three-item rhetorical lists in narration
- abstract noun stacks
- paragraph-ending moral aphorisms
- symmetrical debate formatting
- characters summarizing what scene just showed
- fake profound one-line endings every episode
- excessive em-dash/colon explanation cadence

None is absolutely forbidden once; **repetition is the failure**.

---

# 12. POV-Specific Narrative Texture

Keep protocol attention lenses, but sentence style also adjusts subtly.

Maren:
clean sequencing, omissions noticeable, emotion leaks through practical correction.

Ella:
more social/associative connections, sensory memory but not purple prose.

Noah:
age-dependent directness; peers/options/craft; later more professional rhythm.

Amara:
work/household scale, practical boundary, less abstract self-definition.

Raul:
audience-aware verbal agility; private narration more irreverent than public speech.

Ines:
body/time/function, less patience for conceptual fog.

Jun:
materials/repairs/people using a place, not nostalgic poetry.

Tomas:
tradeoffs/timing; bureaucratic experience without bureaucrat caricature.

---

# 13. Episode End Style

Prefer consequence image/action over narrator thesis.

Rotate:
- something is signed
- door/access closes
- schedule changes
- person leaves/stays
- work continues under changed rule
- private relationship shifts
- physical environment changes

Avoid every episode ending in:
- ominous screen message
- a character `realizing the truth`
- single-sentence philosophical maxim
