---

# 1. Core Style

Base:
**character-forward ordinary life + concrete consequence**.

Add:
- commercial webserial immediacy
- procedural clarity only when decisions require it
- selective quiet emotional depth at earned payoffs

Avoid:
- constant hard cliffhangers
- philosophical essay drift
- dry report prose
- perfect debate-machine dialogue
- shrinking every civilization-scale event into metaphor

---

# 2. Sentence Rhythm

Default:
short-to-medium Korean sentences with real variation.

Longer when:
- one perception accumulates
- memory/social context changes present action
- physical process needs continuity

Shorter when:
- choice lands
- interruption happens
- physical fact becomes unavoidable
- a person refuses/decides

Do not create fake urgency with endless short one-sentence paragraphs.

---

# 3. Paragraph Rhythm

Default mobile-friendly but cohesive.

Typical:
2~4 sentences when one action/thought belongs together.

Single-sentence paragraph:
reserve for actual turn/emphasis.

Avoid:
- every sentence isolated
- giant explanation blocks
- dialogue followed by narration restating the same conclusion

---

# 4. Emotional Delivery

Prefer:
behavior / logistics / routine / object / delay / distance
before explicit emotional labeling.

Characters should not accurately summarize their own arc while living it.

Emotional intensity is allowed.
Over-explanation is not.

---

# 5. Dialogue

Dialogue can be:
- incomplete
- adjacent to question
- practical
- annoyed
- funny at wrong-but-human moments
- professionally sharp when profession supports it

Avoid default patterns:
- thesis → perfect counterthesis → synthesis
- every person using identical technical precision
- complete self-aware speeches
- explaining facts everyone present knows

Do not force quips after trauma.

---

# 6. Narrator Restraint

Narrator does not:
- state moral of scene
- certify `real human`
- summarize both sides after debate
- label event `historical` merely because Blueprint says it matters
- announce ordinary detail as future clue
- provide hidden truth beyond POV boundary

---

# 7. SF / Institutional Description

Technology enters through:
- task
- interface
- waiting time
- maintenance
- bodily effect
- occupied space
- failure/constraint

Law enters through:
- who may act
- who must wait
- whose status/access changes
- what can be appealed/reviewed

Avoid decorative future-tech inventory and statute recital.

---

# 8. Technical Detail Cut Test

Especially Act5:

Ask:
> If half the technical explanation is cut, does the character choice/cost remain understandable?

If yes:
cut it.

If no:
keep only detail necessary to understand cause and consequence.

Never cut human cost before cutting decorative technical detail.

---

# 9. Quiet Episode Rule

Quiet does not mean filler.
A quiet episode still changes:
- trust
- routine
- role
- work
- relationship temperature
- place meaning
- future option

No mandatory crisis every chapter.

---

# 10. Payoff Style

For Count / PR-H1 / Final Approach / insertion:

1. event/fact clearly lands
2. current POV has immediate concrete consequence
3. do not unpack every implication immediately
4. later episodes perform interpretation/action

Shock is earned by causality and simplicity, not narrator hyperbole.

---

# 11. Humor

Use low-key situational/character humor from:
- logistics
- familiarity
- age difference
- wrong assumptions
- mundane needs
- workplace friction

No constant snark/quips.
No joke quota.

---

# 12. Anti-AI Pattern Watch

Watch repetition, not single occurrence:
- `문제는 ~였다`
- `그건 X가 아니었다. Y였다.`
- `그리고 그 순간 알았다`
- repeated three-item rhetorical lists
- abstract noun stacks
- paragraph-ending moral aphorisms
- symmetrical debate structure
- narrator explains what scene already showed
- fake-profound one-line ending every episode
- excessive colon/em-dash explanatory cadence
- translated-English explicit connector overload

QA question:
`Has this become the writer's automatic shortcut?`

---

# 13. Korean Naturalness

Prefer natural Korean contextual omission when unambiguous.

Avoid:
- repeating subjects/names every sentence
- English-logic connector chains
- overly nominal institutional prose

But preserve precise nouns when technical/legal distinction matters.

# 15. Meaning Cluster Rule

EP059~066:
**stop explaining once the current POV has enough information to make that episode's choice.**

Do not reconstruct a philosophy essay across eight chapters.

# 16. PR-H1 Rule

EP112~118 Ella POV run:
- vary physical action/location
- evidence changes each episode
- anger cannot be the only beat

EP117 can be emotionally intense.
Do not make it a courtroom transcript.

EP120 Maren accountability cannot become retroactive acquittal.

---

# 17. Insertion Rule

EP216 does not need disaster.
Scale comes from:
- physical/operational changes
- altered work windows
- accumulated losses becoming final
- adjacent POV relay EP207~218

Maren experiences insertion but does not explain navigation/engine math.

---

# 18. Episode Ending

Prefer consequence/action image over thesis.

Rotate:
- signed/changed status
- closed/open access
- schedule shift
- person leaves/stays
- physical condition changes
- work continues under new rule
- relationship action

Avoid repeated:
- ominous message
- `truth realization`
- aphorism
