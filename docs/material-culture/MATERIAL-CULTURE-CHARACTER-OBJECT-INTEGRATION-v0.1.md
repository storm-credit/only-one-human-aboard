# 1. Object-Salience Tiers

## M0 — Background object
No tracking. Ordinary scene texture.

## M1 — Character-recognition object
Recurring enough to help visual/social recognition.
No required plot payoff.

## M2 — Relationship/history object
Accumulates personal meaning or changes owner/use.
May receive a relationship payoff, but is not automatically mystery evidence.

## M3 — Narrative-engineering object
Only if explicitly registered in Package G Device Atlas.
Plant/payoff lifecycle tracked.

Hard rule:
**M1/M2 ≠ M3.**
Most recurring personal objects never enter the narrative-device ledger.
