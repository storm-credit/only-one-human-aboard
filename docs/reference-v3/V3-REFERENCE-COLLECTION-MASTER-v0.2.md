# 3. Selected synthesis directions

## Characters
**Grounded Morphology + Selective Shape Anchors**

Real adult face/body/age diversity is the base.
Each recurring character receives only a small number of strong posture/silhouette/material anchors.
No universal attractive-face template.

## Machines
**Interface Lineage + Role-Specific Body**

Shared standards create family resemblance.
Actual job/load/access geometry creates silhouette differences.

## Civic spaces
**Shared City Standards + Landmark Cross-Pollination**

Meridian remains one city.
Transit, leisure, medicine, domestic life and infrastructure may overlap instead of becoming game biomes.

## Destination
**Process-Synthesised Cool-Temperate Water World**

Earth references are geology/weather/process libraries, not location copies.

## Material culture
**Durable Ordinary Diversity**

Repair, replacement, reissue, personalization and mundane disposable objects all coexist.

## Collectibility
**Recognition Through Lineage + Use History**

No rarity/power ladder.
Reader pleasure comes from recognizing family, ownership and transformation over time.

# 8. Science repair discovered during reference research

Current destination atmosphere is oxygen-poor despite near-compatible total pressure.

Therefore:
- filter-only mask = rejected,
- outdoor default = supplemental breathing gas + monitoring,
- filtration is separate and only for contaminants,
- long-range/specialist work may use larger/semi-closed systems,
- verified indoor spaces have processed breathable atmosphere.
