## Mandatory same-face tests

For every final core-cast concept sheet:
1. convert to grayscale,
2. remove hair color,
3. replace clothing with neutral fitted work layer,
4. compare front neutral,
5. compare 3/4 profile,
6. compare side profile,
7. compare head-covered state,
8. compare 64px silhouette.

FAIL if:
- two faces need hair/color to distinguish,
- all women share same nose/jaw with different hairstyles,
- all men share same narrow handsome face,
- age is represented only by gray hair or wrinkles,
- ethnicity is represented as costume shorthand.

# 5. H-A / H-B difference budget

Act3 requires subtle lived-history differences, not alternate-skin designs.

Allowed high-salience delta types:
- repair/certification detail,
- callus/scar difference,
- personal carry habit,
- qualification marker,
- household object/history,
- hair maintenance difference if caused by current life.

Forbidden:
- full costume palette swap,
- radically different face/body,
- obvious alternate-universe fashion,
- matching everyone to a new faction look.

Target:
3~5 meaningful visual/material deltas across the cast before ontology clarity.

---

# 6. Reference collision test

Every new selected reference gets checked against:
- source dominance,
- existing cast silhouette,
- existing machine silhouette,
- existing zone language,
- current ontology,
- reveal timing.

If a reference is visually strong but creates a collision, reject the reference rather than weakening the existing story logic.

---

# 7. AI concept-generation guardrail

When generating original concept art later:
- do not prompt all characters with the same beauty adjectives,
- vary face geometry explicitly,
- specify age and body structure separately from clothing,
- generate neutral turnarounds before cinematic hero shots,
- test characters in same lighting/background,
- test machines in neutral orthographic/3-4 views before key art,
- do not accept a beautiful image if it breaks differentiation.
