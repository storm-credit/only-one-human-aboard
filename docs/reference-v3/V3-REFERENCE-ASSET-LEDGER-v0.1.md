# R1 Character / Human Visual Identity

## REF-C01 — Arcane / Fortiche character development
Source family:
Fortiche + Riot character-design interviews / production coverage.

Media:
Animation/game-derived IP.

Study principle:
Design teams explored multiple archetypes, body types and styles before refinement; later costume/silhouette changes can track character evolution.

BORROW:
- explore body-type range before detail,
- make silhouette changes reflect lived arc,
- allow imperfections/asymmetry.

DO NOT BORROW:
- Arcane facial rendering style,
- Piltover/Zaun color/fashion coding,
- recognizable hairstyles/costumes.

Meridian mapping:
Core-cast differentiation; Act2/6/9 clothing-state changes.

Status: SELECTED PRINCIPLE.

## REF-C02 — Spider-Verse visual-language process
Source family:
Sony Pictures Imageworks / animation production interviews.

Media:
Animated film/comic-derived.

Study principle:
Strong line/shape systems and simplified readable forms can create immediate character recognition while preserving emotion.

BORROW:
- small-scale silhouette test,
- face geometry readable before costume,
- intentional line/shape rules per character.

DO NOT BORROW:
- comic halftone/render language,
- superhero proportions,
- exaggerated hero pose grammar.

Meridian mapping:
Grayscale and same-clothes character collision tests.

Status: SELECTED PRINCIPLE.

## REF-C03 — Andor / Ferrix costume logic
Source family:
StarWars.com interviews with costume designer Michael Wilkinson.

Media:
Live-action TV.

Study principle:
Costume difference should come from job, age, ownership history and individual life rather than giving a whole district one uniform.

BORROW:
- job-derived wear,
- individualized workwear,
- backstory embedded in fabric condition,
- reused/old clothing that belongs to a life.

DO NOT BORROW:
- Star Wars silhouettes,
- Ferrix-specific jackets/headwear,
- franchise color palette.

Meridian mapping:
Old Works/Midring workers; civilian variation; Act6 wear.

Status: SELECTED PRINCIPLE.

## REF-C04 — Planetes ordinary space workers

BORROW:

DO NOT BORROW:
