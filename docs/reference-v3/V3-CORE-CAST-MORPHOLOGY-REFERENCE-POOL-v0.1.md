# V3 CORE CAST MORPHOLOGY REFERENCE POOL v0.1

Status: `CHARACTER REFERENCE SYNTHESIS / NOT CANON / NO PROSE`
Date: 2026-08-20
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
Prevent same-face convergence without assigning one actor/celebrity/game character as the template for any Meridian character.

Reference philosophy:
- real occupational/documentary images provide age/body/asymmetry reality,
- animation/game references provide silhouette/shape readability only,
- final face is synthesized from parameters, not copied from an identifiable person.

Primary real-reference families used as morphology pools:
- NIOSH age-diverse worker photography and productive-aging materials,
- NIOSH mining/industrial worker images showing different ages, work postures and body wear,
- hospital/rehabilitation public galleries for clinicians/patients/family posture diversity,
- transit/community public-space imagery for ordinary civilian body variety.

Stylisation/process support:
- Fortiche/Arcane morphology/asymmetry exploration,
- Spider-Verse small-scale silhouette readability.

Hard:
No final character may be described internally as `Actor X + Character Y`.

---

# Morphology dimensions

Each core character is fixed across these axes before face art:
1. face length ratio,
2. face width / jaw width,
3. cheek projection,
4. nose bridge/mass/profile,
5. eye spacing / lid shape,
6. brow weight/angle,
7. mouth width/lip mass,
8. ear visibility/shape tendency,
9. age texture distribution,
10. neck/shoulder relation,
11. torso/limb mass distribution,
12. habitual posture,
13. one subtle asymmetry,
14. one explicit collision to avoid.

Color/pigmentation is intentionally NOT the primary distinction axis.

# Attractiveness distribution rule

Do not rate characters on one beauty scale.
The cast should include:
- conventionally attractive people,
- ordinary average-looking adults,
- distinctive/asymmetric faces,
- visible aging,
- softer bodies,
- wear/fatigue,
without using appearance as morality coding.

No villain uglification.
No protagonist automatic prettification.
