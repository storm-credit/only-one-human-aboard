# SA-6A

## Baseline Change
`정착파 vs 잔류파` 두 진영으로는 가족과 사회를 설명할 수 없게 된다.

## Device Work
- `CT-03` payoff — Amara가 가족을 한 구성으로 유지하려는 욕망의 한계.
- `CT-02` adult payoff — Noah의 제3경로 패턴이 성인 자율성으로 확장.
- `WP-01` partial payoff — 여러 정착경로가 실제 life path가 됨.
- `RP-01` reinforce — 가족 continuity와 co-location을 분리.
- `RH-BINARY-01` close — settle/stay 단순 이분법 폐기.
