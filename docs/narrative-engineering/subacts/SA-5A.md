# SA-5A

## Baseline Change
목적지는 정치 슬로건이 아니라 계약·근무·주거·예산 문제로 바뀐다.

## Device Work
- `TK-01` trigger — arrival clock이 구체적 사회압력이 된다.
- `CK-01` trigger — reserve/spare systems가 allocation 대상이 됨.
- `PR-02` reinforce — commons constraint가 전략자산으로 확대.
- `WP-01` reinforce — 미래경로가 career/budget 선택으로 전환.
- `MR-02` reinforce — 현재 home과 미래 infrastructure의 충돌.
