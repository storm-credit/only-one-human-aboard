# SA-5D

## Baseline Change
문명은 이미 `도착 후를 준비하는 상태`로 넘어가 되돌아갈 수 없게 된다.

## Device Work
- `CK-01` major payoff — 물리적 transfer/reserve drawdown.
- `WP-ASSET-01` major payoff — 현재 redundancy가 실제 감소.
- `TK-01` reinforce — deadline이 비가역 선택을 만든다.
- `MR-02` turn payoff — ship/home 일부는 그대로 보존 불가.
- `WP-01` reinforce — 미래경로에 물리적 비용이 붙는다.
