# SA-6C

## Baseline Change
Maren의 초기 욕망 `가족을 안정시킨다`가 `가족의 선택을 통제하지 않는다`로 이동한다.

## Device Work
- `RP-01` major payoff — old-state restoration 없는 가족지속.
- `CT-01` partial payoff — Maren이 타인의 선택을 소유하지 않음.
- `CT-02` payoff — Noah는 보호대상이 아니라 성인행위자.
- `TK-01` reinforce — final allocation/insertion deadline 접근.
- `MR-01` reinforce — 개인 continuity 문제가 최종 civic mirror를 준비.
