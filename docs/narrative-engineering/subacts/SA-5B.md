# SA-5B

## Baseline Change
ship preservation vs settlement가 두 버튼이 아니라 자산별 연속적 선택으로 보이기 시작한다.

## Device Work
- `CK-01` partial payoff — pumps/radiators/precision lines가 future capital로 지정.
- `WP-ASSET-01` payoff — 자산의 가치는 질량보다 기능·정밀도·redundancy.
- `CT-03` reinforce — Amara는 여러 실무자 중 한 명으로 reliability/현장영향을 말한다.
- `MR-02` reinforce — infrastructure 결정이 livelihood/place 결정과 연결.
