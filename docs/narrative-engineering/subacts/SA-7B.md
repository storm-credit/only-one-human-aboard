# SA-7B

## Baseline Change
미래가 논쟁이 아니라 실제 이동·건설·잔류로 갈라진다.

## Device Work
- `WP-01` major payoff — ship/orbit/surface/new-habitat paths physically begin.
- `CK-01` aftershock — 옮긴 산업자산이 foothold를 가능하게 하고 ship redundancy는 낮아짐.
- `TK-01` payoff — EP216-region system insertion.
- `MR-02` major payoff — home이 복수의 실제 장소가 된다.
- `RP-01` reinforce — 가족선택이 이동/부재로 물리화.
