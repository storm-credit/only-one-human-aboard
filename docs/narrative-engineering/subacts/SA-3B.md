# SA-3B

## Baseline Change
옛 분류가 추상이 아니라 Amara의 평범한 가족생활을 직접 압박한다.

## Device Work
- `OL-IDENTITY-01` payoff — protected confirmation.
- `RI-01` plant/trigger/payoff — public traces + privacy-protected provenance + false candidates.
- `RH-03` soft plant — status=authority라는 사회적 오해의 씨앗.
- `CT-03` reinforce — Amara의 family-boundary instinct.
- `WP-01` reinforce — 배우자/자녀는 이미 독립 목표가 있다.
