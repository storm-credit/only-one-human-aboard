Relationship: ontology-safe replacement candidate for v0.2 where noted.

Lifecycle: `PLANT → REINFORCE → TRIGGER → PAYOFF → AFTERSHOCK`

---

# 0. New device hard rules

1. No clue proves cosmological parallel universes.
2. No clue makes cross-history memory normal.
3. No one archive/query reveals the complete civilization field.
4. HUMAN:1 remains invariant but does not explain all anomalies.
5. Physical substrate clues must arrive late enough not to destroy the human-scale illusion.
6. A related person in another lineage is not a resurrection of the dead person here.
7. The final payoff is civic/ethical irreversibility, not simply a computer shutdown.

# 17. Density guardrail

The vast ontology must NOT increase clue frequency.

Paradoxical rule:
**The bigger the hidden system becomes, the rarer direct evidence should feel.**

Why:
- isolation is designed to work,
- most citizens must live coherent lives,
- direct leakage is failure,
- mystery depends on tiny cracks revealing enormous scale.

Therefore use a few high-quality cracks, not constant anomalies.
