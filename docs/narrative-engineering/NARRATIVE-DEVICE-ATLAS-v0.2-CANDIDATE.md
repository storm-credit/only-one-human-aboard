# 0. V3 Device Rules

1. MacGuffin moves people; it is not the universal truth key.
2. Red herring is a reasonable reading of true evidence, never narrator fraud.
3. Every major survival incident must do at least two jobs: survival + character/mystery/world payoff.
4. Ordinary detail must greatly outnumber tracked clues.
5. Information payoff must change action, relationship, access, risk or resource.
6. Same clue may change meaning across states; all meanings stay on the author ledger.
7. Final ~15% shifts strongly from Plant to Payoff.
8. No late `actually everything was X` twist may invalidate lived stakes.

# 1. Primary Long-Range MacGuffins

## MG3-01 — HUMAN:1 Record
Type: `title MacGuffin + hard-clue chain + delayed identification mystery`

Plant:
- faint legacy fields in ordinary records.
- `HUMAN` appears in technical contexts inconsistent with modern civic speech.

Reinforce:
- the value remains `1` across incompatible historical records.

Trigger:
- Act 5: hard evidence that `HUMAN:1` is not a typo.

Payoff ladder:
1. the count is real.
2. Rowan is not that one.
3. HUMAN is a legacy natural-origin continuity class.
4. the one is a preserved person who has not yet lived a social life.

Aftershock:
classification cannot settle moral personhood.

Guardrail:
no admin key, throne, ownership, chosen-one authority or universal causation.

# 2. Hard Clues

## HC3-01 — Non-matching Death Registry
A living person's name appears in an authentic memorial/death record.

Fair alternatives:
namesake / corruption / forgery / witness error / propaganda.

Final value:
proof of another lived history, not mechanism.

## HC3-02 — Impossible Maintenance Wear
A component has repair wear for an incident official history denies.

Purpose:
lets Rowan discover ontology through his job.

## HC3-03 — Divergent Personal Object
A pet collar, repaired tool, engraving, family object or scar photo differs in a way ordinary butterfly effect cannot explain.

## HC3-04 — Cross-State Identity Collision
Legacy queries return fragments tied to one person but incompatible lives.

Guardrail:
fragmentary, permission-limited, collision-prone.

## HC3-05 — HUMAN Count Stability
`HUMAN:1` persists across materially different historical configurations.

# 9. Horror / Divination / Ecology Integration

Ghost-like residue: low-frequency cross-arc soft clue.

Zombie-like outbreak: 0–1 major arc maximum; biological/control/continuity cause only.

Divination: mostly culture; rare residue/side-channel overlap.

Companion ecology: attachment, sensory warning, memory triggers, state contrast; never universal detector.

Paleo culture: recurring place/world attachment, not genre takeover.

# 10. Payoff Density Rules

For each tracked device record:
- ID
- plant window
- ordinary surface function
- first interpretation
- alternate interpretation
- trigger
- local payoff
- final recontextualization
- aftershock
- state

No tracked device remains OPEN for >120 episodes without reinforcement, deliberate dormancy, or abandonment note.

Every 25~35 episode block should contain at least:
- one local mystery payoff,
- one relationship payoff,
- one survival/world consequence.

Final 60 episodes:
- at most 2 new high-salience mystery devices, preferably zero.
- payoff/recontextualization dominates.
