## 0. Purpose

This document defines the exact scope of the project's **reader-recognition / completion-desire / guidebook-IP asset layer**.

It does **not** create a protagonist inventory system and does **not** convert the novel into a game, loot ladder, or merchandise-first franchise.

Core distinction:
- `V3-COLLECTION-COMPLETION-LEDGER-v0.1.md` H01~H16 = **narrative HIGH-memory return anchors**.
- This document = **broader visual/IP recognition roster** including characters, machines, tools, places, and in-world collecting culture.

Collection pleasure target:
> `처음 본다 → 다시 알아본다 → 같은 계열임을 안다 → 사용 흔적/세대/소유 변화가 보인다 → 일부는 완성하고 싶어진다`

No rarity/power-score progression.

# 1. Exact production budget

## Base roster
**64 base asset families**.

Breakdown:
- Character visual identities: **13**
- Machine / craft / vehicle families: **15**
- Professional / personal prop families: **12**
- Place / landmark families: **12**
- In-world collection / material-culture families: **12**

Total = **64**.

## Recognition tiers
These are **IP-production tiers**, not moral importance, combat power, or narrative truth tiers.

- `SIGNATURE` = **16**: reader should remember/recognize with little re-explanation.
- `RECURRING` = **24**: naturally reintroduced; recognition is rewarding but not required every time.
- `WORLD-DEPTH` = **24**: guidebook/artbook/world texture; prose recall is not required.

## Variant budget
Base 64 do not each receive endless variants.

Initial sanctioned variant slots: **28**.
- character lived-state variants: 8
- machine/craft lineage or crisis variants: 12
- place state/transformation variants: 4
- prop/culture provenance variants: 4

Initial complete internal design catalog target:
**64 + 28 = 92 design plates/families**.

Reserve:
up to **4 additional variants** only if Visual Execution QA proves a functional need.

Hard ceiling without a new explicit gate:
# **96**

This ceiling exists to stop collector design from swallowing the novel.

# 2. Field definitions

Each asset records:
- `Tier`: SIGNATURE / RECURRING / WORLD-DEPTH.
- `Recognition hook`: what the reader can recognize without a label.
- `Desire hook`: why a reader might want a figure/model/map/guide entry.
- `First-display target`: existing episode/window where the asset can be visually established; no plot reassignment.
- `State path`: meaningful change/lineage, if any.
- `Story status`: TRACKED / PERSISTENCE / NO-CHEKHOV / REVEAL-SENSITIVE.
- `IP surface`: figure / model / prop replica / map-art / guidebook / in-world collectible / none.

Hard:
`IP surface` never justifies the story existence of an asset.

# 11. Anti-overdesign constraints

1. Base roster is **closed at 64** until a concrete omission is proven.
2. Variant slots are **28**, hard catalog ceiling **96**.
3. A new object cannot be added because it would make good merchandise.
4. `SIGNATURE` does not mean plot clue.
5. At least half of culture/world-depth assets must remain **NO-CHEKHOV**.
6. At least 3 recurring personal possessions remain persistence-only.
7. At least 1 older machine generation is retired because a newer design is simply better for that task.
8. Act9 introduces no more than 2 brand-new HIGH-memory craft/machine families; most final assets must descend from known standards.
9. HUMAN:1 is deliberately **not** a collectible-character asset family and receives no sacred/mascot merchandise logic in design governance.
10. The novel never performs a roll-call of all 64.

A 410-episode novel can contain 64 design assets only if exposure is unequal.
