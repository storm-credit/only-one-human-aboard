Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
Convert the old collection/completion concept into a **v3 410-episode tracked return system**.

Core loop:
`Encounter → Recognition → Recontextualization → Transformation / Persistence / Loss`

Collection belongs to the **reader and the living world**, not the protagonist's inventory.

No power-loot progression.

# Memory budget

HIGH memory tracked elements:
**12~16 maximum active series-wide**.

MED memory:
**20~30**, naturally reintroduced.

LOW memory:
unlimited ordinary noise; no recall required.

Hard:
Most cups, clothes, meals, shops, tools and background machines never need payoff.

# Act-level collection balance

Act1:
**Encounter-heavy.** Establish 8~12 HIGH/MED elements naturally; ordinary noise > tracked elements.

Act2:
**Recognition under stress.** Familiar objects/places fail, save, block, or change.

Act3:
**Wrong familiarity.** Small H-B visual/material deltas; avoid collecting dozens of alternate versions.

Act4:
**Social recontextualization.** Same city/machines behave differently under rumor/prediction.

Act5:
**Provenance recontextualization.** Old materials/objects gain history meaning, but no relic hunt.

Act6:
**Transformation/loss.** Strongest visible wear, cannibalization, route changes, ownership/access changes.

Act7:
**Meaning convergence.** Interfaces/standards/objects support understanding; new object count should be low.

Act8:
**Rights over things vs people.** Resource machinery appears as constraint, never person-value metric.

Act9:
**Completion.** Known standards become settlement tools/places. More transformed returns than brand-new gadgets.
