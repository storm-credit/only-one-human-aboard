### H2 — Body / Mind
시민 대부분은 실제 인간형 생물학적 몸과 살아 있는 뇌를 가진다. 차이는 현재 몸의 재질보다 **의식이 처음 발생한 방식**.

### H3 — Birth
부모의 실제 유전정보로 배아를 만들고 보조생식 절차 중 합성 인지 시드를 사용. 아이는 실제 임신/출산/영아기/아동기를 거친다.

### H4 — Death / Backup
현재 의식은 로컬 뇌에서 실행. 실시간 완전백업은 없음. 저빈도 연속성 스캔 + 생활로그 + 조건부 사후복원.

### H6 — Population
인구 약 30만은 고정 숫자가 아니라 수용능력 Band. 신규출생과 복원은 같은 생활/자원 수용량을 두고 정치적으로 경쟁.

### H7 — One Human
세습 혈통이 아니라, 역사적 타협으로 ‘한 번에 둘 이상 자연기원 인격을 만들지 않는’ 오래된 출생 프로토콜. 현재 자연기원 인간이 사라진 뒤 다음 정상 출생 중 하나에서 인지 시드가 생략되는 방식이 1순위.
