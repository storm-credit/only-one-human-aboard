# Living World v0.2 — Three-Habitat Civilization

Status: `PROVISIONAL REFACTOR / NO CANON`

목표:
World Logic v0.2에 맞춰 v0.1의 테마파크형 구획을 폐기/재배치한다.

핵심 원칙:
> 우주선은 ‘철학별 마을 8개’가 아니라 **3개의 거대 생활대륙 + 그 사이를 잇는 무중력 교통/산업권**이다.

가족, 학교, 병원, 식당, 회사는 모든 생활권에 존재한다.
한 생활권이 하나의 철학만 대표하지 않는다.

# 1. Macro Geography Candidate

정확 수치는 아직 Canon 아님.

## Habitat A — Civic / Old Urban Cylinder
인구 후보: 약 10~12만.

### 기능
- 가장 오래된 대규모 주거도시
- 중앙 행정/법률기관 다수
- 대학/대형병원/상업
- 오래된 고밀도 주거지와 신개발 지역 공존

### 경제
서비스, 행정, 교육, 의료, 금융/보험, 문화산업.

### 생활
‘표준적인 우주선 생활’이라고 외부인이 생각하는 이미지가 여기서 만들어짐.
하지만 내부에는:
- 부유한 중심부
- 오래된 노동주거지
- 이민/이주민 지역
- 학생가
가 모두 있음.

### 중요 District Candidate
**Old Quarter / 구도심**
수백 년 된 초기 도시조직 일부.
현재 노후시설/안전문제로 단계적 폐쇄 논쟁.

기존 ‘구환’은 독립 생활환이 아니라 **Habitat A 내부의 오래된 거대 구역**으로 축소.

### Story Engine
- 주인공 직장
- R의 법률활동
- M의 기관정치
- S/N 가족생활
- Old Quarter 폐쇄

---

## Habitat B — Green / Watershed Cylinder
인구 후보: 약 9~10만.

### 기능
- 대형 농업/산림형 생태구역
- 물순환/바이오매스 관리
- 주거도시도 충분히 존재

농장만 끝없이 펼쳐진 곳이 아님.
도시와 농업, 수로, 공원, 처리시설이 섞인 생활권.

### 경제
식량, 수자원, 생물자원, 환경관리, 의료용 생물소재.

### 문화적 경향 후보
- 장기 생태순환을 일상적으로 봄
- 물질 재활용/사망 이후 신체처리에 대한 실용적 관점
- 일부 지역에서 one-life / do-not-restore 문화 강세 가능

중요:
전체 주민이 같은 철학을 갖는 것은 금지.

### Story Engine
- 농업 사고
- 생태부하
- 식량/이주 갈등
- 단생주의/복원거부 가족사건
- 생활/여행의 시각적 변화

---

## Habitat C — Technical / Mixed Industrial Residence Cylinder
인구 후보: 약 7~9만.

### 기능
산업시설 자체는 주로 Spine/Outer Works에 있지만, 그 노동자/기술자/가족이 많이 사는 생활권.

### 경제
- 조선/정비 설계
- 보철/재건 의료산업
- 로봇/물류
- 열관리
- 대형 구조물 서비스

### 생활
교대근무 문화, 무중력 출퇴근자 많음.
다른 생활권보다:
- 보철
- 재건수술
- 위험직 Scan
경험자가 많을 수 있음.

### 정치
산업노조/의료접근권/위험수당 이슈 강함.

### Story Engine
- D 출신지 후보
- 노동갈등
- 고위험 reconstruction rights
- zero-g/industrial culture
- C8-B의 직업/가족 배치 후보 가능

# 2. Non-Rotating Spine — ‘바다이자 철도망’

인구 후보: 상시거주/교대 포함 약 1~2만 규모를 검토.

### 기능
- 세 생활원통 연결
- 물류
- 저장
- 대형 화물 이동
- 무중력 작업
- 도킹/외부 접근
- 일부 특수 연구시설

### 세계적 의미
생활원통 사이 이동은 단순 엘리베이터가 아니다.

Spine은:
- 다른 중력문화가 만나는 곳
- 환승도시
- 화물항
- 여행의 경계
에 가까움.

### Story Use
- P/R 이동장면
- 봉쇄/교통 중단
- 무중력 노동
- 서로 다른 생활권 사람들이 충돌하는 중립지대

# 3. Outer Works — ‘국경/해양 작업지대’

거주지는 최소화.
대부분 교대작업/장기숙소.

### 포함 후보
- 방열기
- 외벽점검
- 추진/전력계통 접근부
- 외부 센서
- 구조재 저장

### 문화
여기서 일하는 사람들은 ‘외벽 사람’이라는 직업정체성을 가질 수 있으나 독립 종족처럼 만들지 않는다.

### Story Use
PP3 산업사고, 구조, physical pressure.

---

# 4. Founding Core / Legacy Decks

기존 ‘선구역’을 비밀 던전으로 만들지 않는다.

### 역사
초기 항해 세대는 현재 3개 생활원통이 완전히 가동되기 전 중앙축/작은 초기거주모듈에서 살았음.

세기가 지나며 대부분:
- 창고
- 연구
- 설비
- 폐쇄공간
으로 용도전환.

### 현재
일부 시설은 평범하게 사용 중.
일부는 위험/비효율 때문에 폐쇄.
일부 역사자료/구식 장비가 남음.

### Mystery Benefit
진실이 ‘금지된 비밀방 하나’에 전부 저장되어 있지 않음.
여러 시대의 기록이 서로 다른 기관/시설에 흩어짐.

# 10. Independent Conflict v0.2 — Old Quarter Closure

구환 전체가 아니라 Habitat A 내 오래된 대형 구역.

### Trigger
노후:
- 압력계통
- 물순환
- 구조/전력
의 장기 보수비가 증가.

### Mission Bloc
단계적 폐쇄/재개발 주장.

### 주민
‘위험을 알지만 여기서 계속 살겠다’는 사람과 ‘좋은 조건이면 이주’하는 사람이 갈림.

### Heritage
건물/기록 보존 요구.

### Habitat B
대규모 이주 수용 시 생태/주거부하 걱정.

### Habitat C
새 주거/산업전환 수요로 이익을 보는 사람도 있음.

### P
연속성/친권/재건환자 같은 **개인 사건** 때문에 현장에 파견될 수 있음.
P가 구역 폐쇄정책 자체를 결정하지 않는다.

### O
주민대표/오랜 친구 후보.

### C8-B
이 구역 또는 이주 대상 인접지역의 평범한 부모로 먼저 등장시킬 수 있음.
이 경우 C8을 메인 미스터리와 무관한 생활문제로 1~2회 먼저 보여줄 수 있음.
