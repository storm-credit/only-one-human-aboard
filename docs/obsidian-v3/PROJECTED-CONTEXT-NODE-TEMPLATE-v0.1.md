A `CTX-V3-EPxxx` note is a **Projected Execution Contract**, not a mini-blueprint.

## STATIC fields the node routes
1. exact Episode Blueprint selector,
2. Episode→Beat→Sub-Act→Volume→Act ancestry,
3. forecast incoming carry selector,
4. character/relationship state selectors,
5. world/location/institution/material selectors,
6. reveal/knowledge fence selector,
7. collectibility salience budget,
8. concurrency/geography preflight where required,
9. forecast outgoing selector,
10. DYNAMIC placeholders.

## DYNAMIC fields kept PENDING until JIT
- actual incoming continuity,
- actual relationship state,
- actual material state,
- actual location/access state,
- actual institution/network state,
- POV-known actual,
- reader-confirmed actual,
- active device state,
- selected foreground assets,
- compiled five-bundle payload,
- realized delta.

## Hard interpretation
- `PROJECTED` never means the event/state already happened.
- exact A-Plot/POV/End Turn truth stays in the Episode Blueprint.
- a Context file may be deep as a router, but direct drafting payload remains max five bundles.
- graph-active/eligible assets are not automatically prose-salient.
- unresolved C2 labels remain stable IDs/placeholders.
- never draft from Context alone.

## Directive levels
`MUST / TARGET / PREFER / MAY / FORBID`.
Only MUST/FORBID are hard prose constraints.

## Runtime transition
`PROJECTED → (actual prior continuity loaded) → FROZEN → DRAFTED → CONTINUITY-FROZEN`.
