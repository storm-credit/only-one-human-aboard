# V3 PROTAGONIST NAME — DEEP BRAINSTORM v0.2

Status: `C2 SURFACE DESIGN / NOT CANON / NO PROSE`
Date: 2026-08-20
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
Reopen only the protagonist full-name surface choice after the prior v0.1 matrix proved too narrow in surname pool and too dependent on a few repeated combinations.

This does NOT reopen character architecture.

Current character target:
- male ~36~38,
- ship damage-analysis professional,
- ordinary citizen,
- practical/skeptical/dry,
- not military,
- not detective archetype,
- not chosen one,
- carries a long 410-episode story,
- Korean reader must pronounce and remember the name without friction.

User feedback already binding:
- `Rowan Han / 로언 한` = discard,
- `Kyle Han / 카일 한` = discard,
- surname `한` has no privileged reason,
- clipped 2+2 names such as `에런 베일 / 레온 케인 / 이안 로웰 / 노아 벡` feel awkward,
- prefer asymmetrical or fuller Korean rhythm.

---

# 1. Naming philosophy retained

Use recognizable Earth-origin names recombined over centuries.

Do NOT:
- invent fantasy/SF syllables merely to sound future,
- bind given-name origin to surname ancestry,
- explain nationality unless story requires it,
- give protagonist a conspicuously heroic/aristocratic name.

Preferred Korean full-name rhythm:
- 3+3 strongest,
- 3+2 acceptable when surname has enough consonant weight,
- 4+3 selective,
- 2+3 only if given name remains strong in dialogue.

---

# 2. Scoring model

Each 1~5, total 35.

1. Korean read-aloud ease
2. full-name rhythm
3. given-name dialogue durability
4. age / working-professional fit
5. memorability without hero-coding
6. fit beside Mira Solano / Arun Kalev / Niko Osman / Selene Adebayo
7. low artificial-`international cast` feel

Penalty flags:
- HERO = too protagonist-handsome/romantic/genre-coded
- YOUNG = feels too young/light
- POLISH = too intellectual/elite for hands-on specialist
- CLASH = phonetic collision with core cast
- GENERIC = disappears too easily
- REGION = combination feels too deliberately region-coded rather than centuries-recombined

# 4. Strongest five after expanded pool

## 1. 다니엘 마레크
Why it rose above v0.1:
- 3+3 rhythm is smooth without decorative flourish,
- `다니엘` works naturally alone in dialogue,
- `마레크` gives enough distinctiveness without feeling like codename,
- adult field-professional impression is strong,
- does not sound tied to the same regional cluster as Mira Solano,
- works beside Arun Kalev and Niko Osman without phonetic confusion.

Risk:
`다니엘` is familiar enough that surname must carry some memory load.

Current verdict:
**LEADING.**

## 2. 요나스 켈러
Strength:
- quiet, practical, slightly unusual but immediately pronounceable,
- no hero aura,
- good fit for dry skeptical protagonist,
- `요나스` alone is memorable.

Risk:
less familiar to some Korean readers than Daniel/Lucas.

Current verdict:
**STRONG ALTERNATIVE.**

## 3. 토마스 나바로
Strength:
- mature age fit,
- warm enough for family/relationship scenes,
- full-name rhythm excellent,
- not fantasy or game-coded.

Risk:
slightly more cultural flavor than Daniel Marek/Jonas Keller.

Current verdict:
**STRONG ALTERNATIVE.**

## 4. 루카스 베르너
Strength:
- very readable,
- strong action/dialogue rhythm,
- easy cover-name recognition.

Risk:
slightly more conventional `handsome lead` signal than desired.

Current verdict:
**KEEP / NOT FIRST.**

## 5. 엘리엇 마레크
Strength:
- excellent 3+3 sound,
- strong mystery tone,
- previously surfaced naturally in brainstorming.

Risk:
reads more polished/intellectual than field-damage specialist.

Current verdict:
**KEEP / TONE-DEPENDENT.**
