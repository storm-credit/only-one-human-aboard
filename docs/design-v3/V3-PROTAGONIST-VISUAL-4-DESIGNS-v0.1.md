Role fixed:
late-30s male / ship damage analyst / ordinary citizen / not soldier / not chosen one.

Goal:
Find a visual identity memorable enough for cover/illustration/figure recognition while remaining believable as an ordinary experienced technical worker.

---

# P-A — Quiet Technical Realist

Silhouette:
- lean medium-height build,
- slightly rounded working shoulders,
- compact field jacket,
- narrow equipment case.

Face/hair:
- plain mature face,
- dark short-to-medium hair,
- tired eyes,
- almost no stylization.

Strength:
maximum realism and ordinary-person fit.

Weakness:
can disappear in cover art; weak immediate IP hook.

Verdict:
`GOOD BASE / TOO QUIET ALONE`.

---

# P-B — Rugged Failure Investigator

Silhouette:
- taller/heavier,
- visibly strong forearms/hands,
- more protective layers/harness,
- weathered face and obvious work scars.

Strength:
strong survival/thriller visual presence.

Weakness:
reads too much like action hero / veteran engineer; risks making profession heroic by physique.

Verdict:
`REJECT AS PRIMARY / BORROW HANDS-ON MATERIALITY`.

---

# P-C — Civic Professional / Analyst

Silhouette:
- cleaner professional layers,
- less visible tool load,
- smart but understated interface carry.

Strength:
fits investigator/mystery readability; visually adult.

Weakness:
weakens dirty-hands field specialist identity; can look office/detective-coded.

Verdict:
`REJECT AS PRIMARY / USE OFF-DUTY OR REVIEW-MEETING STATE`.

---

# P-D — Layered Field Civilian

Silhouette:
- ordinary civilian body,
- recognizable short field jacket with asymmetric tool-side wear,
- narrow hard case in work scenes,
- no permanent helmet/armor,
- posture changes radically between work and home.

Face/hair:
- mature but not conventionally heroic,
- hair long enough to lose shape under protective gear but short enough for work,
- one subtle asymmetry/feature candidate (slightly crooked nose from old mundane injury, strong brow, or asymmetrical smile) to choose later,
- no iconic scar.

Hands/material:
- fingertips/knuckles show ordinary technical wear,
- one older repaired watch/band is possible but should not become heritage clue,
- marking stylus and case create visual recognition.

Civilian state:
- soft overshirt/jacket, normal shoes, almost no technical gear,
- important because he must look like someone's brother/son/ex-partner, not on-duty protagonist 24/7.

Crisis state:
- same base garments with added task-specific protection, smoke/abrasion/temporary markings; no transformation into armored action suit.

Strengths:
- clear occupational silhouette,
- strong cover/figure hook without weapon,
- ordinary-life contrast,
- visual evolution across Acts.

Weakness:
needs exact face/hair/color calibration later.
