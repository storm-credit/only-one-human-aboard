# V3 MACHINE / CRAFT / EQUIPMENT ECOLOGY v0.1

Status: `IP/VISUAL DEEP-DESIGN CANDIDATE / NOT CANON / NO PROSE`
Date: 2026-08-20
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
Create memorable recurring machine/equipment families that make Meridian physically believable and collectible/recognizable without turning the series into combat-mecha or gadget-progression fiction.

## Machine design law

1. Machines exist because a 300k-person closed city needs work done.
2. Visual identity follows role, maintenance history and environment.
3. Model generations differ mainly through safety, efficiency, control and modular compatibility—not linear combat power.
4. Old units can remain because certification/parts/interface continuity matters.
5. Named model families are scarce. Most equipment stays generic.
6. A machine becomes reader-memorable by **return + changed context**, not spec dumping.
7. Human judgment remains necessary at edge cases.
8. No autonomous lethal combat fleet.
9. No protagonist-owned super-machine.
10. Damage and replacement have institutional/resource consequences.

---

# Naming grammar — candidate

Reader-facing default:
**function name first**, model name/series only when recurring.

Example grammar:
- `구조 크롤러`
- `구조 크롤러 4세대형`
- local nickname only after repeated use.

Avoid:
- dozens of alphanumeric codes,
- Gundam-style heroic unit names for ordinary municipal machines,
- rarity tiers.

Author-facing model dimensions:
- Era: legacy / mature / current / settlement adaptation
- Chassis: compact / standard / heavy
- Environment: civic / service / low-g / external
- Control: direct / supervised autonomous / remote-support
- Tool pack: inspection / rescue / cargo / isolation / fabrication

# EQ-P — Protagonist Damage Analysis Kit

This is a **kit ecology**, not one magic scanner.

## P1 Surface/Fracture Mapper
Function:
structured-light/contact/ultrasonic-style multimodal surface and near-surface mapping at narrative level.

Visual:
folding three-point head or compact bar with contact pads; throws visible calibration marks only when active.

Limits:
- needs access/angle/contact depending mode,
- coatings/heat/contamination can corrupt data,
- cannot see arbitrary deep structure,
- needs known material baseline.

Story recurrence:
Act1 normal work → Act2 contaminated/partial data → Act5 impossible sequence → Act7 physical-history inference.

## P2 Thermal/Residue Sampler
Function:
collect local residue/material/heat history evidence.

Visual:
small cartridge tabs and sealed sample tray.

Limits:
chain of custody, contamination, time degradation.

## P3 Calibration Block Set
Function:
known references to prove sensor truth before accusing records.

Visual:
small dense blocks/strips in field case.

Character value:
shows protagonist checks his own tools before believing impossible evidence.

## P4 Physical Marking Kit
Function:
number, arrow, boundary, sequence marking on authorized surfaces.

Visual:
highly recognizable temporary marks; becomes recurring visual language in damaged spaces.

## P5 Isolation/Lockout Tags
Function:
physically label/secure unsafe systems during work.

Act6 payoff:
becomes more prominent as protagonist learns some systems should be disabled rather than immediately repaired.

Hard:
No device identifies `which lineage this object came from`.

# M01 — Structural Inspection Crawler Family

Role:
confined service corridors, structural interfaces, pressure boundaries, underfloor/overhead spaces.

Scale:
large dog / low utility cart class depending variant.

Silhouette:
- low rectangular/hex body,
- four to six clamp/articulated legs,
- short sensor mast,
- replaceable abrasion panels,
- exposed standardized tool rail.

Control:
supervised autonomous navigation + human tasking; manual recovery possible.

Variants:
- S: compact inspection
- C: contact/sampling
- H: heavy clamp/support

Generation language:
Legacy units: bulky joints, many adapters, easier field repair.
Current units: quieter, compact sensor integration, better self-check.

Why old survives:
legacy corridor geometry and certified attachments.

Failure modes:
- clamp slip,
- sensor contamination,
- comms loss,
- joint overheat,
- false clean result from inaccessible surface.

Act path:
Act1 ordinary recognition → Act2 one unit trapped/damaged → Act5 older interface unexpectedly accepts a legacy adapter → Act7 this compatibility helps prove deep maintenance ancestry → Act9 descendant rig uses same attachment standard.

Collectibility:
miniatures, retired panels, local service stickers, model-generation recognition.

# M02 — Damage Mapping Field Drone Family

Role:
rapid room/corridor geometry capture and hazard mapping.

Silhouette:
flat triangular or three-lobed body with protected rotors/ducts or micro-thrust/airflow appropriate to local environment; service-zone variants may use crawling/magnetic contact instead of flight.

Key visual:
projects a moving **reference lattice** only onto surfaces for measurement; not universal AR hologram.

Variants:
- civic enclosed-space mapper
- service crawler-mapper
- low-g tethered mapper

Limits:
smoke, dust, reflective/absorptive surfaces, occlusion, network segmentation.

Hard:
It cannot solve failure cause by itself; it gives geometry/data.

Reader hook:
recognizable three-lobed silhouette and temporary light-grid pattern.

---

# M03 — Emergency Rescue Skiff Family

Role:
move responders/patients/equipment through service corridors, low-g transfer spaces or temporary isolated routes where normal transit is unavailable.

Not:
a fighter craft.

Silhouette:
- compact central control pod,
- open/convertible side rails,
- rear modular cradle/tool pallet,
- strong bump/handhold geometry.

Mobility:
variant-dependent wheeled/rail/low-g translation; external variant is separate certified chassis, not one magical all-terrain vehicle.

Variants:
- R-Med: patient cradle
- R-Access: cutting/seal/support tools
- R-Evac: more seats/handholds

Act2:
rescue variants appear in separate zones; one route choice matters.

Act6:
scarcity creates mixed-generation fleet and cannibalized modules.

Act9:
settlement descendant is slower/rougher in early infrastructure, visually linking rescue culture to new terrain.

Collectibility:
clear module variants without power ranking.

# M04 — Utility Tug / Freight Tractor Family

Role:
Transfer Belt freight, heavy component movement, depot shunting.

Silhouette:
- blunt low nose,
- standardized attachment collar/hitch,
- cabin offset for visibility,
- replaceable bumper/panel surfaces.

Why memorable:
ubiquitous civic workhorse—like buses/forklifts/trucks combined in cultural familiarity.

Variants:
- passenger-service support
- bulk cargo
- hazardous cargo shielded/control variant
- low-g transfer tug

Visual variation:
district/operator markings, repair panels, generations.

Plot:
Act1 ordinary traffic → Act2 reroute bottleneck → Act4 panic causes reservation/flow distortion → Act6 neutral-corridor logistics → Act9 old attachment standard reused in settlement cargo rig.

In-world collecting:
children/adults may collect miniature tug variants, retired route plates, operator patches.

---

# M05 — Outer Works Service Frame

Role:
support trained human external workers with leverage, anchoring, tool handling and fatigue reduction.

Design choice:
**non-combat industrial exoframe / work rig**.

Silhouette:
- torso/hip support frame,
- external tool/anchor rails,
- oversized non-anthropomorphic manipulators or tool booms depending task,
- tether and life-support interface visually dominant,
- no weapon hardpoints.

Use:
radiator, shield, sensor, outer structural maintenance; later settlement heavy commissioning.

Control:
human-in-loop; some remote/support automation.

Failure modes:
- joint lock,
- anchor failure,
- power/thermal limit,
- suit/frame interface damage,
- tool boom collision.

Collectibility/IP:
strong model-kit potential precisely because it is a **work machine**, with variant tool arms and generations.

Hard anti-drift:
- not bipedal heroic humanoid by default,
- cannot duel,
- not privately owned protagonist vehicle,
- no secret military prototype.

# M06 — Public-Safety Barrier / Containment Drone Family

Role:
rapid access control, warning, portable sensing, crowd/route separation, hazard perimeter support.

Silhouette:
- deployable panel/wing geometry,
- bright directional indicators,
- low center of gravity,
- no gun-like barrel silhouette.

Functions:
- temporary barrier mesh/panel,
- light/sound warning,
- local camera/sensor relay,
- door/route interface support,
- evidence-preserving perimeter.

Limits:
can be moved/damaged/bypassed; not magic prison wall.

Act4/6:
visual measure of public-safety escalation; more units in streets changes atmosphere before violence.

Hard:
no autonomous guilt assessment or lethal force.

---

# M07 — Medical Transfer Cradle Family

Role:
patient stabilization during movement between field, transit, hospital.

Why include:
medical machinery should be visually recognized rather than all healing happening invisibly.

Silhouette:
low rigid frame with modular life-support/monitor clips and hand-carry/vehicle locking geometry.

Variants:
- ordinary emergency
- contamination isolation
- low-g transfer

Act2/6:
scarcity/availability becomes visible through empty/full cradle queues, damaged modules, improvised transfers.

Collectibility:
not merchandise-first, but strong world-recognition object.

---

# M08 — Settlement Commissioning Field Rig

Role:
Act9 early external infrastructure assembly, isolation and local control.

Critical design rule:
**must visibly descend from familiar Meridian machine standards rather than appear as a completely new sci-fi toy at the finale.**

Ancestry:
- M01 attachment/clamp logic,
- M04 cargo collar,
- M05 tool-boom/anchor practice,
- known local-control/isolation systems.

Silhouette:
modular squat field platform with separated local-control cabinet, deployable anchors and swap tool modules.

Story:
one early unit remains relatively stable during shared-network failure because commissioning isolation was never removed.

This is a payoff to ordinary engineering practice, not destiny.

# Machine-era visual grammar

## Legacy / Foundational-compatible
- thicker housings,
- more exposed fasteners/interfaces,
- many certified adapter plates,
- physical service marks,
- less integrated display surfaces.

## Mature Meridian
- best balance of repairability/modularity,
- most common long-lived fleet,
- visual baseline.

## Current / Final Approach
- more compact controls/sensors,
- improved efficiency and diagnostics,
- sometimes harder to field-repair,
- settlement adapters beginning to appear.

Hard:
`newer = better in every way` is false.
Tradeoffs matter.

# Hostile gates

FAIL if:
- a better model repeatedly solves plot,
- protagonist receives unique prototype,
- machine names exceed reader memory budget,
- workframe becomes combat mecha,
- drones replace human judgment,
- every Act introduces new vehicle family,
- specifications interrupt scene action,
- machines exist only for merchability.

PASS target:
reader can recognize 5~6 families by silhouette/use, understand old/new variants, and feel satisfaction when early machines or standards return in later changed roles.
