# 1. Core image

There is one real interstellar vessel: **Meridian**.

Inside Meridian are ultradense engineered-matter substrate banks.
Those banks physically contain an incomprehensibly large population of microscopic civilization anchors/seeds and the distributed physical substrate that executes their states.

The intended mental image is:

> 하나의 우주선 안에 사람이 셀 의미가 없을 정도로 많은 문명 가능성이 물리적으로 실려 있다.

This is NOT:
- many cosmological parallel universes,
- many duplicate macroscopic spaceships,
- literal ordinary atoms each containing a pocket universe.

It IS:
- one macroscopic ship,
- physically instantiated microscopic civilization substrates,
- astronomical lineage/possibility count,
- finite but extremely advanced compute/storage/interconnect,
- variable execution depth.

# 3. Civilization count: astronomical, not literally infinite

Hard distinction:

**Possibility count ≠ fully conscious civilization count.**

The system can generate astronomically many candidate paths because most remain cheap or compressed.

Working depth classes:

- `D0 Seed` — archived lineage seed/state reference.
- `D1 Forecast` — low-depth statistical/agent prediction.
- `D2 Deep Model` — high-detail civic/social model without assuming full continuing personhood for every entity.
- `D3 Lived Civilization` — full subjective civic history; persons are moral subjects.
- `D4 Crisis Depth` — temporary extra fidelity/resources during extreme novelty or instability.

Rules:
1. D0/D1 count can be effectively uncountable from a citizen perspective.
2. D2 can be extremely large but physically finite.
3. D3 is much more expensive and physically bounded, but **no arbitrary `2~3` cap** is imposed.
4. Exact D3 count is intentionally not frozen until a later quantitative SF pass.
5. Never describe all generated possibilities as conscious persons.

This preserves both:
- the user's `수천만·천문학적 가능성` vision,
- finite power/heat/ethics.

# 4. How civilizations repeat

The hidden system does not run a simple loop.

Author model:

`civilization seed → huge possibility expansion → pruning/deepening → some lived histories → extraction of robust lessons/novelty → descendant civilization seeds → expansion again`

This produces a **genealogical search tree**, not a circle.

A later civilization may inherit:
- institutional rules from one lineage,
- technical solutions from another,
- social warnings from another,
- selected identity/person lineage seeds,
- no direct conscious memory of those sources.

It is not required to choose one `winner world` wholesale.

The system searches for resilience, adaptation and novel response rather than a single ideology.

# 5. Character lineage rule

Recurring characters are not scripted NPCs.

A recurring person-lineage provides a starting configuration such as:
- temperament distribution,
- learned dispositions,
- developmental history seed,
- family/social starting conditions,
- embodied identity continuity rules.

After divergence, each lived person is an independent person.

Therefore a familiar character can:
- make the same decision again,
- make the opposite decision,
- make a new third decision,
- die early,
- never meet the protagonist,
- have a different family,
- become politically powerful,
- remain an ordinary worker,
- become villainous in one history and admirable in another,
- be irrelevant in most histories but civilization-critical in one.

**Importance itself is an emergent variable.**

No fixed `hero roster` exists in the hidden system.
The story has recurring cast because those lineages repeatedly become narratively informative, not because the system crowns them protagonists.

# 6. Social cascade engine

Civilization outcomes depend on interacting variables, not isolated personality switches.

Required variable families:
- individual decision,
- family obligation,
- friendship,
- romantic attachment,
- parental/child attachment,
- grief,
- altruism,
- resentment,
- reputation,
- group identity,
- class/work role,
- institution,
- resource scarcity,
- physical disaster,
- chance encounter,
- misinformation,
- unknown actor,
- novel invention,
- behavior the system did not predict.

Causal pattern:

`small action → relationship change → group response → institutional response → resource/violence/trust cascade → civilization outcome`

Important:
Love, friendship or altruism are not magical uncomputable forces.
Most effects are partly predictable.
The hard cases emerge from nonlinear interaction and path dependence.

# 7. Memory across histories

Cross-history memory is NOT a normal civilization feature.

It is an integrity failure family.

Most people experience zero cross-lineage autobiographical leakage in an entire lifetime.

Possible rare failures:
- one scene from another lived lineage,
- a family relationship that does not exist here,
- a remembered death,
- knowledge of a corridor or disaster never experienced locally,
- a face triggering another lineage's attachment,
- two incompatible memories.

Strong coherent rememberers are series-scale exceptions.

Social interpretation may be:
- trauma,
- delusion,
- déjà vu,
- past-life belief,
- prophecy,
- luck,
- secret information,
- religious revelation.

No institution possesses a reliable `past-life API`.
If it did, secrecy would already have collapsed.

# 9. Death stakes

Hard rules:
1. Death in a D3 lived civilization is real for that person.
2. A counterpart in another lineage is not the dead person automatically resurrected.
3. Stored information alone is not sufficient to declare subjective continuity restored.
4. Personal death does not trigger a reset.
5. The protagonist cannot intentionally reproduce the Act2 failover.
6. A civilization can continue elsewhere while a particular person remains dead.
7. Later discovery of another version of a loved one must not erase grief for the person actually lost.

Reader-facing emotional rule:

> `다른 곳에 같은 얼굴이 있다` is not a cure for bereavement.

# 10. Lived-lineage lifecycle / ethics

The system cannot ethically treat D3 histories like disposable calculations.

Current candidate history:
- early mission systems used shallow/short counterfactual states,
- designers treated them as model extensions rather than independent societies,
- over centuries the system needed deeper social novelty,
- execution depth increased,
- some histories crossed into full lived personhood,
- legal/governance categories did not evolve at the same speed.

This creates the central late ethical conflict.

A D3 lineage may be:
- actively running,
- continuity-preserving quiescent/paused,
- resumed,
- lost through real substrate destruction,
- transitioned only under rules still to be designed.

Automatic mass deletion of living D3 civilizations is forbidden as an author-side easy solution.

Open P0/P1:
- rights of quiescent persons,
- consent to being branched,
- children born within divergent histories,
- settlement representation,
- allocation under real ark emergency.

# 12. Outer-ark coupling

The outer ship is not decorative.

Every major external constraint can affect many internal histories:
- power loss → depth reduction/rationing,
- radiator damage → compute/thermal ceiling,
- radiation strike → corrupted anchor cluster,
- interconnect fault → isolated lineages,
- fabrication loss → fewer repair options,
- external signal → new scenario input or real threat,
- destination approach → settlement resource competition.

Conversely, internal civilization learning can affect outer mission policy indirectly through validated technical/social outputs.

No internal civilization gets omnipotent access to outer hardware by default.
