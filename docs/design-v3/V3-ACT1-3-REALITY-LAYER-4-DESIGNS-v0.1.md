# Design A — Physical A → Immediate PSS Reset

Act1~2:
- L1 physical Primary.

Act2 ending:
- terminal gate.
- shipwide PSS immediately restores most minds near earlier Anchor.

Act3:
- 같은 몸/더 늙은 선체/과거에 가까운 정신상태.

## Strength
- 첫 90화 100% physical.
- 회귀 착시 강함.
- body scar / serial clue 매우 강함.

## Weakness
- Act3부터 벌써 작품 최대 윤리기술 PSS를 써버림.
- 30만 현재 인격 overwrite라는 핵폭탄을 너무 빨리 소비.
- 후반 Act8 윤리 reveal 전에 사실상 핵심 메커니즘이 실행됨.
- 반복 사용 기대를 낳아 death stakes 약화.

Verdict: **REJECT AS FIRST TRANSITION**.

# Design B — First 90 = L2 Lived World → Alternate L2

Act1~2:
- 처음부터 full-conscious L2.

Act2 ending:
- Primary branch quiescence/붕괴.

Act3:
- same Anchor alternate SLL.
- 로언 memory residue.

## Strength
- 기술적으로 가장 깔끔한 regression.
- 선체 물리 reset 불필요.
- branch 구조를 바로 활용.

## Weakness
- 후반에 `첫 90화가 simulation`으로 읽힐 위험 최고.
- 물리 시설기사 주인공의 장점이 소급 약해질 수 있음.
- 첫 메리디언을 잃은 감정이 `저장된 branch` 문제로 변질될 가능성.

Verdict: **STRONG MECHANICS / HIGH EMOTIONAL RISK**.

Act1~2:

Act2 ending:

## Strength

- 두 역사 모두 실제 도덕주체.

- `우리가 따라온 로언이 누구냐` 문제가 큼.
- B가 최종 실제 미래에 어떻게 참여하는지 약함.
- finale에서 A/B 중 한쪽이 감정적으로 버려질 위험.

Verdict: **GOOD MIDGAME / WEAK FINAL CONVERGENCE**.

# Design D — Physical Primary + Alternate Lived Lineage + One Rare Physical Succession [LEADING]

핵심:

> **첫 세계는 실제 물리 메리디언이다. 두 번째 역사는 lived alternate다. 후반에 딱 한 번의 rare PSS가 두 역사와 물리 미래를 충돌시킨다.**

## Phase 1 — L1 Primary A

Act1~2 중심:
- 실제 선체,
- 실제 시민,
- 실제 부상/사망,
- 실제 자원손실.

Reader promise:
`첫 메리디언은 진짜였다.`

## Phase 2 — SLL-B

대형재난/불확실성 이후 CCAL이 과거 Anchor에서 alternate lived lineage B를 연다.

B는:
- full-conscious persons,
- 같은 핵심 인물,
- 다른 조건,
- 자체 죽음/관계/역사
를 갖는다.

로언에게 A의 autobiographical residue가 비정상적으로 많이 남으면:
`죽고 돌아왔다`고 느낄 수 있다.

Hard:
로언만 유일한 residue carrier가 아니다.
그의 coherence가 높은 이유는 후속 설계가 필요하지만 chosen-one 금지.

## Phase 3 — A/B collision

중후반:
- physical A가 terminal recovery risk에 접근하거나,
- B가 현재 문명의 더 viable lineage로 평가되는 사건이 발생.

여기서 처음으로 **story-era PSS 1회 후보**가 열린다.

PSS는:
- B 사람을 새 몸에 출력하는 것이 아니라,
- A의 continuity-compatible physical bodies에 대응 B lineage state를 재구성.

결과는 B의 단순 승리가 아니다.

- A 몸의 흉터/나이/물리손상,
- A memory residue,
- B autobiographical state,
- L0 누적 선체상태
가 한 현재에 겹친다.

이것이 Act7의 `돌아온 적 없는 세계 / novel state`에 매우 잘 맞는다.

## Phase 4 — physical irreversible future

PSS 이후 현재 사회는 다시 L1 physical.

그러나:
- 어느 한 history의 완벽한 복구가 아님.
- A도 B도 아닌 successor civic state.

Final Approach에서는 다시 이런 PSS를 할 자원/권한을 시민들이 스스로 끊는다.

## Strength
- first-90 physical = 최고.
- Act3 regression/multiple history = 강함.
- PSS를 후반 대형 payoff로 아낌.
- Act7 `novel state`를 기술/인물/윤리 세 축에서 동시에 설명.
- final physical future로 자연스럽게 수렴.
- `같은 사람 / 다른 조건`이 실제 몸과 기억에 충돌.

## Weakness
- 가장 복잡함.
- A/B 어느 lineage를 독자가 언제 따라가는지 Writer Ledger 필수.
- PSS가 `B가 더 좋은 사회라서 선택`처럼 보이면 우생/최적화 위험.

Required guardrail:
PSS selection은 도덕점수/이념점수가 아니라 **terminal recovery + viable continuity** 조건이어야 한다.
B 역시 결함/죄/상실을 가진다.

Verdict: **BEST LONG-FORM CONVERGENCE**.

# Selected candidate — Design D

Working macro reality grammar:

```text
L0 physical ship: always forward

L1-A physical Primary
   ↓ Anchor / crisis
SLL-B alternate lived history
   ↓ residues / conflicting lives
A ↔ B collision
   ↓ one rare PSS candidate
L1-N novel physical successor state
   ↓ citizens end rehearsal
Irreversible physical future
```

Important:
- `N`은 B의 완전복제도 A의 원상복구도 아니다.
- 물리 몸/선체는 A의 시간축을 계속 가지고 있음.
- 인격상태는 B 영향이 크더라도 A residue가 남음.
- 제도/관계는 양쪽 학습을 거쳐 새로 결정.

이것이 로언의 최종 arc:
`고치면 원래대로` → **`원래대로라는 상태 자체가 없다.`**
와 정확히 맞는다.

# Identity fairness

Design D의 가장 큰 위험은 `A 사람을 B로 덮어쓰는 것`.

따라서 작품은 PSS를:
- 치료라고 확정하지 않고,
- 살인이라고 확정하지도 않고,
- 과거 설계자들의 identity assumption과 현대 시민 윤리의 충돌로 다룬다.

특히 A의 잔존 기억을 가진 인물이:
> `당신이 살리려던 나는, 이미 여기 있었어.`
같은 갈등을 만들 수 있다.

문장 자체는 예시이며 정본 대사 아님.

# Rowan rule

로언이 높은 residue coherence를 가진 이유를 `주인공이라서`로 두지 않는다.

후보:
1. 과거 사고로 NCL 손상/재보정 이력.
2. 시설업무상 오래된 구획의 강한 감각/절차 기억이 Anchor reconstruction에서 잘 보존.
3. prior historical PSS 흔적이 family/genetic이 아니라 **개인 의료이력**에 있음.
4. 단순 통계적 outlier + 이후 시스템이 관찰대상으로 삼음.

4안 비교 필요.
