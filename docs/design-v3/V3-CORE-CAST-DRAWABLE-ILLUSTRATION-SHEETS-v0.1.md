# Outfit-state budget

Do NOT design 10 canon outfits per character.

Core cast default:
- civilian state,
- work state,
- crisis variation,
- late-settlement variation only if the character physically needs it.

Maximum HIGH-memory outfit states per person:
**4**.

This protects recognition and prevents costume-collection drift.
