# What “deep enough” means here

## Character
For each core recurring character, lock:
- height/build band,
- face impression (not beauty ranking),
- hair/maintenance habits,
- dominant silhouette,
- normal civilian clothes,
- workwear/protective layer,
- crisis-state variation,
- footwear/carry logic,
- 1~3 material anchors,
- movement/gesture signature,
- what changes between H-A and H-B, if anything,
- what changes after Act6,
- illustration/figure recognition hook.

## Craft / machine
For each selected family, lock:
- role,
- scale class,
- silhouette,
- propulsion/mobility type at narrative level,
- crew/automation level,
- normal habitat/route,
- generational/retrofit distinction,
- failure modes,
- who uses it,
- recurrence episodes/Acts,
- visual damage/transformation,
- why a reader might remember the family,
- what NOT to over-specify.

## Background
For each major zone, lock:
- dominant geometry,
- ceiling/verticality feeling,
- primary materials,
- repair visibility,
- light source/temperature family,
- ambient noise,
- airflow/smell cues,
- crowd rhythm,
- signage/wayfinding,
- one or two landmarks,
- normal-state palette language,
- emergency-state transformation,
- Act6 damage/occupation state,
- Act9 descendant motif if reused in settlement.

## Collectibility
Use both in-world and reader-facing layers.

In-world:
- transit memorabilia,
- retired interface shells,
- district patches/pins,
- miniature engineering models,
- team/sport items,
- vintage repaired tools,
- old game components,
- local craft,
- voyage/heritage reproductions,
- high-end authenticated Earth/founding objects.

Reader-facing:
`Encounter → Recognition → Recontextualization → Transformation`.

Hard:
- no loot progression,
- no legendary artifact set,
- no rarity color grades,
- no hidden command-key collectible,
- collection belongs to the reader/world, not protagonist inventory.
