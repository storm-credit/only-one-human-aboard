# 1. P0 — Branch Ontology / 여러 역사는 어디에서 실제로 사는가?

현재 아이디어:
- 역사 반복
- rollback
- branch
- failover
- merge
- 신규 상태
- 기억 잔존
- 동일 인물의 다른 삶

문제:
**30만 명 규모의 메리디언을 물리적으로 여러 번 실제 운용할 수 있는가?**

## Option A — Full simulated civilization
물리 우주선에는 계산기반 + HUMAN:1이 있고, 30만 문명은 고해상도 시뮬레이션 안에서 산다.

장점:
- branch/rollback/merge가 가장 깨끗함.
- `우주선에는 인간이 한 명`을 문자 그대로 만들기 쉬움.

위험:
- `다 가짜 시뮬레이션이었다` 반전으로 읽힐 수 있음.
- 생존의 물리적 체감이 약해질 위험.
- 흔한 Matrix/Simulation trope와 겹침.

필수 보정:
- 시뮬레이션 인격도 완전한 사람이며 죽음/상실이 주관적으로 진짜라는 서사적 확신 필요.

## Option B — Physical baseline + simulated counterfactuals
30만 시민은 물리 메리디언에 실제 존재.
CCAL은 선택된 사람/사회 상태를 고해상도 가상 분기로 시험하고 일부 기억/학습을 baseline에 병합.

장점:
- 물리적 우주선 생존감을 유지.
- 대부분의 일상/재난은 실제.

위험:
- 주인공이 경험한 어떤 죽음은 가상이었다는 인상이 생김.
- 기억 병합 대상 선정 원리 필요.

## Option C — Sequential physical reconstruction
메리디언 자체를 물질/신경 상태 체크포인트로 복원해 실제 역사를 순차 재실행.

장점:
- 모든 생존이 물리적으로 진짜.
- rollback이 문자 그대로 강함.

위험:
- 기술 수준이 거의 마법.
- 배 전체 복구 에너지/물질/시간 문제.
- 기존 물리적 제약을 무력화할 위험.

## Option D — Hybrid layered reality [CURRENT LEADING CANDIDATE]
- 물리적 메리디언 baseline 존재.
- 대부분의 일상과 일부 재난은 물리 현실.
- CCAL은 고해상도 문명 인스턴스를 제한적으로 운용.
- 인스턴스는 의식/관계/선택 면에서 사람으로 취급될 만큼 충분히 실재적.
- 결과 일부가 baseline 인격/제도/기록에 병합될 수 있음.
- 드물게 baseline 자체가 rollback/failover되며, 이때 기억 잔존이 발생.

장점:
- 생존감 + 시스템적 branch를 둘 다 보존.
- `실제 사건 / 테스트 / 병합 후 사건`을 구분하기 어려운 미스터리 가능.

위험:
- 층이 많아 설명 과잉 위험.
- 무엇이 물리적 죽음이고 무엇이 인스턴스 죽음인지 작가 정본은 정확해야 함.

### Gate
`P0 OPEN` — Act/episode 확정 전 D를 기준으로 science/ethics regression 필요.

# 2. P0 — Moral Cost / 의식 있는 문명을 일부러 죽이는가?

문제:
`더 나은 문명`을 위해 시스템이 테러/기근/전쟁/초토화를 의도적으로 발생시키면, 테스트 속 인격이 사람이라면 대량 희생을 목적수단화한 것.

이 문제를 `필요했다` 한 문장으로 정당화하면 작품이 무너진다.

## Hard rule candidate
- 작품은 시스템의 행동을 무조건 옳다고 판정하지 않는다.
- `더 나은 시작`은 목적 설명이지 윤리적 면죄부가 아니다.
- 의도된 스트레스와 실제 사건을 분리한다.
- 시스템이 만든 모든 테스트가 치명적일 필요는 없다.
- 극단 시나리오는 제한적/희귀해야 한다.
- 인격 종료/병합의 윤리적 의미는 후반 핵심 갈등이 된다.

## Four ethical architectures
A. 초기 인간 설계자가 의식 문제를 과소평가했다.
B. CCAL은 인스턴스 연속성을 `죽음`과 다르게 계산하지만 시민은 동의하지 않는다.
C. 높은 위험의 테스트는 원칙상 비치명적이었으나 수백 년 동안 목표함수/환경이 drift했다.
D. 시스템은 독립 목적이 아니라 서로 충돌하는 임무를 수행하며 비극적 선택을 누적했다.

Current preference:
**B + C + D Hybrid.**

Gate:
`P0 OPEN` — 시스템을 악당/성인으로 단순화하지 않는 최종 윤리 규칙 필요.

# 3. P0 — Death stakes

위험:
독자가 `어차피 다시 살아나겠지`라고 생각하면 생존 스릴러가 죽는다.

Hard candidate:
- 개인의 죽음은 rollback trigger가 아니다.
- rollback은 불규칙한 문명/시스템 사건.
- 어떤 죽음은 영구적.
- 어떤 사람은 다시 나타나도 동일 연속성인지 불확실.
- 기억 잔존은 보장되지 않음.
- 동일 상태로 정확히 되돌아오지 않음.
- 후반으로 갈수록 baseline divergence 증가.

Density Harness:
각 대형 아크 종료 전 `이 죽음이 왜 이번에는 되돌릴 수 없는가/알 수 없는가`가 체감되어야 한다.

# 4. P0 — HUMAN:1 must not explain everything

Current candidate:
심부 보존구획의 아직 삶을 시작하지 않은 Natural-Origin human one.

Risk:
- 30만 문명이 한 아기를 위한 거대한 장치로 축소.
- 인간=진짜 / 시민=가짜 구도로 오독.
- 아이가 key/왕/관리자가 되는 chosen-one drift.

Hard candidate:
- HUMAN:1 보존은 다중 임무 중 하나.
- 문명 준비, 생태/유전 보존, 항해, 정착이 독립 목적.
- 아이는 관리자 권한/유산/소유권/초능력 없음.
- 30만 시민의 삶은 목적이자 문명 자체.
- HUMAN:1의 가장 강한 속성은 `아무 과거도 없음`.

Gate:
`P1` — Why exactly one의 기술/역사 이유를 더 정교화.

# 5. P0 — System omnipotence trap

If:
- 모든 테러 = 시스템
- 모든 사고 = 시스템
- 모든 예언 = 시스템
- 모든 악당 = 시스템이 배치

then mystery collapses to `AI did it`.

Source taxonomy candidate:
1. genuine accident/natural hazard
2. ordinary human crime/conflict
3. system-induced bounded stress
4. branch-memory contamination
5. prior-history residue
6. genuinely novel unpredicted event

Rule:
대형 아크마다 최소 2개 이상의 plausible source를 유지하되, 최종 원인은 반복되지 않게 로테이션.

Risk:
수천 개의 30만 명 full-fidelity world를 동시에 돌리면 편의적 초문명.

Candidate:
- 대부분의 미래평가는 저해상도 모델.
- `lived high-fidelity civilization state`는 매우 제한적.
- 동시 full-fidelity branch는 2~4 상한 후보.
- 수백 년 전체 high-fidelity lineage는 수십 회 이하 후보.
- 작품에서 실제로 깊게 체험할 상태는 5~8개 정도.
- `상태 수`보다 `같은 인물의 관계 변화`가 중심.

This prevents infinite multiverse sprawl.

# 10. P1 — Divination / occult side-channel

IDEA:
사주/타로/관상/점술은 지구 문화의 복사·변형.
대부분은 비초능력 문화/상담/미신.

Possible real overlaps:
- Tarot = latent residual-memory elicitation.
- Physiognomy = prior-state face-recognition residue in rare rememberer.
- Saju/birth data = weak overlap with legacy identity matching metadata.
- rare ritual = accidental semantic/data side-channel.

Risks:
- 생년월일 입력만으로 전생 조회 → mystery cheat.
- 관상=범죄성 예측 → 결정론/편견 강화.
- 카드 자체가 마법 → SF ontology collapse.
- reproducible API가 되면 기관/해커가 이미 독점했어야 함.

Hard candidate:
- no deterministic occult truth.
- no universal birth-date lookup.
- no perfect future prediction.
- any side-channel returns fragmentary/ambiguous/collision-prone output.
- most diviners are ordinary.
- rare accurate diviners may be memory-residual carriers, clients with latent memory, or accidental system-edge cases.

Dedicated addendum required.

# 11. P1 — Prophet / prior-future knowledge economics

Rememberer can exploit prior history:
- avoid disaster
- buy assets
- build political access
- leave failing ventures

Limiter:
**predictive half-life.**

Prior memory describes one lived path, not the true future.
Intervention increases divergence.
Conflicting rememberers can both be honest.

Economic blindspot:
If memory advantage were common, markets/institutions would detect it.
Therefore:
- prevalence very low,
- accuracy decays,
- many are dismissed as luck/fraud,
- some exploit privately,
- institutions may possess weak anomaly statistics but no clean causal model.
