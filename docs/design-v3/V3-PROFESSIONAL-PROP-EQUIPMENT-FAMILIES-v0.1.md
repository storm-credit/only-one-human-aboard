# P01 — Damage Analysis / Structural Diagnostics

Primary users:
protagonist, Gideon, Niko/team.

Core family:
1. surface/fracture mapper,
2. residue/sample tabs,
3. certified calibration blocks,
4. physical marking stylus/kit,
5. lockout/isolation tags,

- evidence physically marked,
- many devices need calibration and access.

# Cross-profession incompatibility rule

Equipment families share safety/access standards where sensible, but jobs remain distinct.

Examples:
- protagonist mapper cannot perform Leila's medical assessment,
- Sora evidence recorder cannot bypass Selene command authority,
- Mira route slate cannot certify structural safety,
- Rafi rescue gear cannot open every sealed structure,
- outer robot fleet cannot make personhood/governance decisions.

This prevents `one universal future tablet` syndrome.

---

# Prop detail budget in prose

First appearance of HIGH-memory family:
1~3 concrete visual/use details.

Later return:
name/function shorthand + one changed detail.

Do NOT repeat full description every time.

Technical specification appears only when:
- failure depends on it,
- generational compatibility matters,
- a tradeoff is being decided.
