# 2. Core premise — leading

One physical interstellar vessel, Meridian, travels through external space.

Inside it exists an **ultradense physical civilization substrate field** containing an astronomically large number of civilization anchors/lineages/possibility states.

The system continuously:
- generates possibilities,
- runs low-depth forecasts,
- deepens informative states,
- executes some lived civilization histories,
- learns from failure/success/novel choice,
- carries civilization forward during the centuries-long voyage.

This is NOT cosmological parallel universes.

---

# 3. Physical model — leading

Current preferred architecture:
**microscopic civilization anchors + distributed ultradense substrate lattice.**

Reason:
- preserves user vision of incomprehensibly many physical civilization seeds inside one ship,
- avoids literal one-ordinary-atom-stores-everything claim,
- retains physical power/heat/error/damage stakes.

Exact technology/scale remains open.

`HUMAN` is a legacy Natural-Origin biological continuity category, not a moral personhood category.

**B+D Hybrid**

# 5. Persons / identity — leading

Citizens are real persons, not NPCs.

Recurring character lineages preserve tendencies, not scripts.

Possible:
- convergent choice,
- divergent choice,
- novel choice,
- reduced importance,
- early death,
- no relationship with protagonist.

Importance is emergent.
A previously minor person can become civilization-critical under particular conditions.

# 7. Memory anomalies — leading

Cross-history autobiographical memory is NOT a feature.

It is a **rare critical integrity bug**.

Most citizens never experience it.
Strong L4/L5 rememberers are exceptional at series scale.

Divination/prophecy/ghost motifs are mostly culture, ambiguity or rare leakage effects.
No stable past-life API.

# 8. Death / backup — leading candidate

Preferred:
**Snapshot-successor + physical continuity anchor hybrid.**

Rule:
A person is an active continuous physical process, not merely stored information.

Therefore:
- backup != automatic resurrection,
- counterpart != resurrection,
- fork creates an independent person after divergence,
- local death remains meaningful.

Exact rights/law still open.

# 9. System ethics — leading candidate

Preferred:
**Continuity Equivalence Doctrine + Depth Drift + Personhood Threshold Uncertainty.**

Early forks were short/bounded enough that designers treated them as one person's experience expansion.
Over centuries, the system deepened lineages to capture social novelty.
Some branches became full lives/civilizations while old governance categories lagged behind.

The system is not a simple evil AI.
The mission goal can be defensible while its inherited ethics become unacceptable.
