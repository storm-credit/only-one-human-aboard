# EMERGENT CRITICAL ACTOR POOL v0.1 — V3 CANDIDATE

Status: `NOT CANON / DEEP DESIGN INPUT`
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
고정 핵심인물만 문명을 움직이는 구조를 피하고, 평범한 사람이 특정 관계·우연·집단·재난·도덕적 선택의 교차점에서 갑자기 문명적으로 중요해질 수 있도록 후보군과 작문 규칙을 만든다.

---

# 0. Core rule

`중요 인물`은 시스템과 작가가 처음부터 정해둔 계급이 아니다.

어떤 사람은 다수 역사에서 반복적으로 높은 영향력을 보이는 attractor일 수 있지만,
어떤 사람은 대부분의 역사에서는 평범하다가 특정 조건에서만 civilization-critical actor가 된다.

중요도 자체가 변수다.

Hard:
- 무명인물의 급부상은 우연한 deus ex machina가 아니다.
- pivot 전 최소 1~3회의 평범한 seed가 있어야 한다.
- 그 사람의 직업/관계/습관이 결정적 순간의 행동과 연결되어야 한다.
- `숨겨진 천재/왕족/선택받은 자`로 뒤집지 않는다.
- 같은 계보라도 다른 역사에서는 중요하지 않을 수 있다.

# 1. Emergent actor archetypes

## EA-01 — Transit Dispatcher
평소 기능:
운송노선/차량/인원 흐름 배치.

Seed:
Act1에서 Rowan이 짜증낼 정도로 우회 노선을 자주 바꾸는 실무자.

Pivot candidate:
대형 정전 중 90초 빠른 노선변경이 특정 의료팀/구조팀 생존 여부를 바꾸고, 이후 두 집단의 신뢰관계까지 바꾼다.

Alternate history:
같은 사람이 규정대로 움직여 대량 고립을 일으켰다는 증언이 존재할 수 있다.

## EA-02 — Sanitation / Waste Technician
평소 기능:
폐기물·오염·수처리 관리.

Seed:
냄새/밸브/오염센서 문제로 짧게 등장.

Pivot:
공식 센서보다 먼저 미세한 화학·생물학 이상을 알아차리고 구획 폐쇄를 주장.

Possible moral split:
한 역사에서는 과잉대응으로 시민분노를 샀고,
다른 역사에서는 그 판단이 감염 확산을 막았다.

## EA-03 — Community Cook
평소 기능:
주노 네트워크와 연결된 식당/급식 실무자.

Seed:
사람 이름/알레르기/식습관을 잘 기억함.

Pivot:
배급위기에서 자원보다 `누가 누구와 함께 먹는가`를 바꾸는 작은 결정이 적대집단 간 접촉을 만들고 폭동/협상을 바꾼다.

Hard:
요리로 세상을 구하는 감동 클리셰가 아니라 사회망 접점으로 사용.

## EA-04 — School Caregiver
평소 기능:
아이 돌봄/통학/생활지도.

Seed:
니코 또는 로언이 생활구역에서 마주치는 평범한 성인.

Pivot:
대피 중 아이 하나를 규정과 다르게 데려가는 선택이 특정 부모/구조팀/지도자의 판단을 연쇄적으로 바꾼다.

Possible dark form:
자기 반 아이들만 보호하려는 판단이 외부 집단 배척의 상징이 될 수도 있다.

# 2. Importance transition grammar

평범한 인물을 갑자기 중요하게 만들 때 본문은 다음 순서를 따른다.

`ordinary presence → small competence/relationship seed → crisis intersection → unexpected choice → social cascade → delayed recognition`

금지:
`이 사람이 사실 모든 것을 바꿀 인물이었다` 같은 예고.

독자가 먼저 느껴야 하는 것:
`저 사람의 작은 선택 때문에 일이 커졌네.`

나중에 다른 역사 증언으로 재맥락화 가능:
- 여기서는 영웅,
- 다른 데서는 실수로 참사를 키운 사람,
- 또 다른 곳에서는 아무 일도 하지 않은 평범한 시민.

# 3. Core cast vs emergent cast rule

Core cast는 독자의 정서적 앵커다.
Emergent actor는 세계가 주인공만을 중심으로 돌지 않는다는 증거다.

한 대형 아크에서:
- 핵심 결정 전부를 Core 1~2명이 독점하면 FAIL.
- 최소 1개의 의미 있는 인과는 Rowan 부재 상태에서 진행되어야 함.
- Act 5~7 가운데 최소 한 번은 minor actor의 선택이 major outcome을 실질적으로 바꿔야 함.
- minor actor가 떠오른 뒤 반드시 Core cast에 편입될 필요는 없음.

---

# 4. Cross-history reputation use

다른 역사에서의 중요도는 narrator summary가 아니라 반응/증언으로 표현한다.

예:
현재의 평범한 학교 돌봄교사를 보고 한 기억 누출자가 공포에 질림.

`저 사람이 문을 잠갔어요.`

현재 사람들은:
`저 사람은 애들 데리고 다니는 교사인데?`

라고 반응.

Later evidence:
다른 lived lineage에서 실제로 그 교사가 대피시설 책임자가 되어 문을 봉쇄했음.

이때 독자는 `사람의 본질`보다 `상황 + 권한 + 관계 + 선택`을 보게 된다.

---

# 5. Harness

PASS 조건:
1. pivot 전 ordinary seed 존재.
2. 숨겨진 초능력/혈통 없음.
3. 직업 또는 관계가 pivot의 실제 메커니즘에 기여.
4. Core cast가 결과를 대신 낚아채지 않음.
5. 다른 역사에서는 다른 중요도/결과가 가능.
6. 이 인물이 사라져도 세계가 작가 편의로 동일하게 굴러가면 FAIL.
7. pivot이 최소 하나의 관계/제도/생존 결과를 영구 변경.
