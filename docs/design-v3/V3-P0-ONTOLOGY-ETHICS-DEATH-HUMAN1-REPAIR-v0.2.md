# 1. Neural Continuity Lattice / NCL

## 1.1 What it is

합성기원 인간의 발생설계에 포함된:
- 미세 신경상태 telemetry,
- 의료 진단,
- 재활 calibration,
- 장기 신경질환 추적
용 분산 생체 인터페이스.

일반 시민도 `신경계 의료 인터페이스가 있다`는 사실 자체는 알 수 있다.

숨겨진 사실은:
> Mission Core가 이 장기 telemetry를 문명 Anchor와 L2 인격 seed에 사용할 수 있다는 것.

## 1.2 What it is NOT

- 매초 완벽한 뇌 복사본 아님.
- 영혼 파일 아님.
- 클릭 한 번으로 어제의 나를 복구하는 개인 backup 아님.
- 감정/의지 원격조종 장치 아님.
- 일상 police mind-reader 아님.

## 1.3 Capture fidelity

NCL은 장기간 축적된 dynamical model이다.

Author-facing fidelity hierarchy:

### N0 — health telemetry
- 신경건강/수면/손상/약물반응 등.
- 시민 의료영역.

### N1 — cognitive structural profile
- 언어/절차/장기 기억구조의 거친 모델.
- 재활/중증손상 보조 가능.

### N2 — Continuity Anchor grade
- 특정 Anchor window에서 개인의 autobiographical / procedural / affective state를 고밀도로 추정.
- CCAL restricted.
- 여전히 완벽하지 않음.

### N3 — Lived-instance seed
- N2 + 사회/관계/환경 상태로 L2 인격을 시작할 수 있는 수준.
- branch가 시작된 뒤에는 새 경험으로 독립적 인격이 됨.

Hard:
`N3 seed = 그 사람 본인이라는 metaphysical proof`가 아니다.

# 2. Anchor는 한 순간의 save file이 아니다

## 2.1 Anchor Window

문명 Anchor는 `202년 3월 4일 12:01:03` 같은 한 프레임이 아니다.

Working candidate:
**24~96시간 class의 synchronization window**.

이 기간 동안:
- 개인 NCL 모델,
- 관계그래프,
- 경제상태,
- 시설상태,
- 법/제도상태,
- 기록 provenance
를 정합화한다.

정확 시간은 Freeze 전 조정.

## 2.2 Why this helps story

Anchor가 window이므로 successor는 완벽한 과거복사가 아니다.

가능한 오차:
- 누군가는 2일 전 기억까지 있고,
- 누군가는 마지막 대화를 잃고,
- 소품/기록이 시간차를 보이고,
- 관계당사자 기억의 경계가 어긋남.

이것이 단순 continuity error가 아니라 author-rule로 관리된다.

## 2.3 Sparse capture

N2/N3급 Anchor는 비싸므로 드물다.

평소에는 N0/N1만 유지.

따라서:
- 아무 날짜로 rollback 불가.
- 개인별 최신 완전 backup 없음.
- Anchor 밖에서 일어난 죽음/관계/선택은 되살릴 수 없는 정보손실이 생김.

# 3. Branch Learning Return — 정상 경로

대부분 L2가 끝나면 사람 전체를 L1에 쓰지 않는다.

L1로 돌아가는 것은:
- 설비 failure pattern,
- 정책 취약점,
- 구조 우회법,
- 의료 protocol,
- 제도적 위험,
- 통계적 인간행동,
- novelty marker
같은 **비인격 또는 집단 수준 학습**이다.

개인-level memory delta는 원칙상 금지/필터 대상.

Memory residue는:
- lineage ID collision,
- 오래된 필터 결함,
- paired branch provenance 혼선,
- legacy recovery 흔적
때문에 드물게 새는 현상.

이 규칙으로 CCAL이 매번 사람을 덮어쓰는 omnipotent system이 되는 것을 막는다.

# 4. Person-State Succession / PSS — 매우 희귀한 비상 복구

## 4.1 Why it exists

Founders가 상정한 최악의 경우:
- 선체는 생존,
- 다수 신체도 생존,
- 그러나 장기 폭력/공황/신경독성/사회붕괴/정보오염으로 문명상태가 `recoverable but terminal` 판정을 받는 경우.

그들은 이를 `사람을 죽이고 교체`가 아니라:
> **동일한 시민을 더 이른 continuity state로 복구**
라고 해석했다.

후대 시민이 바로 이 전제를 공격한다.

## 4.2 Preconditions

PSS는 다음이 모두 맞아야만 기술적으로 가능하다.

1. 유효한 N2/N3 Anchor 존재.
2. 해당 사람의 원래 신체 또는 continuity-compatible하게 복구된 같은 신체가 존재.
3. 신경 lattice가 물리적으로 살아 있음.
4. shipwide recovery gate가 열림.
5. L0 power/thermal/medical capacity가 허용.

Hard:
- 다른 사람 몸에 임의로 쓰지 않는다.
- 신체가 완전히 소실된 사람을 즉석에서 출력하지 않는다.
- 30만 사망 후 30만 새 몸 생성 같은 복구는 불가능.

## 4.3 What PSS physically does

PSS는 생존한 synthetic-organic nervous system을:
- 깊은 torpor,
- 재생의학적 stabilization,
- NCL-guided neural reconsolidation
상태에 두고, 선택된 Anchor/lineage의 동역학 패턴으로 장기간 재구성한다.

그 과정에서:
- 현재 기억 일부가 사라질 수 있고,
- 이전 상태 memory trace가 남을 수 있고,
- 몸의 흉터/나이/손상은 그대로 남는다.

즉 정신상태를 되돌려도 **몸과 배는 과거가 아니다.**

## 4.4 Historical frequency

PSS는 branch마다 쓰는 기능이 아니다.

Working band:
- 항해 전체 **0~3회급** 후보.
- 많아도 손에 꼽을 수준.

너무 자주 쓰면:
- 시민사회 은폐 불가,
- 죽음 stakes 붕괴,
- 시스템 만능화
가 발생한다.

정확 횟수는 역사설계에서 확정.

# 5. Death / body reconstruction constraints

## 5.1 살아 있는 몸

PSS의 주 대상.

신체가 살아 있으므로 identity conflict가 가장 잔혹하다.

질문:
`현재의 나를 지우고 과거의 나를 쓰는 것은 치료인가 살인인가?`

이것은 작품이 정답강의하지 않는다.

## 5.2 뇌손상/임상사망 후 복구 가능한 몸

매우 제한적으로:
- 신체 구조가 보존되고,
- NCL lattice 일부가 살아 있고,
- 재생의학적 복구 가능
하면 successor reconstruction 후보가 될 수 있다.

이 경우 D3 reappearance가 가능하다.

하지만:
- 시간,
- 조직,
- 의료자원,
- Anchor quality
제약을 받는다.

## 5.3 신체 소실

Hard:
- 증발/소실/복구불가능 파괴 → routine PSS 불가.
- 별도 새 몸 제작은 일반 branch recovery의 일부가 아니다.

따라서 어떤 죽음은 정말로 다시 나타날 수 없다.

## 5.4 왜 `죽은 사람이 살아 있다`가 가능한가

독자가 본 죽음의 source는 여러 종류다.

1. L2에서 죽었지만 L1 counterpart는 살아 있음.
2. 다른 L2 lineage에서는 죽지 않음.
3. 복구 가능한 L1 신체에 rare PSS가 시행됨.
4. 기억자가 다른 상태의 죽음을 현재 사람에게 투사함.

이 네 가지를 섞되 author ledger에는 반드시 하나로 고정한다.

# 6. `Merge` 용어 수리

이후 작가 문서에서 가능하면 `merge` 하나로 모든 현상을 부르지 않는다.

분리:

- `Learning Assimilation` = 제도/기술/위험학습 병합.
- `Memory Residue` = 비의도 autobiographical fragment leakage.
- `Lineage Selection` = 다음 L2 seed가 어느 branch state를 기준으로 하는지 선택.
- `Person-State Succession` = 물리 신체의 희귀 NCL recovery.
- `Novel State Synthesis` = 여러 결과를 참고해 새 사회조건을 구성.

Hard:
**완전한 두 인격을 한 몸에 융합하는 표준기능은 없다.**

Act3 자체를 L2로 두면 PSS 없이도 같은 효과를 낼 수 있다.

Blueprint Freeze에서 두 안을 사건단위로 비교한다.

# 10. Historical near-discovery requirement

`아무도 몰랐다`는 설정을 폐기한다.

대신:

> **여러 사람이 조각을 봤지만 전체 구조를 증명하지 못했다.**

역사에 최소 다음 흔적을 둔다.

1. `수면/기억 동기화 스캔`을 둘러싼 오래된 의료윤리 논쟁.
2. 특정 세대의 `같은 흉터, 다른 기억` 도시전설.
3. 폐기된 감사보고서에 continuity compute의 비정상 열부하 기록.
4. 오래된 종교/점술 전승에 `두 번 산 사람` 모티프.
5. 보안/의료/시설 기록이 서로 다른 날짜를 가리킨 사건.

기관도 바보가 아니다.
다만 조각이:
- 다른 권한영역,
- 다른 세대,
- 다른 설명체계
에 흩어져 전체 원리를 못 만들었다.

# 12. Writer-facing fairness rule

독자가 후반 진실을 알았을 때 초반을 다시 보면 다음이 보여야 한다.

- 몸의 나이는 기억보다 미세하게 앞섬.

- 의료기록에는 설명되지 않는 NCL calibration gap.

- memory residue는 감정/감각 위주이고 완전한 데이터 dump가 아님.
- high-compute 기간 전후 열/전력 이상이 있음.

이 단서 중 최소 3종은 Act1~5에 자연스럽게 심는다.
