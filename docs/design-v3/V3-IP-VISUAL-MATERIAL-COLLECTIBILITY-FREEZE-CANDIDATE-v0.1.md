# 1. Selected visual philosophy

Meridian must feel like:
**a centuries-lived civilian civilization with layered repair history, ordinary domestic life, professional equipment, and selective high-recognition machinery — not a sterile spaceship set and not a mecha catalogue.**

Primary visual sources of identity:
1. people and how they move/work,
2. lived civic spaces,
3. recurring utility equipment,
4. material age/repair/provenance,
5. transformation across crises and settlement.

Merchandise potential is downstream only.

# 12. Anti-fake-world rule

Critical author/art rule:
**Experienced Meridian is a real lived civilization in moral, causal and subjective terms even though its human-scale environment is implemented through ultradense physical substrate.**

Outer Ark reveal changes implementation scale, not whether prior lives mattered.

Never authoritatively frame:
- citizens as NPCs,
- city as a fake stage,
- deaths as game deaths,
- outer hardware as the `real world` that nullifies the experienced world.

Act7 visual reveal should produce scale shock, not backstage debunking.

# 13. Anti-collectible-overdesign rules

Mandatory:
1. story/world use before visual/merch use,
2. HIGH memory budget small,
3. machine HIGH families small,
4. at least 3 recurring personal possessions persistence-only,
5. at least 1 recurring old machine/equipment retired because newer is simply better for the job,
6. ordinary-noise majority,
7. no rarity colors/grades,
8. no object grants authority by ownership,
9. no protagonist collecting every meaningful artifact,
