# V3 410-EPISODE DENSITY MAP v0.1

Status: `PACING HARNESS / NOT CANON`
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
Test whether ~410 episodes can sustain tension without rushing first-world attachment or bloating ontology exposition.

---

# 0. Global pacing rules

- Every 8~15 eps: visible turn/reward.
- Every 20~30 eps: at least 2 reward types.
- Every 25~35 eps: at least one real mystery or relationship payoff.
- No Act is allowed to function as pure setup.
- Act1 must contain concrete mini-survival/work wins before first major catastrophe.
- Act7~8 exposition must be interrupted by present physical/social stakes.
- Final ~60 eps: payoff/recontext > new mystery.

# 4. Red flags

FAIL if:
- first 15 eps have no concrete incident,
- Act2 geography/objective stays unchanged >12 eps,
- Act3 feels like Act1 rewrite,
- Act4 contains multiple reliable prophets,
- Act5 piles HUMAN + Arun + substrate truth simultaneously,
- Act6 is nonstop war spectacle,
- Act7 has 3 lore-heavy episodes in a row,
- Act8 becomes courtroom/philosophy lecture,
- Act9 introduces new hidden system layer,
- more than ~35 eps pass without a meaningful local mystery payoff.
