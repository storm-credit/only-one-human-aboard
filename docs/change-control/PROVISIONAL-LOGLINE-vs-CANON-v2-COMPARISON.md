# 3. "장르가 다르다"의 실제 원인 — 미스터리 실의 시작점

정본 Act1은 미스터리 실을 **가지고 있다.** 다만 시작이 늦다.

| 회차 | 미스터리 기여 |
|---|---|
| EP001~011 | **없음** — 가족/절차/생활세계 전용 |
| EP012 | 훅: 임상 기록의 평범한 `시드 완료` 필드. 아무도 이상하게 여기지 않음 (mundane primer) |
| EP013 | `The Seed Field` — attempted vs verified completed 구분. Seed가 의학으로 정상화됨 |
| EP017 | `Old Words, Ordinary Case` — **첫 실질 이상징후**. 구기록의 `synthetic-origin cognition` 기술 필드 |
| EP023 | 타 생활권 동일 문제 — 용어 불일치 확산 |
| EP024 | `The Audit Becomes Someone Else's Job` — 레거시 스키마 크로스워크가 정식 워크스트림화 |
| EP025 / EP028 | 감사 실이 Act2로 넘어갈 전방 경로 확보 |

Blueprint §17행 명시:
> "Readers must want to follow Maren/Ella/Noah as a family **before** the Natural-Origin mystery becomes the main engine."

즉 **의도된 설계**다. 그러나 결과적으로:

- 승인 원고 = **EP001~010**
- 첫 미스터리 프라이머 = **EP012**
- 첫 실질 이상징후 = **EP017**

사용자는 **미스터리 엔진이 점화되기 2화 전에** 읽기를 멈췄다.
"재미없다" 2회 + "장르가 다르다" 1회는 모두 같은 지점을 가리킨다.

CHG-049(EP001 플래시포워드 프롤로그)는 이 간극의 **증상 완화**였고, 원인은 미조치 상태다.
