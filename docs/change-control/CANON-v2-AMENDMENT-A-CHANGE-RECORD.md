# 1. Why Canon Is Being Reopened Narrowly

After the original Encyclopedic Canon v2 Freeze passed, an additional adversarial pass tested rare but civilization-scale ordinary scenes that were not explicit in the original final fuzz set.

Three bounded gaps were identified:
1. an ordinary election / executive turnover / court-hierarchy scene would require inventing governance mechanics,
2. found property / decommissioned strategic-equipment salvage lacked one explicit ownership rule,
3. human-subject research and medical aid-in-dying were sufficiently civilization-scale that they should not be invented ad hoc if ever used.

These are **not contradictions** in the frozen v2.
They are narrow completeness additions.

No change is proposed to:
- ontology,
- Seed,
- Reconstruction,
- population,
- existing quantitative ship/destination bands,
- support-character names,
- 7-Act architecture,
- POV,
- Reveal milestones,
- PR-H1,
- Human Settler,
- ending.

# 2. Superseded Parallel Modular Attempt

During the additional audit, a separate experimental modular set under `canon/v2/` was created.

Comparison against the official frozen v2 found that this modular attempt accidentally reintroduced older values/names in several places, including:
- older support-name candidates such as Toma/Mara/Sana/Imani/Leonie,
- different ship transfer-node / pressure-sector / water-buffer values,
- different arrival staging-orbit / first-year external-population bands.

Therefore:
**the experimental `canon/v2/` set is NOT promoted and must be treated as NON-CANON design history.**

Official baseline remains the existing monolithic frozen v2 plus this Amendment A.

# 3. Amendment A Scope

New Canon file:
`canon/CANON-v2-AMENDMENT-A-GOVERNANCE-ETHICS.md`

Adds only:

## A1. Election / Executive / Judiciary
- franchise 18+
- four-year shipwide general-election cycle
- mixed-member two-vote 선내의회
- Assembly size bounded ~120–180, preferred center ~150
- residential district seats + compensatory proportional list seats
- no Habitat/origin/profession/property vote weighting
- small 5–7-member Assembly-selected collective executive
- constructive no-confidence
- directly elected local councils without Habitat sovereignty
- ordinary first-instance → general appeal → high civic/rights/constitutional review architecture
- 시민항소원 = specialized high civic/admin rights appeal, not sole judiciary
- judges professionally qualified/nominated and democratically confirmed with long staggered high-court terms
- emergency cannot indefinitely suspend elections.

## A2. Found Property / Salvage
- finding ≠ ownership
- distinguish lost / apparently abandoned / private-enterprise / public-common / controlled / decommissioned / heritage material
- strategic/common equipment does not become private merely because disconnected/old/decommissioned
- first discovery of arrival resource does not create sovereignty.

## A3. Human-Subject Research Ethics
- informed voluntary consent for interventional/recruited living-subject research unless narrow lawful waiver
- independent ethics review for more-than-minimal risk
- data minimization / protected-domain separation
- withdrawal rules
- no Civic Floor coercion
- **Amara has no research duty because she is unique**.

## A4. Medical Aid-in-Dying
- narrow contemporaneously competent adult pathway
- serious irreversible/incurable condition + enduring intolerable suffering
- independent second clinician / capacity review where needed / alternatives / reconfirmation / oversight
- disability, poverty, unemployment, housing scarcity or isolation alone do not qualify
- no proxy/guardian/AI/old directive active authorization for a currently incapable person
- old directives may still govern refusal/withdrawal of burdensome treatment under ordinary end-of-life law.
