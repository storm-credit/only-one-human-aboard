# 8. Social-Network Diversity Guardrails

Core characters must not all share:
- same income class,
- same household form,
- same hobby,
- same political circle,
- same attitude to arrival,
- same number of friends,
- same work schedule.

Package F intentionally separates:
- family-centered vs friend/community-centered life,
- office/civic vs field/shift work,
- stable housing vs recovery/young-adult transition,
- structured vs spontaneous leisure,
- more/less permissive personal AI habits.

---

# 9. Recurring Supporting Character Promotion Rule

A support candidate should gain stable name/card when at least one is true:
1. appears meaningfully ≥2 times,
2. carries an independent relationship with a core character,
3. creates return/recognition pleasure,
4. represents a recurring workplace/community continuity that cannot be served by a role label,
5. changes over time in a way readers can recognize.

Do NOT name every:
- reviewer,
- clerk,
- doctor,
- teacher,
- neighbor,
- worker,
- journalist.

`More names` is not encyclopedia completeness.
