# 3. Settlement World P

Status:
- existence/type core = `CANON-V1`
- PLAN-H1 environmental details = `V2-CANDIDATE`
- exact numerical values = `C2-ELASTIC`.

Working center candidates:
- orbit ~0.50–0.54 AU; center ~0.52 AU,
- orbital year ~150–160 Earth days,
- gravity ~0.97g,
- day ~29.5h,
- obliquity ~14°,
- abundant stable surface liquid water,
- cool-temperate overall,
- near-Earth-order total pressure,
- oxygen fraction low enough that long-duration unassisted breathing is unsafe,
- outdoor work uses breathing support rather than full pressure EVA in normal conditions.

Exact atmospheric fractions are NOT frozen.

## What `habitable` means
The planet offers:
- real gravity,
- open terrain,
- weather,
- abundant water,
- tolerable pressure,
- large long-term expansion space.

It does NOT mean:
- Earth clone,
- immediately breathable biosphere,
- ready-made agriculture,
- no weather/geology/biosafety/rescue risk.

## First settlement-site logic
A site must combine:
- water,
- terrain stability,
- landing/access,
- resource potential,
- communications,
- low hazard,
- future expansion,
- biosafety.

No single paradise valley solves all constraints.

# 8. Comparative Advantage Table

| Node | Best early advantage | Weakness / bottleneck |
|---|---|---|
| Meridian | mature city / precision / medicine / education / governance | finite redundancy, aging systems, cannot expand mass freely |
| Orbit / resource nodes | low-g resource/logistics/construction access | thin civilian/medical depth, radiator/power/logistics dependence |
| Surface | gravity, water, open long-term space, later large population | low O2, immature infrastructure, weather/rescue/biosafety/logistics |
| New habitat | future custom-built orbital city potential | enormous time/industry/material requirement |

No node is the universal best answer.

# 9. ISRU Ladder

Early local outputs:
1. water,
2. oxygen/chemical feedstocks,
3. shielding/aggregate/silicate mass,
4. basic metals/structural components.

Precision-development ladder:
1. Meridian-built precision capital,
2. local assembly using local bulk + imported precision components,
3. growing local precision manufacturing,
4. mature independent industrial ecology.

This takes years/decades.

Hard:
`asteroid → CPU` shortcut forbidden.
