# 1. Functional Object Classes

| Class | Meaning | Examples | Plot guardrail |
|---|---|---|---|
| O1 — Ordinary Cycle Goods | common consumable/recyclable goods | food containers, hygiene consumables, simple school goods, common textiles | normally unnamed/non-clue |
| O2 — Durable Personal/Household Goods | repairable personal/home goods | cookware, furniture modules, terminals, instruments, hobby gear, tools | can accrue memory without becoming magic relic |
| O3 — Professional / Controlled Equipment | specialist tools/equipment | medical tools, water diagnostics, Outer Works gear, structural tools, emergency equipment | training/custody may matter; misuse possible |
| O4 — Strategic Commons / Enterprise Assets | high-value system/industrial capital | reserve pumps, radiator modules, precision fabrication/metrology, redundancy systems | not casual private collectible; Act5 arrival tradeoffs possible |
| O5 — Heritage / Provenance-Rich Objects | objects valued for historical/family continuity | Earth-origin goods, founding artifacts, family heirlooms, local historical objects | provenance/social meaning, not superpower |

One item may change classes over time.

# 2. Provenance States

| State | Meaning |
|---|---|
| P-A | documented provenance / strong chain |
| P-B | attributed provenance / strong context but incomplete chain |
| P-C | restored/composite historical object with substantial replacement |
| P-D | later replica/reproduction |
| P-E | uncertain/disputed provenance |

These are evidence states, not RPG rarity grades.

A P-C family object may matter more emotionally than a P-A museum artifact.

# 4. Ordinary Repair Culture

Normal:
- modular replacement,
- repair/remanufacture,
- local fabrication,
- visible repaired goods,
- replacement for fashion/safety/efficiency/convenience,
- long-lived professional equipment where certification/compatibility favors continuity.

Not normal:
- everyone ideologically worships repair,
- every old object is expensive,
- all new goods are wasteful/immoral.

# 5. Personal Interfaces

Direction:
networked device ecosystem, not one magical hologram.

Properties:
- layered authentication,
- work/household/public permission separation,
- devices can fail/lose network,
- emergency alert paths are resilient,
- children have age/guardian-dependent permissions,
- protected records require more than casual possession.

Hard:
- no adult origin scanner,
- no omniscient personal assistant,
- no one interface grants all records.

# 9. Weapons / Public-Safety Boundary

Closed-city externality:
high-penetration/high-energy interpersonal weapons create risk to people and critical systems.

Direction:
- ordinary civilian life does not assume widespread high-energy firearm culture,
- prevention/access control/barriers/separation/de-escalation prioritized,
- escalating public-safety force options exist for serious threats,
- specialized higher-force equipment is tightly stored/authorized/reviewed,
- dangerous industrial tools remain real and potentially misusable.

Hard:
- no magical perfectly safe stun weapon,
- no autonomous system independently determines guilt and applies open-ended lethal force,
- no claim that restricting weapons eliminates violence.

Exact catalog remains final legal/material micropass if scenes require it.

# 17. Random Object Test Template

When inventing/using an object, ask:
1. Which O-class is it?
2. Is its provenance relevant or irrelevant?
3. Who owns/custodies it?
4. Is repair/replacement ordinary?
5. Is access/training required?
6. If dangerous, what work/legal controls apply?
7. Is it actually a narrative device, or only world texture?
8. Does it accidentally create forbidden origin/authority technology?

If question 8 = yes, reject.
