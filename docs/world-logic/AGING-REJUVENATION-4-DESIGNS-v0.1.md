# A-A — Injury Repair, Biological Age Preserved

## Core
Recovery Map은:
- connectomic topology
- functional relationship
- lesion repair target
을 제공하지만 `젊은 시절 전체 분자상태`를 저장하지 않는다.

Reconstruction은 **현재 살아 있는 neural anchor의 나이/상태를 기준으로 손상만 복구**.

### Strength
- 가장 단순.
- old scan으로 30세 롤백 금지.
- demographic/death logic 안정.

### Weakness
미래의학이 장기/세포 노화를 거의 못 고친다는 인상 가능.

### Verdict
`STRONG BASE`

---

# A-B — Partial Healthspan Extension, Neural Continuity Limit

## Core
미래의학은:
- 암
- 심혈관
- 장기교체
- senescent cell 일부
- 조직 재생
을 크게 개선.

하지만 살아 있는 사람의 **뇌 전체를 더 젊은 상태로 되감는 것**은 다른 문제.

이유:
- 기억/성격/학습도 현재 neural state에 물리적으로 얽힘.
- 광범위한 rejuvenation/rewrite가 현재 anchor를 너무 크게 바꾸면 continuity risk.
- Recovery Map은 `damage repair`이지 `time reversal blueprint`가 아님.

### Strength
- 고도의학과 유한수명 동시 가능.
- 늙음은 느려져도 사라지지 않음.

### Weakness
정확히 어디까지 rejuvenation 가능한지 경계설명 필요.

### Verdict
`CURRENT BEST SUPPORT LAYER`

---

# A-C — Full Rejuvenation Possible But Capacity-Rationed

## Core
기술적으로 젊어질 수 있으나 엄청난 자원 때문에 일부만 가능.

### Strength
계급/자원 사건 강함.

### Fatal Risks
- 부자 불멸사회가 작품의 더 큰 설정이 됨.
- 30만 capacity 정치가 노인 vs 아이 전쟁으로 고정.
- `왜 C8 부모/과거 natural-origin은 안 살렸나` 추가구멍.

### Verdict
`REJECT AS BASE`

# A-D — Old Scan Age-Reset Creates New/Derived Person

## Core
30년 전 scan을 이용해 젊은 neural body를 만들 수 있으나,
현재 사람의 연속 복구가 아니라 `Derived Person`.

### Strength
철학사건 생성.

### Weakness
무한 복제/젊은 복사본 문제가 다시 열림.
- Derived Person story가 메인 설정을 삼킴.

### Verdict
`DO NOT USE AS ROUTINE TECHNOLOGY`

특수 불법실험 사건 가능성도 Freeze 후 별도검토.

# 1. Minimum Rule

> **Continuity Reconstruction repairs discontinuous damage relative to the current surviving neural anchor. It does not restore a person to an earlier chronological version.**

Recovery Map stores enough to infer:
- missing connections
- regional functional organization
- learned structure at map time

but not a magic full-body/brain molecular rewind state.

---

# 2. Why Old Maps Do Not Make You Younger

## Rule A — Current Anchor Dominates
정상 reconstruction에는 current surviving neural substrate가 필요.

수년 전 map은:
- missing network guidance
- comparison baseline
으로 쓰이지만,

현재 anchor의:
- later memories
- later learning
- aging state
을 지우고 과거 map으로 대체하지 않음.

## Rule B — Map Is Not Full Temporal Snapshot
Full continuity scan이라는 옛 표현을 쓰더라도 실제 데이터는:
- connectomic recovery model
- key state constraints
이지 모든 세포/분자의 완전 복제본이 아님.

## Rule C — Too Much Replacement Breaks Normal Restoration Category
현재 anchor를 버리고 old map으로 전체 뇌를 새로 만들면 정상 Reconstruction이 아니라 별도 Derived Person 문제.

routine medicine으로 허용하지 않음.

# 3. Body Rejuvenation

가능:
- 장기 교체/재생
- 혈관치료
- 암 예방
- 대사/면역 개선
- 일부 노화세포 제거
- 보철/재건

불가능/미완성:
- 뇌 전체를 젊은 시절로 안전하게 reset
- 무제한 반복 rejuvenation
- 현재 인격을 보존한 채 모든 누적 노화를 완전히 제거

따라서 건강수명은 현대보다 길 수 있지만 불멸 아님.

---

# 4. Lifespan Candidate Band

정확 수치 NOT CANON.

Story sanity candidate:
- ordinary effective lifespan: `~90~120 years`
- healthy active years significantly extended
- exceptional cases: `120~130+` possible

중요:
- 150~300년 일반수명은 현 1순위 아님.
- Restoration은 accident survival을 높이지만 chronological aging 자체를 0으로 만들지 않음.

이 범위면:
- M 60대도 충분히 현역
- 14년 후 노화 체감 가능
- 100년 전 natural-origin exceptions는 대부분 현재 active가 아닐 수 있음

---

# 5. Aging And Finality Culture

사망에는 최소 세 유형 존재 가능:

1. **Acute repairable injury**
   - neural anchor survives
   - reconstruction possible

2. **Catastrophic anchor loss**
   - true death possible

3. **Progressive aging / systemic decline**
   - 반복수리로 무한 회복하지 못함
   - 어느 시점엔 reconstruction benefit/viability 감소

따라서 One-Life / Finality Networks가 실제 의미 있음.

고령 시민이:
`다음 큰 사고 때 더 이상 reconstruction하지 말 것`
을 선택하는 사건도 자연스러움.

---

# 6. Population Consequence

Restoration은:
- 사고로 인한 permanent exit 감소
하지만
- aging exit를 제거하지 않음.

따라서 stable 300k society에서 annual permanent turnover few-thousand order가 여전히 가능.

Demography doc와 정합.

---

# 7. Natural-Origin Compatibility

Seeded / natural-origin 모두 현재 reconstruction 가능.

중요:
Seeded cognition이 modern reconstruction에서 특별한 필수키가 아님.

역사적으로 Seed가 early continuity technology와 compatibility benefit을 제공했을 수 있으나,
현대 mapping이 발전해 차이는 임상적으로 decisive하지 않음.

따라서 C8가 병원에서 자동발견되지 않음.

# 9. Red Team

## RT-AG-01 — 장기재생이 되는데 뇌 노화만 특별취급 아닌가?
### Answer
뇌도 치료 가능.
금지하는 것은 `전부 젊은 과거 상태로 되감기`.

점진적 치료/건강수명 연장은 허용.
그러나 현재 neural pattern 자체가 기억/인격이므로 전체 replacement는 continuity 문제.

Verdict:
`PASS CANDIDATE`

---

## RT-AG-02 — Recovery Map가 connectome이면 기억도 저장하는 것 아닌가?
### Answer
부분적으로 recovery에 필요한 learned constraints를 포함할 수 있음.
하지만 standalone executable mind / complete molecular snapshot는 아님.

현재 anchor가 없으면 정상 restoration 불가라는 RB-B rule 유지.

Verdict:
`PASS`

---

## RT-AG-03 — 부자가 반복 장기교체로 150년 살 수 있지 않나?
### Answer
exceptional longevity 가능성 자체는 허용.
하지만 brain/systemic aging + reconstruction viability가 hard limit.

정확 maximum을 법처럼 고정하지 않음.

Verdict:
`PASS CANDIDATE`

---

## RT-AG-04 — 왜 오래된 unseeded 사람을 rejuvenation 안 했나?
### Answer
모두가 무한 rejuvenation 가능하지 않음.
과거 exceptions는 자연사/anchor loss/개인 finality로 사라질 수 있음.

현재 C8가 `마지막으로 남은 운명적 혈통`이 아니라 demographic current state 유지.

Verdict:
`PASS`
