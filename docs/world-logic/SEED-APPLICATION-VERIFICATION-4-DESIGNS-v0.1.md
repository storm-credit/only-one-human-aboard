# 1. Functional Canon Rule

A citizen is classified as confirmed Seeded-Origin only when the prenatal record shows **successful Seed completion**, not merely appointment/order/attempt.

Successful completion requires contemporaneous evidence that the generated developmental prior altered the targeted early network-formation trajectory within the critical window.

This evidence is stored as provenance metadata/clinical completion status.

---

# 2. What Is Observed During Verification

Do NOT define a magical `consciousness meter`.

The clinic monitors a bundle of treatment-specific developmental responses, e.g. future-tech equivalents of:
- network maturation dynamics
- evoked-response structure
- molecular/growth-signal response
- expected connectomic developmental trajectory

No single signal equals `a soul`.

The system verifies **treatment effect**, not consciousness itself.

---

# 3. Why Adult Origin Cannot Be Read Directly

The successful treatment changes initial developmental conditions.
Over decades:
- plasticity
- learning
- aging
- injury/repair
- normal variation
rewrite network detail.

The transient treatment-response signature is not a permanent unique adult marker.

Adult brains of Natural- and Seeded-Origin citizens overlap strongly in normal structural/functional variation.

Therefore:
- modern medicine can treat/map both
- provenance proves origin
- adult scan alone cannot classify with certainty

---

# 4. Failure Modes

Possible prenatal outcomes:
1. successful Seed completion
2. first-attempt incomplete → successful repeat within window
3. incomplete/unverified course → special medical follow-up
4. deliberate refusal → no Seed attempt

Important:
An incomplete/unverified course is **not automatically entered as Seeded**.

If the critical window closes without verified completion, the provenance record reflects that ambiguity/no-completion.

---

# 5. Why Current Hidden Natural-Origin Count Can Still Be One

Modern prenatal records are highly reliable because:
- successful completion was verified contemporaneously
- ambiguous cases are labeled and can be included in the historical audit separately
- full unseeded/failed-completion cases are rare and reviewable through provenance

The Count audit does not simply run:
`Seed appointment = yes/no`.

It reconciles:
- completion status
- treatment-window records
- legacy origin definitions
- current alive registry

Thus an unnoticed failed Seed is not a plausible hidden second Natural-Origin by default.

# 9. Red Team

## RT-SV-01 — If fetal monitoring is this advanced, why can't adult scans classify origin?
Treatment verification observes a transient response to a known intervention while it happens. Adult classification tries to infer a decades-old initial condition after massive plasticity and overlap. These are different inference problems.

Verdict: `PASS STRONG`

## RT-SV-02 — Doesn't verification make Seed deterministic personality engineering?
No. It verifies that the developmental prior influenced target early-network formation, not the later person's memories/personality/choices.

Verdict: `PASS`

## RT-SV-03 — Could a clinic falsify completion and create hidden Natural-Origin citizens?
Fraud is logically possible but not systemic. The core story does not rely on perfect incorruptibility; audit trails, multiple telemetry channels and later data integrity checks make large-scale unnoticed falsification implausible. A one-off fraud would be a different plot and must not be introduced without reopening the count premise.

Verdict: `PASS CANDIDATE`

## RT-SV-04 — What about historical verification before standards matured?
Historical ambiguous/deceased cases can exist. The current audit separately reviews active ambiguous cases. The factual present count is one.

Verdict: `PASS`
