# 3. Rare Unseeded Rate Needed

현재 active natural-origin expectation λ를:
`~0.5~2`

범위로 두면 정확히 1명이 존재하는 것이 특이하지만 비정상적이지 않다.

Recent cohort가 160k~350k일 때 필요한 full-window Seed refusal / true unseeded birth rate는 대략:

`1 per ~80,000 to 700,000 births`

가장 편한 중앙 후보:

> **대략 수십만 출생당 1회**

예:
- annual births ~3,000
- active cohort window ~90y
- births ~270,000
- unseeded rate ~1 / 250,000

이면 expected active natural-origin:
`λ ≈ 1.08`

Poisson에서 exactly one probability는 λ≈1 부근에서 약 37%.

λ 범위:
- 0.5 → P(N=1) 약 30%
- 1.0 → 약 37%
- 1.5 → 약 33%
- 2.0 → 약 27%

즉 `현재 정확히 한 명`은 우주가 맞춘 숫자일 필요가 없음.
