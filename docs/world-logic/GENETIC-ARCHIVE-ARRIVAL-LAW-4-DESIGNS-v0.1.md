# 1. Genetic Archive Canon Rules

## LOCK CANDIDATE
The archive primarily stores/reconstitutes:
- gametes
- germline/stem-cell line diversity
- reference genomes

It is NOT a population of sleeping conscious humans.

## Cognitive-Origin Rule
A future child conceived using departure-era germline material can still be:
- Seeded-Origin if prenatal Seed is applied
- Natural-Origin if full Seed window is declined

Therefore:
`old DNA = real human` is scientifically/legally false under current world rules.

This is important Reveal protection.

---

# 2. Why Keep It If Population Is 300k?

300k is large enough to avoid tiny-founder-population collapse, but the archive still preserves:
- broader Earth ancestry diversity
- rare alleles
- immune diversity
- lineages lost during voyage
- reproductive contingency after disaster

It can also be used gradually over generations rather than waiting for arrival.

Thus archive is a **diversity reserve**, not a replacement population.

# 4. Exact Conflict Candidate

Working legal problem:

> **The destination settlement registry inherits an early-voyage `Human Settler` class whose archived definition cross-references Natural/Bio-Origin Cognition, while modern Civic Law recognizes all current civic persons regardless of developmental origin.**

If translated literally:
- Amara maps automatically into the narrow legacy class.
- most citizens require another classification/manual equivalency.

But this does NOT mean:
- they lose ship citizenship
- Amara owns the colony
- Amara can command the ship

It means transition authorities must decide whether:
1. `Human Settler` is read by historical technical definition
2. or functionally/equitably mapped to `current civic person`
3. or old categories are abolished and replaced
