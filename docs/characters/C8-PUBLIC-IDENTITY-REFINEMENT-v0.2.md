# 1. Re-identification Logic

Official audit releases only:
- current civic persons ~300k
- active natural-origin count = 1

It does NOT release name.

However society already contains lawful/public fragments:
- old public reporting on natural-development debates
- historical court/policy records with partially identifying context
- community archives
- family interviews/activism from decades earlier
- public age/residence/career facts

No single source proves identity.

But after `count=1`, citizens/journalists/researchers can combine fragments and narrow candidate list.

This is a normal **uniqueness / re-identification** problem.

# 3. Why Public Guessing Is Not Immediate Proof

Historical records are noisy:
- some refusals were partial/delayed Seed, not full-window unseeded
- some records anonymized
- some people died
- some moved/changed names
- some cases lacked complete provenance

Therefore public speculation can produce:
- C8 as strong candidate
- several false candidates
- wrong guesses about C8 children/relatives

Official identity still requires protected provenance audit.
