# Character Missing-Gaps — 4-Design Pack v0.1

Status: `DESIGN COMPARISON / PROVISIONAL RECOMMENDATIONS / NOT CANON`

Purpose:
Character Bible Consolidation에서 남은 `주제와 무관한 삶 / 직업 / 장기목표`를 채운다.

원칙:
- 모든 직업이 main mystery에 편리하게 연결되면 실패.
- 모든 가족문제가 Continuity/Origin 문제면 실패.
- 직업은 14년 동안 승진/이직/실패/이주가 가능한 ordinary career여야 함.
