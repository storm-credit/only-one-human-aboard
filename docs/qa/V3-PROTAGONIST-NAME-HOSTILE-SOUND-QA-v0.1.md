# Test 1 — Can the given name carry hundreds of dialogue repetitions?

## 다니엘
Pros:
- immediately readable,
- natural in command/family/intimate/professional scenes,
- neutral enough to survive tonal changes.

Risk:
- common enough that prose must not rely on name alone for distinctiveness.

Verdict: **5/5**.

## 요나스
Pros:
- memorable,
- calm/technical tone,
- not heroic.

Risk:

Verdict: **4.5/5**.

## 토마스
Pros:

- ordinary-worker credibility.

Verdict: **4.5/5**.

## 엘리엇

# Test 2 — Full-name mouthfeel in Korean prose

Repeated forms tested conceptually:
- `다니엘 마레크가 말했다.`
- `마레크는 대답하지 않았다.`
- `다니엘, 거기서 손 떼.`

Result:
**다니엘 마레크 = very stable 3+3 rhythm.**

`요나스 켈러`:
- good 3+2 asymmetry,
- slightly clipped surname ending gives stronger technical/cool tone.

`토마스 나바로`:
- smooth 3+3,
- warm open vowels,
- slightly more noticeable cultural sound.

`루카스 베르너`:
- clean 3+3,
- reads more conventionally protagonist-coded.

`엘리엇 마레크`:
- clean but polished.

Ranking:
**Daniel Marek > Jonas Keller ≈ Thomas Navarro > Lucas Werner > Elliot Marek.**

# Test 4 — Family scenes

The protagonist must be believable as:
- son,
- younger brother,
- uncle,

not only as an engineer.

`다니엘` and `토마스` are strongest ordinary-family names.
`요나스` remains believable but slightly more character-distinct.
`루카스` works but carries more lead-character energy.
`엘리엇` slightly distances the character toward polished fiction tone.

- 요나스 켈러: low attention; relatively coherent-sounding but not plot-significant.
- 토마스 나바로: recognizable regional surname flavor somewhat stronger.
