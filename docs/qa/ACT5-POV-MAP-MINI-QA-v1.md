# 3. Specialist POV = Exposition Camera Risk

Hard test for each Tier-3 episode:
Would the episode still matter if all technical explanation were shortened by half?

Expected answer:
YES, because each owns a choice/cost:
- Outer Works Lead chooses repair/fabrication/labor tradeoffs.
- Registrar must place real households/workers into provisional statuses.
- Asset Coordinator converts a system that cannot easily be restored.
- Survey Lead accepts bounded confidence instead of perfect certainty.
- Ordinary Claimant gains equality but still waits under material capacity queue.

If prose leaves only technical definitions, execution has failed the map.

Verdict:
`PASS`
