## Why v0.3

The user explicitly asked whether weapons, relics, equipment and collectible/heritage objects should be part of the setting bible.

Audit result:
**YES.**

A ~450-year generation-ship civilization cannot be reference-grade complete if its object culture, weapon/public-safety boundary, repair ecology, heirlooms, museums, collectibles, salvage and strategic heritage assets are left to scene-by-scene improvisation.

However, renumbering the already-stabilized A~I package layout again would create avoidable documentation churn.
Therefore material culture is added as an independent cross-cutting completion package:

**Package C-M — Material Culture / Equipment / Relics Bible**

It is a mandatory gate item even though its code is nested beside Package C.

# Material Culture Completion Tests

Package C-M is not complete merely because a list of gadgets exists.
It must pass at least these tests.

## MC-T1 — Random Citizen Pocket / Bag Test
Pick several citizens of different age/class/profession.
Can the setting say what they plausibly carry/use without inventing a new world rule?

## MC-T2 — Random Home Object Test
Can a kitchen, bedroom, school bag, hobby shelf and work locker be described coherently?

## MC-T3 — Crime / Weapon Boundary Test
If a citizen threatens someone, steals dangerous work equipment, or illegally possesses a restricted weapon, are authority/custody/risk rules already known?

## MC-T4 — Reconstruction Heirloom Test
If a singular heirloom changed hands during a death/Reconstruction interval, can property and family consequences be resolved from existing rules?

## MC-T5 — Earth Relic Provenance Test
Can the setting distinguish original / attributed / restored composite / replica / disputed provenance without `old = magic` logic?

## MC-T6 — Museum / Private Collector Test
Can an important object be privately owned, loaned, sold, inherited, conserved or contested without inventing the institution on the spot?

## MC-T7 — Strategic Heritage Asset Test
Can one old working machine be historically important and operationally necessary without collapsing into a fake binary or universal MacGuffin?

## MC-T8 — Ordinary Noise Test
Across random scenes, are most objects ordinary rather than clue-bearing?

## MC-T9 — Collection Pleasure Test
Does the reader gain recognition/provenance/return/completion pleasure without explicit inventory mechanics?

## MC-T10 — Genre Drift Test
Does equipment depth remain social/living-world SF rather than military gear progression?
