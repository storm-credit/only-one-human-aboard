# 2. Closure criteria

Reference research may close only if all are true:

1. Reference sources span multiple media families.
2. Practical/mechanical/architectural assets include real functional anchors.
3. No one entertainment IP is needed as a final design template.
4. Core-cast same-face risk has a parameterized differentiation scheme.
5. Machine families have role-derived silhouette rules.
6. Major civic zones remain distinct without color-biome coding.
7. Domestic/family life is referenced, not only industry/public corridors.
8. Med/HUMAN care is referenced without sterile-lab/sacred-child drift.
9. Destination is process-synthesized, not copied from one Earth location.
10. Low-O2 breathing support is scientifically repaired.
11. Collectibility is based on lineage/use history rather than rarity/power.
12. Original Meridian-native synthesis boards exist without external-IP shorthand.
13. Remaining uncertainty can be tested by original concept art rather than solved by collecting more references.

**PASS — STOP BROAD COLLECTION.**
