---

# 1. Four collection strategies

## A — One prestige reference per category
Example:
- one show for characters,
- one game for craft,
- one film for backgrounds.

Strength:
coherent quickly.

Failure:
Derivative risk is extreme; one franchise's visual DNA leaks across the project.

Verdict: **REJECT.**

## B — Large moodboard accumulation
Collect hundreds of visually attractive images, curate later.

Strength:
wide exploration.

Failure:
- aesthetic hoarding,
- weak provenance,
- impossible source dominance tracking,
- attractive but story-irrelevant references win.

Verdict: **REJECT AS PRIMARY.**

## C — Function-question collection
Each search begins from a Meridian design problem:
`how should a narrow-space inspection machine attach?`
`how does a logistics worker's clothing differ from medical staff without uniforms?`
`what makes a transfer hub recognizable without color coding?`

Strength:
references answer actual story/world functions.

Weakness:
can become visually conservative.

Verdict: **SELECTED BASE.**

## D — Function + recognition + lineage hybrid
Start with C, then add:
- one silhouette/readability source,
- one material-history source,
- one real-world functional source,
- one transformation/collectibility check.

Strength:
keeps realism but creates memorable IP identity.

Verdict:
# **SELECTED PRIMARY METHOD.**

# 2. Initial research findings

The first research pass produced a deliberately mixed pool:

Character/readability:
- Arcane/Fortiche — body-type/style exploration and arc-linked silhouette change,
- Spider-Verse/Sony Imageworks — explicit visual-language and shape/line readability,
- Andor costume design — job/backstory/material wear drives individual clothing,
- Planetes — working adults remain visually ordinary in space.

Craft/function:
- Hardspace: Shipbreaker — same class/assets remixed into role-readable variants,
- NASA on-orbit servicing — dexterous robotic arms and servicing architecture,
- The Expanse production design — form derived from operational requirement and technology ancestry.

Background/material:
- Alien: Isolation — strong production constraint applied across architecture/tools/materials,
- Andor/Ferrix — industrial community retains individual material histories,
- Planetes — mundane worker spaces and ordinary life remain central.

These are principle sources, not appearance templates.

# 3. Blindspot attacks

## B01 — Same-face attractiveness convergence
Risk: **CRITICAL.**

Generative/concept workflows often converge toward:
- similar narrow jaw,
- similar nose,
- symmetrical attractive faces,
- age shown only by wrinkles,
- women differentiated by hair only.

Repair:
- mandatory grayscale/same-clothes/bald-or-covered tests,
- face geometry matrix controls prompt/design,
- at least 3 deliberately non-glamorous ordinary adult faces among core cast,
- reject image even if beautiful when face family collides.

Gate: HARD.

---

## B02 — Reference collage = plagiarism smell
Risk: **CRITICAL.**

Failure:
face from A + coat from B + ship from C can still look like a collage if iconic details remain.

Repair:
- extract principles, not parts,
- rewrite each selected principle in Meridian functional language before concept generation,
- HIGH element uses 3+ sources / 2+ media families,
- no exact iconic profiles/logos/palettes.

Gate: HARD.

---

## B03 — One source silently dominates
Risk: **HIGH.**

Hardspace could dominate machines; Andor could dominate clothing; Alien could dominate interiors.

Repair:
- single-IP influence cap ~20% of HIGH decisions,
- real-world anchor mandatory where function matters,
- each track must show source diversity in ledger.

Gate: HARD.

---

## B04 — Collectibility becomes loot design
Risk: **CRITICAL.**

Failure:
models become rarity tiers, upgrades and power ladders.

Repair:
collect through:
- model genealogy,
- tradeoffs,
- repair history,
- local modification,
- ownership wear,
- successor design.

Never:
- legendary/epic,
- S-tier,
- new=better,
- plot-important=rare.

Gate: HARD.

---

## B05 — Everything returns, so the world feels scripted
Risk: **HIGH.**

Repair:
- tracked HIGH/MED elements remain minority,
- >=30~40% of sampled ordinary visual props explicitly tagged `NO PAYOFF`,
- include forgotten/replaced shop signs, clothes, tools, toys, containers.

Gate: HARD.

---

## B06 — Industrial references swallow civilian life
Risk: **HIGH.**

Failure:
Old Works/craft become memorable; Midring/Garden/Med become generic.

Repair:
next collection batch prioritizes:
- transit,
- domestic courtyards,
- school routes,
- hospital teaching/recovery spaces,
- ordinary restaurants/services,
- parks/engineered-open spaces.

Gate: P1 ACTIVE.

---

## B07 — Mecha franchise drift
Risk: **CRITICAL.**

Repair:
- service craft function first,
- humanoid armed frames prohibited as default,
- no ace pilot lane,
- no protagonist signature combat machine,
- machine closeups must show access/tool/cargo logic more often than heroic front poses.

Gate: HARD.

---

## B08 — Character props become gimmicks
Risk: **HIGH.**

Repair:
- at least 3 core-character recurring possessions remain ordinary/no-reveal to the end,
- object meaning follows character action; never substitutes for it,
- no every-character signature gadget requirement.

Gate: HARD.

---

## B09 — Role coding becomes caste/faction coding
Risk: **HIGH.**

Failure:
security always dark, medicine always white, logistics always orange, Old Works residents all same workwear.

Repair:
- role identifiers detachable/task-specific,
- private clothing independent,
- citywide common standards recur,
- job affects wear/tool placement, not entire identity.

Gate: HARD.

---

## B10 — Ethnicity/name becomes visual stereotype
Risk: **CRITICAL.**

Repair:
- surname never auto-selects skin tone, hairstyle or costume,
- centuries-mixed Meridian allows independent phenotype/cultural choice,
- no ethnic costume coding unless specific personal/family context later supports it.

Gate: HARD.

---

## B11 — H-A/H-B visual spoiler
Risk: **HIGH.**

Failure:
reader instantly sees alternate-world costume skins.

Repair:
- differences are lived-history artifacts only,
- 3~5 high-salience deltas across cast,
- no palette swap or face swap.

Gate: HARD.

---

## B12 — Outer Ark references spoil the ontology
Risk: **HIGH.**

The project team may collect physical Outer Ark reference art, but reader-facing marketing/early concept use could reveal that experienced Meridian is not the physical ship.

Repair:
- reference library tags `SPOILER CLASS: OUTER ARK`,
- no early cover/key art using true Outer Ark cross-section before reveal strategy is decided,
- public-facing art package separated from author reference package.

Gate: HARD.

---

## B13 — Destination becomes new visual franchise at Act9
Risk: **HIGH.**

Repair:
- Act9 vehicles inherit existing interfaces/lineage,
- new HIGH machine families <=2,
- settlement architecture inherits Meridian fabrication/service language,
- environment creates new weather/material conditions, not total design reset.

Gate: HARD.

---

## B14 — Production reference links rot
Risk: **MEDIUM.**

Repair:
ledger stores:
- source title,
- creator/studio,
- page title,
- URL,
- short principle summary,
- retrieval date.

Do not depend on one image URL to explain a design decision.

Gate: PROCESS.

---

## B15 — Copyright/reference-asset management
Risk: **HIGH.**

Repair:
- repo stores analysis/URLs/bibliographic locators by default,
- do not bulk mirror copyrighted art into repository,
- original Meridian concept art stored separately with provenance,
- reference images are study inputs, not assets for publication.

Gate: HARD.

---

## B16 — Visual design outruns plot/reveal authority
Risk: **HIGH.**

Repair:
reference phase may NOT:
- create a new faction,
- create a new major technology,
- change HUMAN meaning,
- create an extra Act,
- create a new alien reveal,
- add a craft solely because it looks good.

Any such desire routes back to story governance rather than becoming silent visual canon.

Gate: HARD.
