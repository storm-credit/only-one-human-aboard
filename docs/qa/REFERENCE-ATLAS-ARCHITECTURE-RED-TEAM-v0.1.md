# Reference Atlas Architecture — Hostile Red Team v0.1

Status: `PACKAGE H ARCHITECTURE QA / NOT CANON`
Date: 2026-08-18

Target:
`REF-H1 — Human-Readable MOC + Source-Linked Atlas Tables + Authority/Elastic Registry + Optional Structured Metadata`

## Attack 1 — Shadow Canon
**Attack:** A concise Atlas row is easier to read than the source Bible, so writers begin treating Atlas wording as truth.

**Defense:**
- every Atlas page declares navigation/reference-only status,
- every consequential row links to owner authority,
- nuance stays in owner documents,
- explicit hierarchy says Atlas cannot override Canon/Blueprint/M1.

Verdict: `PASS`

## Attack 2 — Candidate Becomes Canon By Formatting
**Attack:** Tables visually flatten Canon v1 and v2 candidates into equivalent facts.

**Defense:**
Use stable status vocabulary in every relevant row:
`CANON-V1 / LOCKED-STORY / V2-CANDIDATE / C2-ELASTIC / IMPLEMENTATION / SUPERSEDED / REJECTED / FORBIDDEN`.

Verdict: `PASS`

## Attack 3 — Old Markdown Resurrects Exact-One Protocol
**Attack:** Search finds old WL11 `one-at-a-time` concept and an agent treats it as active.

**Defense:**
Authority registry must explicitly flag exact-one preservation protocol as SUPERSEDED/FORBIDDEN and point to current demographic-state Canon.

Verdict: `PASS REQUIRED`

## Attack 4 — Map Creates Habitat Castes
**Attack:** Civic map labels 1/2/3환 by function and a writer turns them into elite/farm/worker castes.

**Defense:**
Civic atlas must say mixed residents/jobs/classes in all Habitats; functions are emphasis, not caste. Engineering overlay separate.

Verdict: `PASS REQUIRED`

## Attack 5 — Engineering Overlay Becomes Exact Blueprint
**Attack:** Reference map invents pressure-sector counts, node locations or failure topology not actually frozen.

**Defense:**
Only relational topology and known ranges may appear; exact unsolved counts remain C2-ELASTIC or omitted.

Verdict: `PASS`

## Attack 6 — Institution Matrix Grants Power
**Attack:** A table simplifies an institution into powers it does not possess; Maren/service becomes constitutional sovereign by shorthand.

**Defense:**
Every institution row includes `may / may not / authority source` fields. Maren family-recusal, no AI sovereignty, no Amara authority remain visible.

Verdict: `PASS`

## Attack 7 — Timeline False Precision
**Attack:** 450-year broad history gets fake exact years that later contradict M1 or historical candidates.

**Defense:**
Use broad Voyage Year bands for history and explicit exact locks only from M1/Blueprint. Mark working dates/ranges C2.

Verdict: `PASS`

## Attack 8 — Dependency Matrix Invents Physics
**Attack:** A neat dependency chart silently creates exact power/reserve ratios.

**Defense:**
Dependency Atlas maps qualitative dependencies and failure propagation only; exact numbers remain source-owned/P1 quant.

Verdict: `PASS`

## Attack 9 — Episode Index Leaks Future Knowledge
**Attack:** An episode lookup links to all future device payoffs.

**Defense:**
Episode index routes to Package G knowledge-fenced registry. Future constraints are author-side only; character context remains separated.

Verdict: `PASS`

## Attack 10 — Character Network Spoils Reveal
**Attack:** Amara is visually highlighted as `only Natural-Origin`, turning Atlas into a drafting spoiler for pre-Reveal POV context.

**Defense:**
Character network is author reference. Episode-agent retrieval must go through Package G; it must never load global character truth indiscriminately for pre-Reveal episodes.

Verdict: `PASS WITH RETRIEVAL GUARDRAIL`

## Attack 11 — Material Atlas Becomes Loot List
**Attack:** Relics are ranked by rarity and writers chase them as plot coupons.

**Defense:**
Material Atlas keeps O1~O5 functional classes/provenance and hard rule `Old ≠ powerful / Rare ≠ useful`; no RPG tier.

Verdict: `PASS`

## Attack 12 — Plugin Dependency
**Attack:** Atlas only works if Dataview or a custom plugin is installed.

**Defense:**
Plain Markdown/YAML/wikilinks are baseline. Dataview/database views optional later.

Verdict: `PASS`

## Attack 13 — Atlas Bloat
**Attack:** Every minor scene detail becomes a node, recreating the full repository in another folder.

**Defense:**
Atlas uses high-value lookup tables. C3 incidental detail stays in episode/character source unless reused enough to merit an ID.

Verdict: `PASS`

## Attack 14 — Superseded Blueprint Selection
**Attack:** Act6 v0.1 is found before v0.2.

**Defense:**
Authority registry and Episode Context Index must mark Act6 v0.2 ACTIVE and v0.1 SUPERSEDED.

Verdict: `PASS REQUIRED`

## Attack 15 — `Human` Label Ontology Drift

**Defense:**

Verdict: `PASS REQUIRED`
