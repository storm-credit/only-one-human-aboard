# ATTACK 1 — `결국 시뮬레이션이었다` cliché

Risk:
The ultradense civilization field can still be superficially compared to simulation fiction.

Why current design survives:
- one real physical Outer Ark exists,
- substrate citizens are physical continuous persons, not disposable game NPCs,
- local embodied physics/resources/death remain causal,
- some lineages are full lived societies, most search states are not,
- reveal escalates rights rather than saying earlier suffering was fake.

Required prose rule:
Never use reveal as `놀랍게도 모든 것은 가짜였다`.

Verdict: **PASS**.

# Originality center — what is actually distinctive

The project should NOT market itself internally as novel merely because it has:
- AI,
- simulation-like civilizations,
- regression,
- alternate histories,
- generation ship.

Distinctive combination lies in:
1. one real ark holding an astronomical **physical civilization search ecology** rather than cosmological multiverse,
2. most possibilities non-conscious but some search paths deepening into ethically real lived societies,
3. protagonist experiences exactly one apparent regression via rare continuity-routing failure,
4. same recurring people vary through family/group/institution/chance rather than fixed moral variants,
5. ordinary background actors can become historically central through social cascade,
6. current HUMAN:1 is an attrition result, not chosen-one design,
7. destination resolution is `stop treating lived persons as involuntary test material`, not `turn off the simulation`,
8. the final unknown comes from real external reality exceeding rehearsal.

If execution loses these and emphasizes generic `other worlds / prophet / evil AI`, originality drops sharply.
