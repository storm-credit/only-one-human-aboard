## Real defects found during 410 materialization

Three post-schema implementation defects were discovered and fixed rather than waived:

1. **EP017~028 serialization P1** — legacy compact frontmatter used unsafe/malformed spacing/nesting patterns. All preserved files are now normalized to the frozen flat schema.
2. **Blueprint vocabulary P1** — later Acts use `Want`, `Action`, `Continuity`, and final `End State` rather than only Act1-style labels. Compiler compatibility aliases now map those exact source fields without changing the Blueprints.
3. **Act-tail parser P1** — the final episode card in an Act could consume the following Act QA summary into the last open field. Field parsing now stops at Markdown headings/horizontal rules and EP410 was recompiled cleanly.

These were correctness issues in context materialization, not changes to story Canon/Blueprint.
