# 2. New P0 — L2 lifecycle / branch-end moral accounting

The repaired model says L2 inhabitants are real moral subjects.

But it still does not answer cleanly:
> `테스트가 끝났을 때 아직 살아 있는 L2 시민 30만 명은 어떻게 되는가?`

Bad answers:
- 그냥 delete → system becomes repeated mass killer.
- 모두 영구 archive → millions of sleeping persons become a bigger hidden civilization and late-series ontology bomb.
- 모두 L1 body에 promote → embodiment blocker returns.

Severity: **P0 BLOCKER**.

Required repair:
Design L2 so that full-lived history does not normally create-and-discard 300k-person civilizations.
Recommended shape:
- one `Primary Lived Lineage` normally remains continuously active,
- new state can be a live environmental/social transition without killing the people,
- full duplicate branch is rare,
- only rare paired branch produces true competing person lineages,
- its ethical disposition must be explicit and limited.
