# 1. Star Fit

Current astronomical baseline identifies **Epsilon Indi A** as a nearby K-type main-sequence star at roughly **11.9 light-years** order.

This is close enough to the previous H9R elastic distance band (~12~14 ly) that no structural rewrite is required.

K subtype is slightly later than the earlier K2~K4 placeholder, but that subtype was explicitly provisional/elastic.

Current priority:
- star identity can shift H9R shorthand from `K2~K4 candidate` to `nearby K-dwarf / Epsilon Indi A`.
- do not make exact subtype a story-facing fact unless needed.

# 2. Known Planet-System Guardrail

Modern astronomy already associates Epsilon Indi A with a long-period giant-planet system candidate/confirmed object under the `Ab` naming lineage.

Therefore:
**do not Canon-lock the fictional habitable target as `Epsilon Indi Ac / 인디 c` unless final astronomy designation continuity is checked.**

Future discovery order can change letter designations and would create unnecessary real-world fragility.
