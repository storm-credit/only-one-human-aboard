# 1. 현재 시각 스타일 방향

## 1.1 메인 스타일

현재 1순위 제작 방향:

# **2D SEMI-REAL ANIMATION / GAME-CONCEPT HYBRID**

목표:
- 실사 사진처럼 보이지 않는다.
- 단순 카툰처럼 평면적이지 않는다.
- 얼굴/기체/공간의 형태 차이를 선명하게 읽을 수 있다.
- 장기연재 IP의 설정집/캐릭터시트/기체도감으로 확장 가능하다.
- 표지나 키아트에서는 더 극적인 연출로 확장할 수 있다.

금지:
- photoreal portrait 기본값
- 피부 모공/주름을 사실적으로 과장해 30대 후반을 40대 후반 이상으로 보이게 하는 표현
- 모든 캐릭터를 동일한 `잘생긴 애니 남성/미형 여성` 템플릿으로 통일
- 지나친 셀애니 단순화로 직업 장비와 재질이 사라지는 것

# 2. 주인공 시안 A/C에서 얻은 캘리브레이션

최근 샘플 중 사용자가 선호한 방향:
- Proposal A
- Proposal C

이 둘은 **최종 얼굴 정본이 아니다.**
오직 스타일/비율/직업감 캘리브레이션 자료다.

## A에서 가져올 것
- 정돈된 2D 세미리얼 완성도
- 장기 주인공으로 보기 쉬운 얼굴 가독성
- 장신/슬림 실무형 전신 실루엣
- 얼굴 클로즈업 + 측면 + 전신 + 장비가 한 시트에서 읽히는 구성

## C에서 가져올 것
- A보다 조금 더 현장 전문가다운 단단함
- 지나치게 아이돌형이 아닌 성인 남성 인상
- 작업복/케이스가 장식이 아니라 직업 도구처럼 보이는 감각

## 가져오지 않을 것
- 두 시안의 실제 얼굴을 그대로 복제
- 특정 국적/민족으로 자동 고정
- 특정 실존 배우 얼굴의 직접 복사
- 가상의 회사/로고/이름을 정본처럼 고정
- 군인/특수부대처럼 보이는 과도한 하네스/전술장비

## 현재 주인공 캘리브레이션
- 체감 나이: **37~39세**
- 성별: 남성
- 체형: 장신 또는 중상신장, lean practical
- 인상: 차분함 / 관찰적 / 현재진행형 에너지
- 수염: 없거나 매우 약함
- 주름: 나이를 알리는 수준만, 피로/노쇠 강조 금지
- 국적/민족 인상: **미확정 / 특정 인종 고정 금지**
- 얼굴 형태: 다른 남성 캐릭터와 충돌하지 않는 독자적 morphology가 우선
- 직업 시각앵커: 짧은 현장재킷 + 좁은 필드케이스 + 표면을 읽을 때 앞으로 기울어지는 자세

# 3. CHARACTER PRODUCTION RULES

## 3.1 캐릭터는 얼굴색/머리색이 아니라 구조로 구분한다

각 핵심 인물은 다음 요소 중 최소 4개가 다른 핵심 인물과 명확히 달라야 한다.

- 얼굴 길이/폭
- 턱과 광대 질량
- 코의 길이/폭/브리지
- 눈 간격/기울기/눈썹 질량
- 체형/어깨/목
- 자세와 중심축
- 머리 덩어리 실루엣
- 손/장비를 쓰는 습관

Hard fail:
- 머리카락을 가리면 두 인물이 같은 사람처럼 보임
- 남성 전원이 좁은 턱의 미형 얼굴
- 여성 전원이 같은 코/턱에 머리만 다름
- 나이를 흰머리/주름만으로 구분

## 3.2 특정 인종/국적은 자동화하지 않는다

이름, 성씨, 직업만 보고 외형을 자동 결정하지 않는다.
메리디언은 장기 다문화 도시 문명이며 미래 세대의 외형 다양성을 허용한다.

금지:
- `성씨가 X이므로 반드시 X민족 얼굴`
- 민족성을 의복/피부색 클리셰로 표현
- 전 캐릭터를 동아시아인 또는 서구인 한쪽으로 통일

## 3.3 매력도 분포

모든 핵심 인물을 모델형 미남/미녀로 만들지 않는다.

필요 범위:
- conventionally attractive
- ordinary attractive
- distinctive ordinary
- age-textured
- softer/heavier/wiry/compact 등 다양한 체형

주인공은 매력적이어도 되지만 `아이돌 화보`보다 `장편 서사의 중심인 성인 실무자`가 먼저다.

# 5. MACHINE / CRAFT PRODUCTION RULES

기체의 멋은 무기와 속도감이 아니라 **기능을 읽을 수 있는 구조**에서 나온다.

공통 조상:
- 인터페이스 규격
- 체결/도킹 문법
- 센서/작업 표식
- 유지보수 접근성

역할별 차이:
- crawler = 표면 부착/접근
- mapping drone = 센서 시야
- tug = 하중/결합
- rescue skiff = 환자/구조 접근
- service frame = 작업팔/툴 구조
- Outer Ark craft = 실제 우주 유지 기능

Hard fail:
- 색/로고 없이는 기체 구분 불가
- 모든 기체가 날렵한 전투기 코/캐노피를 가짐
- 작업프레임이 인간형 전투메카로 변함
- 신형=전투력 상승 같은 게임식 진화

---

# 6. MACHINE SHEET DELIVERABLES

SIGNATURE:
- neutral 3/4 hero-neutral view
- side orthographic-ish view
- top/front silhouette if needed
- human/door/tool scale cue
- functional cutaway/detail
- generation/state comparison if variant allocated

RECURRING:
- 3/4 + side
- function callout 1~3개

WORLD-DEPTH:
- guidebook spot plate 또는 cutaway 1개
- 본편에서 기억을 강요하지 않는다.

# 7. ENVIRONMENT PRODUCTION RULES

메리디언은 게임의 각기 다른 biome가 아니라 **하나의 오래된 도시**다.

공유해야 하는 것:
- 표지/wayfinding 조상
- 안전 인터페이스
- 문/배관/서비스 연결 문법
- 세대별 재료의 계보

구분해야 하는 것:
- 공간 geometry
- 사람의 움직임
- 공공/사적 사용비율
- material age
- light source
- acoustic implication
- landmark hook

Hard fail:
- 모든 곳이 어두운 금속복도
- 구역을 색깔로만 구분
- Old Works만 볼거리가 있음
- 목적지가 전혀 다른 프랜차이즈처럼 보임

# 8. PROP / MATERIAL CULTURE RULES

소품은 두 종류로 분리한다.

## Tracked
- 직업/인물/장기변화를 읽게 하는 일부 자산

## Ordinary Noise
- 식기
- 옷
- 장난감
- 가구
- 일회성 공구
- 생활 패키지
- 광고/표지

Ordinary Noise가 항상 더 많아야 한다.

수집욕은 `모든 물건이 비밀`이라서 생기는 게 아니라:
- 같은 계열을 알아봄
- 세대차를 알아봄
- 사용흔적을 알아봄
- 누가 썼는지 기억함
에서 나온다.

# 11. IMAGE GENERATION ARCHITECTURE

모든 생성 입력은 두 블록을 분리한다.

## Identity Lock
자산이 어떤 컷에서도 바뀌면 안 되는 요소:
- morphology
- proportions
- silhouette anchors
- core equipment layout
- family/interface grammar
- base material logic

## Shot / State Block
이번 이미지에서만 바뀌는 요소:
- pose
- camera
- lighting
- Act state
- damage/wear
- environment
- expression

Hard:
Identity Lock을 Shot Block에 묻어두지 않는다.

# 14. STOP RULE

다음 경우에만 추가 이미지를 생성한다.
- 문서만으로 구분성이 판단되지 않을 때
- 두 자산의 충돌을 실제로 확인해야 할 때
- SIGNATURE 자산을 Freeze하기 직전
- 장면/표지/설정집 제작에 실제 이미지가 필요할 때

다음 이유만으로는 생성하지 않는다.
- `한번 보고 싶어서`
- `더 멋진 버전이 나올 것 같아서`
- `변형을 많이 만들면 수집욕이 늘 것 같아서`
