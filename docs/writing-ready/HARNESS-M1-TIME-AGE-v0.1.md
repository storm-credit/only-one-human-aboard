# 7. Time-Skip Safety Rules

Every bridge must show at least 4 anchors across different domains:
1. age/life-stage
2. relationship baseline
3. job/institution state
4. physical/arrival resource state

A bridge may skip:
- routine policy implementation
- repeated training
- repeated commute/work cycles

A bridge may NOT skip:
- breakup/reconciliation
- death of core cast
- marriage/parenthood of core cast if plot-relevant
- career decision that changes settlement path
- legal status change central to Human Settler conflict
- origin/public identity change
- PR-H1 relationship repair
