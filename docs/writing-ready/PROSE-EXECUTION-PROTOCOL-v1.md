# 1. POV

## Hard Default
- one POV character per episode
- third-person limited
- no mid-episode head hopping

## Selection Order
1. irreversible-choice owner
2. immediate cost bearer
3. information-fair observer
4. if genuinely tied, prefer Maren as series anchor

`Episode Blueprint Primary Actor` is strong evidence but not automatic POV.

## Maren Rule
Maren must remain the **largest single POV owner across the series**.
Approximate diagnostic range:
~45~60%.
This is NOT a quota.

## POV Tiers
Tier 1:
- Maren
- Ella
- Noah
- Amara

Tier 2:
- Raul
- Ines
- Jun
- Tomas
- Leo
- Kai
- Mina when age/function supports

Tier 3 one-off POV:
rare; requires explicit execution reason.
Do not create POV merely to deliver information.

## Act-Ahead Mapping
Before drafting an Act:
- assign Execution POV to all episodes in that Act
- run protagonist-share / rare-POV / info-fairness check

POV may change before prose if episode causality stays intact.

# 2. Narrative Distance

Default:
**close-medium third person**.

Move closer for:
- embarrassment
- family conflict
- physical/medical pressure
- irreversible choices

Move slightly wider for:
- place reorientation
- time-skip re-anchoring
- public procedural context

Forbidden:
- omniscient explanation of hidden truth before POV knows it
- narrator declaring the final philosophical meaning of `human`
- constant explicit internal monologue

Thought is usually rendered through:
perception → attention → decision pressure,
not essay-like self-analysis.

---

# 3. Episode Length

Soft production band:
**roughly 5,500~8,000 Korean characters including spaces**.

Longer major-payoff episodes allowed if earned.
Shorter episodes allowed if paid-installment satisfaction is complete.

Platform requirements may override mechanically.
Exact count is not Canon.

---

# 4. Scene Rhythm

Typical:
2~4 substantial scenes.
Not a hard formula.

Every scene should change at least one:
- plan
- access/status
- relationship temperature
- physical constraint
- public/private knowledge

A scene that only explains should be merged into active pressure.

Across ~5 episodes, avoid all scenes being:
- hearings
- archive searches
- committee meetings
- screen/report reading

Use family/work/physical/social/downtime variation.

---

# 5. Openings

Open on present pressure rather than background explanation.

Preferred:
- active job problem
- interrupted routine
- deadline
- interpersonal mismatch
- physical inconvenience
- consequence arriving from prior choice

Avoid repetitive:
- notification arrives
- summons arrives
- report arrives
- screen staring

First paragraph unfamiliar-jargon load:
prefer 0~1.

---

# 6. Episode End / Hook

Rotate:
- choice
- cost
- relationship turn
- changed physical state
- access gain/loss
- public consequence
- expectation reversal
- quiet irreversible emotional decision

Preferred principle:
**hook is caused by prior action**.

Not every episode needs a shock cliffhanger.

---

# 7. Dialogue

Dialogue amount is a soft diagnostic, not quota.

Rules:
- no complete essay speeches by default
- no perfect thesis/counterthesis/synthesis exchange
- interruptions/avoidance/adjacent answers allowed
- people can be tired, petty, incomplete, wrong
- do not narrate the same conclusion again after dialogue already carried it

Dense legal/technical dialogue must include a practical non-rhetorical constraint:
- deadline
- missing info/person
- capacity/queue
- physical inconvenience
- authority mismatch
- incompatible practical goal

---

# 8. Exposition / Jargon

Early active terms:
- 시드
- 연속성
- 복원

Mid terms:
- 복구지도
- 앵커
- 자연기원 / 합성기원

Late terms:
- 개척헌장
- 도착전환
- 인간 정착민

Explain only what current choice requires.

Soft warning:
- prefer one main unfamiliar concept per scene
- two linked concepts fine when the same decision requires both
- if reader must retain 3+ fresh labels, simplify

No in-prose glossary paragraph.

# 9. Voice Lens

Voice differs primarily by **what the POV notices**.

## Maren
contradiction / sequence / status / process.
Under stress, sentence decisions shorten.
Becomes more formal when emotional.
Care appears first as logistics.

## Ella
people / remembered texture / social connection.
More associative and relational.

## Noah
Early: peers / alternatives / escape routes / adult blind spots.
Later: creative/media/craft patterns.
Never Raul-lite.

## Raul
audience / framing / institutional power.
Public speech sharper; private looser and more observational.

## Tomas
institutional timing / tradeoffs / delay costs.
Never cryptic lore elder.

## Ines
body / function / time / prognosis.

## Jun
place / repair / local history / concrete residents.

## Amara
work / household logistics / boundaries / practical consequences.
Do not repeat symbolic-refusal speeches.

# 10. Ordinary Imperfection

Do NOT inject `human texture` token into every episode.

Every 5-episode batch ask:
> Have characters been too efficient, articulate, self-aware, and plot-relevant for too long?

If yes, restore organic ordinary friction when available:
- tiredness
- minor selfishness
- awkwardness
- bad timing
- boredom
- irrelevant preference
- small error
- humor

No mandatory quirk quota.

---

# 11. Description

Priority:
1. used object
2. movement/path/queue/maintenance
3. body state
4. social use of space
5. sensory detail affecting action

Avoid:
- generic cinematic awe
- inventory-list SF
- repeating `vast ship` description

Habitats differ through routines and infrastructure use, not adjective themes.

---

# 12. Science / Law

Preferred technical-explanation order:
`problem → mistaken assumption → practical correction → consequence`.

Preferred law presentation:
- who may act
- who must wait
- whose access/status changes
- what can be appealed

Avoid statute recital unless the literal wording itself is the active object of conflict.

---

# 13. Time Skip

Major skip quickly re-anchors at least 3:
- age/life stage
- relationship
- job/residence
- arrival clock
- visible material change

Prefer changed routine over chronology summary paragraph.

M1 Time/Age Harness is execution clock authority.

# 16. After-Draft Episode QA

## Blueprint
- core problem preserved?
- primary choice preserved?
- irreversible consequence preserved?
- next carry preserved?

## Canon
- no silent new rule?
- no forbidden tech/authority?

## POV
- one POV?
- knowledge boundary respected?

## Voice
- could another character's name be swapped in with no prose change?
If yes: repair.

## Exposition
- any paragraph exists only to explain?

## Hook
- consequence-driven or random drop?

## Anti-AI
- dialogue too symmetric/complete?
- everybody too articulate?
- every detail suspiciously meaningful?
- narrator over-explains theme?

Canon-impact failure:
**STOP. Do not patch around it.**
Run change control.
