# EP057 — Can You Publish One?

## Dominant Function
**Make public release ethically costly but institutionally plausible.**

## CP-H1 Decision Factors
Arguments FOR exact top-line release:
- audit is now public-interest work.
- legacy categories already affect current legal/data interpretation.
- hiding the rare cell would materially distort whether the category has active current members.
- unusual suppression after announcing methodology may itself create uncontrolled speculation.
- the report needs to explain why the legacy field cannot simply be deleted as an empty historical category.

Arguments AGAINST:
- exact `1` is inherently re-identifying pressure.
- combining with public historical fragments can narrow candidates.
- the person never consented to become a public category.

## Selected Decision
Publish exact top-line aggregate **only** with:
- no habitat breakdown
- no age band
- no sex/gender field
- no household/family cross-tab
- no medical/reproductive details
- no source-row access
- explicit anti-inference warning
- separate support/protection response for potential candidates

## Required Moral Shape
This is **not clearly risk-free or clearly wrong**.
The public-interest decision itself creates Act 3 harm.

## Character Rule
No core character unilaterally authorizes release.

## End Movement
Publication clock starts.
