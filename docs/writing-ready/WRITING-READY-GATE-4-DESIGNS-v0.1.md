# Writing Ready Gate — 4 Designs v0.1

Status: `WRITING READY PREPARATION / NO PROSE`

Project: 《우주선에는 인간이 한 명뿐이다》

Canon Freeze is already PASSED.
This document decides how much episode-level design must exist before any manuscript is allowed.

Absolute rule:

- episode blueprint is design, not prose.

---

# WR-A — Canon + 23 Sub-Acts Only

## Structure
Begin writing from the existing 7 Acts / 23 Sub-Acts and design each episode only when reached.

## Strength
- flexible
- fast to start
- avoids overplanning

## Fatal Risks
- foreshadow placement drifts
- 230-episode reward rhythm is untested
- C8 pre-Reveal appearances can cluster unnaturally
- time skips/ages may break
- Maren can accidentally dominate every episode
- case-of-the-week filler can appear between macro turns

## Fit With User Workflow
Poor. The project explicitly chose design-first and no-writing-before-full QA.

## Verdict
`REJECT`

---

# WR-B — Deep First 20 + Rolling 20-Episode Windows

## Structure
Deep-design episodes 1~20, then always maintain a 20-episode blueprint lead while writing.

## Strength
- strongest market optimization for launch
- preserves flexibility
- less sunk planning cost

## Risks
- later Canon problems may appear only after prose has begun
- final foreshadow/payoff cannot be fully regression-tested
- arrival-law/resource/age arcs depend on long-horizon causality

## Fit
Better for normal serial fiction, weaker for this project's explicit Freeze philosophy.

## Verdict
`GOOD INDUSTRY METHOD / REJECT AS THIS PROJECT'S BASE`

---

# WR-C — Full 200~230 Episode Detailed Blueprint Before Writing

## Structure
Every episode receives a detailed card before prose begins.

Mandatory fields per episode:
- episode number
- Act/Sub-Act
- in-world time
- primary location
- viewpoint/primary actor
- episode desire/problem
- event/pressure
- choice/action
- reward/payoff
- irreversible consequence
- information release
- foreshadow/payoff transaction
- relationship change
- end hook
- Canon dependencies

## Strength
- strongest long-form continuity
- full foreshadow regression possible
- filler visible before prose
- time/age/cast balance measurable

## Weakness
- 230 detailed cards can create false precision
- early changes may force huge downstream edits
- too much detail can make later prose feel predetermined

## Verdict
`VERY STRONG / RIGIDITY RISK`

# WR-D — Two-Pass Full Blueprint + Risk-Weighted Deepening + Harness

## Structure
No prose until the *entire series* passes two blueprint passes.

### Pass 1 — Full-Series Episode Matrix
Every planned episode (~200~230) gets a medium-depth causal card.

Required:
- episode #
- Act/Sub-Act
- time band
- primary actor
- location
- problem/event
- choice/turn
- reward
- consequence carried forward
- info/foreshadow function
- hook

Goal:
prove the whole series exists episode by episode.

### Pass 2 — Risk-Weighted Deep Cards
Deepen all high-risk episodes/clusters:
- opening 1~20
- every Sub-Act turn
- Count/Meaning/Amara identity
- Maren/Ella preference-record rupture
- Final Approach certification
- legacy Human Settler conflict
- major time skips
- system insertion / ending

Deep fields:
- 5~8 scene/beat functions (NO prose)
- who changes what
- emotional before/after
- clue visibility
- reader expected inference
- false interpretation if relevant
- physical pressure / downtime balance
- final-page hook type

### Harness / Regression
After both passes, run automated/manual matrices for:
- Reader Promise
- no filler/reset
- hook/reward cadence
- info fairness
- foreshadow/payoff closure
- age/time continuity
- location balance
- non-Maren causality
- character autonomy
- jargon load
- Canon drift
- prohibited directions

## Strength
- full-series certainty without over-specifying every scene equally
- matches design-first requirement
- preserves some writing flexibility in low-risk episodes
- expensive detail goes where failure cost is highest

## Weakness
- still substantial prewriting work
- requires disciplined matrix maintenance

## Verdict
`CURRENT BEST`

# 3. Full-Series Required Matrices

Before Writing Ready:

## M1 — Time / Age Matrix
Track:
- absolute/relative story time
- Maren/Ella/Noah/Raul/Tomas/Ines/Jun/Amara/Leo/Kai/Mina ages at meaningful skips
- recovery/career/school milestones

## M2 — Cast Presence / Causality Matrix
For each episode:
- who initiates the major change
- Maren involvement level
- non-Maren causal actor

Series requirement:
Every Act has sustained non-Maren causality, not only token episodes.

## M3 — Location Matrix
Track:
- 1환
- 2환
- 3환
- Spine
- Outer Works
- Legacy/Old Quarter
- late destination/orbit/surface

Prevent thematic/caste geography.

## M4 — Information Ladder Matrix
Track each factual truth by:
- who knows
- who can access
- reader knowledge
- public knowledge
- legal status

## M5 — Foreshadow / Payoff Ledger
Every deliberate clue gets:
- seed episode
- reinforcement if any
- false/fair alternate reading
- payoff episode
- post-payoff consequence

No clue without planned payoff unless deliberately classified as world texture/MacGuffin.

## M6 — Reward / Hook Matrix
Track:
- reward type
- hook type
- consecutive episodes without meaningful payoff

Guardrail:
no long clue-only corridors.

## M7 — Canon Dependency Matrix
Episode-level links to:
- WORLD_BIBLE rule
- CHARACTER_BIBLE arc
- ACT_BIBLE constraint

## M8 — Anti-Drift Matrix
Flags:
- chosen-one
- human-vs-AI binary
- case reset
- philosophy lecture
- convenient leak
- magical copy
- Habitat caste
- free third way
- war/action genre takeover

# 4. Writing Ready P0 Conditions

Writing Ready is BLOCKED if any of the following remain:

1. any planned episode has no reason to exist beyond exposition
2. Count/Meaning/Amara identity fairness cannot be traced episode-by-episode
3. Maren formally decides her own family dispute
4. Amara becomes mystery-key/technical-key/legal-key
5. Noah/Ella/Raul/Jun/Ines/Tomas lose autonomous series arcs
6. 14-year time/age matrix contradicts itself
7. any core foreshadow lacks payoff or payoff lacks prior fair basis
8. 15+ episode stretch has no meaningful reward/relationship/material turn without explicit hostile-test pass
9. Act 5~7 becomes primarily meetings/legal exposition
10. destination arrival removes scarcity for free
11. a Canon world rule must be silently changed to make an episode work
12. first 20 episodes fail market/readability hostile test

# 5. Writing Ready P1 Conditions

# 6. Blueprint Change Protocol

Once the full blueprint is built:

Episode-level changes are allowed before prose if they preserve Canon.

If a change affects:
- Act order
- Reveal truth/timing architecture
- character core origin/relationship
- world physics/law
- ending architecture
then it requires Canon-impact review.
