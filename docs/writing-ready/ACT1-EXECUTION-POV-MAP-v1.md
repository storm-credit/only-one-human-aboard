# Voice Load Test

Act 1 provides enough recurrence to establish six distinct lenses before Amara enters:

- Maren: contradiction/process
- Ella: social memory/reconnection
- Noah: peer/options/avoidance
- Raul: framing/power/audience
- Ines: body/function/time
- Jun: place/repair/resident specificity

Risk:
EP001~009 has six POV owners in nine episodes.

Mitigation:
- all are core recurring cast
- no one-off POVs
- Maren/Ella/Noah family triad repeats quickly
- POV is always announced through immediate location/action context, never label cards
