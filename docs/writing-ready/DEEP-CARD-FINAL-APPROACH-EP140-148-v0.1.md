# 0. Certification Preconditions

Before certification, all four domains must be sufficiently ready:
1. **Navigation / trajectory** — insertion plan and remaining maneuver margins within accepted bounds.
2. **Destination survey** — system resources/habitable candidate knowledge stable enough for planning, not perfect certainty.
3. **Industrial readiness** — bootstrap production/training/asset plans can support early orbit/surface operations.
4. **Legal / civic transition readiness** — current rights remain protected while destination-registry translation can operate under provisional rules.

No single institution certifies all four.
