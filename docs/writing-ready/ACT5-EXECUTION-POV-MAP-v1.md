# Engineering-Density Guardrail

No technical POV episode may be about `how the machine works` alone.

Every one must answer:
**who loses time / slack / place / career option because this system cannot do everything at once?**

Examples:
- 123 manufacturing line → utility maintenance sequence
- 124 radiator window → lower redundancy / medical delivery delay
- 132 split batch → both maintenance and arrival schedule tighten
- 144 certification prep → overtime/training/current repair displacement

Hard forbidden:
`propulsion needs X GW so households lose electricity`.
