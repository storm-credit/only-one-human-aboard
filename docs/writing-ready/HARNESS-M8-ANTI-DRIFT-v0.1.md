Verify the 230-episode blueprint does not drift away from the frozen Reader Promise into a different genre or premise.

# 1. Case-of-the-Week Drift

Risk:
Maren's profession naturally produces episodic disputes.

Blueprint defense:
- early cases create precedent/relationship/institutional carry
- segmented-rights pilot persists
- post-Reveal cases change service rules
- Old Quarter relocation persists
- EP178 cross-jurisdiction family case creates future precedent
- EP198 and EP229 mirror rather than reset

Rule:
If deleting a case leaves all later baselines unchanged, merge/cut it.

`PASS`.

# 6. Hard-SF Manual Drift

Engineering architecture is used only when it changes:
- maintenance windows
- staffing
- spare margins
- city space
- family/career schedules
- deployment order

Blueprint never requires exact:
- fusion isotope chain
- nozzle geometry
- shield areal density
- orbital mechanics equations in prose

Insertion works because planning worked, not because a character explains equations.

`PASS`.
