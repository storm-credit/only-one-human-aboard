# 0. Lifecycle codes

- `I` = INTRODUCE / first distinct recognition
- `R` = RECOGNIZE / familiar return under new context
- `X` = RECONTEXTUALIZE / meaning/history interpretation changes
- `T` = TRANSFORM / visible state, ownership, role or lineage changes
- `P` = PERSIST / ordinary continuity; no need for foreground payoff
- `H` = HOLD / reveal-sensitive; deliberately hidden or unsalient
- `N` = NO-CHEKHOV / ordinary world texture; may never pay off
- `—` = no meaningful salience needed

Multiple codes can coexist, e.g. `R/T`.

Hard:
A blank-looking Act is not a defect. `—`, `P`, `N`, and `H` are deliberate anti-overdesign states.

# 6. Act-by-Act asset behavior summary

## Act1 — Encounter density, not catalog density
Primary:
C01~C10 ordinary identities; M01/M02/M03; P01/P02/P04/P05; L01~L06; selected W noise.

Rule:
assets appear because people work/live there. No `look at this cool model` scene.

## Act2 — Familiar assets under failure
Primary reward:
R/T on known tools, routes, care and authority.
Only necessary rescue/emergency families get distinct introductions.

## Act3 — Wrong familiarity
Primary reward:
X through small material/social differences.
Do not create alternate skins of every asset.

## Act4 — Social recontextualization
Same city/materials behave differently because belief/rumor/preparation changes use.
Newness low.

## Act5 — Provenance becomes physical action
Legacy/record assets may become X, but every archive/material discovery must cause a current decision, access problem, relationship consequence or safety action.

## Act6 — Transformation-heavy
Lowest new-asset budget.
Known routes, kits, authority marks, freight systems and community spaces are patched, depleted, retired, segmented or repurposed.

## Act7 — Reveal-sensitive physical ecology
Outer Ark assets M08~M11 finally become visible as an ecology, not four product introductions.
Known interface/maintenance logic bridges reader understanding.

## Act8 — Rights/care over gadget spectacle
Very low new-object attention.
Medical, governance and provenance continuity dominate.

## Act9 — Descendants > novelty
M13/M14/L10~L12/P10 can be new because destination requires them.
But emotional/collectibility payoff comes from M15 and inherited standards.

# 7. Anti-overuse budget

Per ordinary episode:
- 0~1 newly distinct tracked asset preferred,
- 0~2 salient returning assets preferred,
- untracked ordinary detail should outnumber tracked detail.

Per scene:
- one visual/material anchor is usually enough,
- second allowed if it supports action,
- third only for incident logistics.

Hard fail:
- three consecutive asset-description paragraphs,
- model/brand roll-call,
- every object returning later,
- every Act giving every core character a new costume,
- Act9 introducing a new visual franchise.
