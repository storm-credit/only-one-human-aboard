# 1. Current POV contract

Series diagnostics:
- protagonist-owned: **319/410 = 77.8%**
- protagonist-present: **386/410 = 94.1%**
- fully protagonist-absent: **24/410 = 5.9%**

The former `272/410 = 66.3%` target is historical and superseded.

Ownership modes:

## P — Protagonist-owned
The protagonist owns the dominant dramatic question, decision, hook or emotional spine.
A secondary scene may still independently move the world.

## M — Mixed secondary-owned
A secondary character owns the decisive local action, while protagonist appears in a separate meaningful scene.

## A — Full protagonist-absent
Protagonist does not appear. Use only the 24 default slots in the current overlay unless a later QA-approved swap is made.

Hard:
`protagonist present` does NOT mean `protagonist owns the other character's decision`.

# 2. Episode card fields

Each execution card records:
- **Ownership Mode:** P / M / A
- **Scene POV Owner(s):** one clear close-third owner per continuous scene
- **Time / Duration**
- **Primary Zone(s)**
- **Immediate Want**
- **A-Plot Action**
- **Independent B-Plot / Relationship**
- **World/Institution Movement**
- **Clue / Device State** — NONE or PLANT / REINFORCE / TRIGGER / PAYOFF / AFTERSHOCK
- **Knowledge Fence**
- **Handoff State** — what information actually reaches protagonist/other actors
- **End Turn**
- **Continuity Output**

For mixed episodes, explicitly mark scene breaks and knowledge isolation.

---

# 3. Episode usefulness gate

PASS only if an episode does at least 2 of:
- survival/practical action,
- relationship change,
- mystery movement,
- world/institution consequence,
- character judgment change,
- ordinary-life attachment,
- causal setup/payoff.

FAIL if:
- pure lore explanation,
- pure travel,
- repeated event with no new action/result,
- secondary POV exists only to explain information,
- protagonist cameo exists only to satisfy the 94.1% target,
- protagonist is dragged into another domain solely to solve it.

---

# 4. Mixed-scene rules

A converted mixed episode must use one of:

### M1 — protagonist frame → secondary decision → protagonist consequence
### M2 — protagonist A-plot + separated independent secondary B-plot
### M3 — secondary opening → protagonist convergence after consequence exists

Hard:
- no head-hopping,
- no protagonist teleportation,
- no automatic information transfer,
- later dialogue uses only explicit handoff information.

If the protagonist scene adds no dramatic function, revert that episode to A/full absence and compensate elsewhere only after QA.

# 5. Off-protagonist causality gate

Every Act still requires:
- >=2 causal developments outside protagonist presence,
- >=1 problem solved or worsened independently,
- >=1 relationship/institution change protagonist does not control.

Act2 and Act6 concurrency ledgers remain hard authority.

Act6 neutral corridor specifically remains:
`Dispatcher → community/medical contact → Juno/Mira/Rafi/Leila → Selene`,
not protagonist-mediated.

Act8 affected D3 persons retain direct voice/consent/proposal authority.

Act9 final solution remains multi-actor.

---

# 6. Protagonist centrality gate

Every Act requires protagonist-owned:
- >=1 irreversible consequential decision,
- >=1 mystery/interpretive advance,
- >=1 relationship movement,
- >=1 competence payoff/failure that changes options.

Protagonist may be story center without being institutional/world sovereign.

---

# 7. Full-absence discipline

Default full-absence slots are defined in:
`POV-OWNERSHIP-REALLOCATION-v0.2.md`.

Full absence should feel deliberate.
Good reasons:
- prove H-B existed before protagonist,
- show other side of protagonist decision,
- show independent current life (e.g. Arun),
- seed an emergent actor before protagonist knows importance,
- show an institutional/community choice protagonist cannot witness.

Default:
no consecutive full-absence run.

---

# 8. Clue / knowledge rules

Explicit cross-history autobiographical memory remains extremely rare.
Prefer material/record/social/institutional evidence.

No POV may reveal hidden truth simply because the character knows something privately unless the Reveal Ledger permits it.

Do not make mixed episodes a loophole for early exposition.

---

# 9. Ordinary-world density

Across each ~10~15 episodes, include meaningful ordinary life:
work / food / commute / family / school / leisure / housing / bureaucracy / health / local business/community.

Ordinary scenes need not become clue scenes.

---

# 10. Act2 / Act6 geography

Act2 ~48~52h and Act6 ~8~10 weeks retain their concurrency ledgers.

A mixed episode may cross locations via scene break, but characters themselves must respect transit/access times.

No protagonist cameo may be achieved by physically moving him somewhere implausibly.
Use remote consequence, prior/after scene or separate location instead.

# 11. Blueprint/Manuscript execution gate

Before drafting an episode:
1. read current v0.2 registry/overlay,
2. identify P/M/A mode,
3. load <=5 direct context items by Context Pack spec,
4. preserve scene-level POV fence,
5. verify clue state,
6. verify continuity output from previous episode,
7. confirm protagonist appearance has a real function if present.

No prose is generated by this specification itself.
