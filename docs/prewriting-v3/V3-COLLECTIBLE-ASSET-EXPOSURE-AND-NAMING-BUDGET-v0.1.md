# 1. First-display budget across 410 episodes

`First display` means the story gives an asset enough visual/material attention that a reader could recognize it later.
It does NOT mean a lore paragraph, model name, or close-up is required.

Maximum first-display allocation:

| Act | Episodes | Max base assets receiving first distinct display | Execution intent |
|---|---:|---:|---|
| Act1 | 001~042 | **24** | establish people, city, work, ordinary culture; no catalog scenes |
| Act2 | 043~094 | **8** | mostly stress/reuse of familiar assets; only necessary rescue/emergency additions |
| Act3 | 095~136 | **3** | wrong-familiarity/material deltas dominate; avoid alternate-version flood |
| Act4 | 137~181 | **5** | social/institutional character and prop additions only as needed |
| Act5 | 182~228 | **5** | provenance/legacy additions; no relic-tour inventory |
| Act6 | 229~279 | **2** | transformation/loss > newness |
| Act7 | 280~327 | **7** | physical Outer Ark function ecology; bundle rather than product-introduce |
| Act8 | 328~370 | **3** | HUMAN/rights/deployment preparation; keep new object count low |
| Act9 | 371~410 | **7** | destination-specific necessities only; descendant designs > new families |

Total maximum allocation = **64**.

This is a ceiling, not a requirement to foreground exactly that many.
A WORLD-DEPTH asset can remain a background visual seed and never receive a prose name.

---

# 2. Per-episode salience budget

Ordinary episode:
- new distinctly introduced tracked asset: **0~1** preferred,
- salient returning tracked assets: **0~2** preferred,
- more only when incident logistics naturally require them.

Hard:
- no three consecutive paragraphs whose purpose is asset description,
- no `arrival at place → list machines → list uniforms → list tools` exposition stack,
- no episode hook whose only payoff is `new model revealed`.

---

# 3. Transformation-over-newness rule

From Act2 onward, the default reader reward is:
`familiar asset under new pressure` > `brand-new asset`.

Especially:
- Act6: transformation / cannibalization / retirement / loss dominate.
- Act7: Outer Ark assets appear as one functional ecology, not a five-product rollout.
- Act9: inherited standards / descendants dominate; destination-new HIGH-memory machine families <=2.

# 4. Reader-facing naming budget

Base roster:
- characters: 13 people with normal character names,
- non-character asset families: **51**.

For those 51 non-character assets:

## Stable recurring reader-facing labels
Maximum:
# **20**

These are terms a regular reader may reasonably encounter multiple times and remember.
They should mostly be functional names/shorthands.

Examples of preferred label style:
- 구조 크롤러
- 매핑 드론
- 화물 터그
- 구조 스키프
- 서비스 프레임
- 점검 포드
- 필드리그
- 벨트
- 미드링
- 가든
- 메드
- 올드웍스
- 루트 태그
- 자격표식

The final 20 are C2 decisions; this file sets only the cap.

## Invented proper/model/manufacturer terms inside the 20
Maximum:
# **6**

This includes:
- invented model-family names,
- manufacturer names,
- historical proper equipment names,
- new fictional venue/landmark proper names when function label would suffice.

Hard:
Do not spend these six merely to make the setting sound futuristic.

## Function/context/artbook-only assets
Minimum:
# **31 of the 51**

These may be described by use/context and can have internal design IDs without a stable prose proper noun.

Examples:
- `방열판 정비 캐리지 한 대`
- `구형 환자 이송 크래들`
- `노선 기념 배지`
- `재생산된 오래된 표지판`

A reader is never tested on these names.

# 5. Model-code budget

Model codes/numbers are optional enthusiast/technical detail.

Hard limits in ordinary prose:
- no more than **3 model codes actively relevant at one time**,
- no more than **1 newly introduced technical proper/model term per episode**,
- most episodes introduce **zero** model codes,
- model code appears only if operational distinction matters or a character naturally uses it.

Forbidden pattern:
`모델명이 곧 캐릭터성/강함/희귀도`.

Preferred:
`구형 크롤러`, `현행형 터그`, `정착용 개조 프레임` unless exact code matters.

---

# 6. Manufacturer/brand budget

A mature 300k civic world certainly has brands/manufacturers, but naming them all is unnecessary.

Series-wide recurring manufacturer/brand proper names:
**0~4 preferred / 6 hard maximum**.

Most products should not receive a brand in prose.
Brand appears only when it adds:
- compatibility context,
- service history,
- ordinary consumer texture,
- provenance conflict.

Brand is never a faction or rarity marker.

---

# 7. Place-name budget

Major geography already has functional official names + lived shorthand.
Do not convert every landmark into a fantasy proper noun.

Preferred:
- Transfer Belt → `벨트`
- Midring → `미드링`
- Garden Commons → `가든`
- Med-University → `메드`
- Old Works → `올드웍스`

Small venues/shops/schools may have names scene-locally, but are not automatically recurring terminology.

Destination first-year sites should initially sound operational/ordinary, not like prebuilt mythic landmarks.

---

# 8. In-world collection terminology

Citizens can collect variants without RPG language.

Allowed vocabulary:
- 초기형 / 후기형
- 구형 / 현행형
- 정비형 / 화물형 / 구조형
- 복각 / 재생산 / 복원
- 원본 / 문서화 / 귀속 추정 / 복합복원
- 노선판 / 기념판 / 행사 배지

Forbidden as standard material-culture language:
- S급 / SSR / legendary / epic rarity
- power-score tiers
- color rarity coding
- `한정판이므로 역사적으로 더 중요하다` 자동논리

# 9. Act-specific anti-dump rules

## Act1
Material attachment is important, but no episode exists to tour equipment.
At least four recurring ordinary details stay permanent non-clues.

## Act3
Use tiny changed details from known assets.
Do not invent dozens of H-B-only alternate variants.

## Act5
Provenance is action-linked; no museum inventory chapter.

## Act6
Readers should mourn/notice changes to things they already know.
New base-family introduction should be exceptional.

## Act7
Physical Outer Ark craft are introduced as roles in one machine ecology.
Avoid serial `this is the inspection pod; next this is the service tug` exposition.

## Act9
New environment requires new equipment, but recognizable inherited standards must dominate.
No destination toy catalogue.

# 10. Completion / guidebook separation

The internal 8 completion sets and 92 eventual design-plate target are **production/guidebook architecture**.

The novel does not show:
- checklists,
- completion percentages,
- collection quests,
- full-family roll calls.

A future setting guide/artbook can make the hidden organization visible after the reader already knows the world.
