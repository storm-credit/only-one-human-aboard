Status: `PREWRITING ACT→SUB-ACT→ASSET ROUTING / NOT CANON / NO PROSE`
Date: 2026-08-20
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
Make the original collectibility goal executable at the **Sub-Act** level rather than stopping at the 9-Act map.

Original collection-pleasure target:
`처음 본다 → 다시 알아본다 → 같은 계열임을 안다 → 사용 흔적/세대/소유 변화가 보인다 → 일부는 완성하고 싶어진다`.

This file connects:
`ACT_BIBLE v3.2 → 28 Sub-Acts → EPISODE-BLUEPRINT Act files / local bands → Episode Cards → active character/material assets`.

Hard:
- this is NOT a checklist to show every asset,
- story action remains primary,
- WORLD-DEPTH assets can remain barely noticed,
- HUMAN:1 is never a collectible-character line,
- no RPG rarity/power progression,
- no model-reveal hook merely for merchandise.

---

# 0. Execution hierarchy

For EPxxx:
1. resolve **Act** from `ACT_BIBLE-v3.2-CANDIDATE.md`,
2. resolve **Sub-Act** by the episode range below,
3. resolve the local **Blueprint Band** inside `EPISODE-BLUEPRINT-ACTn-v0.1.md`,
4. load the exact **Episode Card**,
5. select only assets authorized by this Sub-Act + the 64-asset routing ledger,
6. if an exact C01~C15 return-chain anchor exists, it overrides generic placement.

The Sub-Act layer is a ROUTER. It does not add plot beats.

# 2. Collectibility progression by macro phase

## Acts1~2 — ATTACHMENT
Reader desire:
`저 장소/기체/도구가 익숙해졌으면 좋겠다.`

Reward form:
encounter + ordinary reuse + emergency transformation.

## Acts3~5 — RECOGNITION / RECONTEXTUALIZATION
Reader desire:
`같은 물건인데 왜 상태/이력이 다르지? 세대차를 더 보고 싶다.`

Reward form:
small H-B deltas + provenance + current-person ownership.

## Act6 — TRANSFORMATION / LOSS
Reader desire:
`예전 모습을 아니까 이 수리/퇴역/개조가 아깝고 의미 있다.`

Reward form:
scarcity modification, cannibalization, retirement, repurposing.

## Acts7~8 — ANCESTRY / MEANING
Reader desire:
`이 도시의 기계·규칙이 더 큰 물리 구조와 어떻게 이어졌는지 보고 싶다.`

Reward form:
known interface ancestry, not product novelty.

## Act9 — COMPLETION / DESCENDANT
Reader desire:
`계보를 처음부터 끝까지 보고 싶다.`

Reward form:
settlement descendants + ordinary new history beginning.

# 3. Per-Sub-Act salience discipline

Within one Sub-Act:
- preferred newly foregrounded tracked base families: **0~3 total**, unless already authorized first-display density requires more,
- repeated recognition should come mostly from already-known assets,
- at least one Sub-Act may intentionally have **no collectibility foreground reward** when emotional/reveal concentration benefits from silence,
- a WORLD-DEPTH family does not earn foreground just because its design sheet exists.

Per episode remains:
- new tracked asset 0~1 preferred,
- salient return 0~2 preferred.

---

# 4. Character recognition rule

The 13 visual identities are part of the collectible roster, but the novel must not read like a character gacha catalogue.

Per ordinary episode:
- 1 POV identity,
- usually no more than 3~5 other named core identities with meaningful salience,
- cameos do not earn visual re-introduction paragraphs.

Sub-Act reward rotates:
- profession silhouette,
- private-life state,
- crisis state,
- H-B current-life difference,
- late settlement state.

No armor-tier progression.

---

# 5. Blueprint-band inheritance

The detailed Act episode files use local `Bxx` bands smaller than or intersecting the macro Sub-Acts.

Rule:
- the **Sub-Act contract controls purpose**,
- the **Bxx band controls local pacing/cluster**,
- the **Episode Card controls exact scene action**,
- the **asset routing ledger controls what material/visual family may be salient**.

Do NOT duplicate every Bxx mapping into a second competing blueprint.
Episode number mechanically determines both Sub-Act and local Bxx band.

If a Bxx band crosses a Sub-Act boundary in any future revision, split its asset context at the exact episode boundary rather than moving the Sub-Act gate silently.

---

# 6. Failure conditions

FAIL if:
1. an asset appears because a design sheet exists rather than because scene action uses it,
2. the reader must memorize all 64,
3. Acts3~6 reward new designs more often than changed familiar designs,
4. Act7 becomes a physical-Ark craft catalogue,
5. Act8 turns HUMAN:1 into a collectible icon,
6. Act9's emotional completion depends on more new families than inherited descendants,
7. an exact C01~C15 episode return is moved simply to balance a Sub-Act table.
