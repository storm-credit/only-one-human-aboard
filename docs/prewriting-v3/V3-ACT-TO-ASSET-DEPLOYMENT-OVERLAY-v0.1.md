# 0. Context-pack execution rule

For any episode, do NOT load all 64 assets.

Default episode asset context:
1. exact episode card,
2. 1 primary character identity slice,
3. 0~2 relationship/secondary-character slices,
4. 1 place/institution slice,
5. 0~2 material/machine/prop slices,
6. only active reveal/return chain relevant to that episode.

Normal prose salience:
- new tracked asset: 0~1,
- returning tracked assets: 0~2,
- ordinary untracked details: more numerous than tracked details.

The roster is a **selection pool**, not an episode inventory.
