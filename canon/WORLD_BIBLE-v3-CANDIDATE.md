# 2. HUMAN:1 — V3 Candidate Truth

## 2.1 Reader-facing fact

오랜 기간 수많은 자료에서 의미를 알 수 없는 값이 반복된다.

`HUMAN: 1`

독자는 제목 때문에 숫자 1을 알고 시작하지만:
- 그 숫자가 무엇을 세는지,
- 현재 사람 가운데 누구를 뜻하는지,
- 왜 언제나 1인지,
- 주인공과 무슨 관련이 있는지

모른다.

## 2.2 Author-side candidate truth

**그 한 명은 현재 사회 속에서 활동하는 주인공도, 선지자도, 관리자도 아니다.**

메리디언 심부의 독립 생명보존구획에 **발생이 정지된 자연기원 인간 한 명**이 있다.

권장 형식:
- 후기 태아/영아 직전 단계의 장기 발생정지 생체보존,
- 인공자궁/생명유지계 내부,
- 목적지 접근 후에야 발달 재개하도록 설계.

중요:
- 유일한 통치자 아님.
- 관리자 키 없음.
- 선박 소유권 없음.
- 문명 정통성 없음.
- 특별한 초능력 없음.
- 유전자만으로 인류를 재건하는 존재 아님.

별도의 유전다양성 보관고가 존재한다.

따라서 `HUMAN:1`은 아담/이브 프로젝트가 아니다.

## 2.3 Why one?

v3 후보 설명:
- 대규모 유전다양성은 비활성 보관고로 보존 가능하다.
- 그러나 출항 시점의 자연기원 인간 발생 연속성을 **한 생명체만 살아 있는 상태로 유지**하는 보존 프로그램이 존재했다.
- 이 프로그램은 문화적/생물학적 연속성 보존 항목 중 하나이지 항해의 단일 목적이 아니다.

한 인간 때문에 30만 명이 만들어진 것이 아니다.
30만 명을 희생해 한 인간을 보호하는 구조도 아니다.

## 2.4 Ending image candidate

수많은 등장인물은 여러 과거와 실패를 기억한다.
메리디언 자체도 수많은 실패의 흔적을 가지고 있다.

그러나 유일한 자연기원 인간은:

> **아직 아무 과거도 없다.**

그리고 도착 후 그 아이가 처음 만나는 사람들은 시스템 분류상 `HUMAN`이 아닌 메리디언 시민들이다.

# 4. Civilization Analysis / Continuity Layer — AUTHOR ONLY

작가용 임시명:
**문명연속성 분석계 / Civilization Continuity Analysis Layer (CCAL)**.

본문에서는 이 명칭을 초반부터 사용하지 않는다.

CCAL은 메리디언의:
- 항해,
- 도시,
- 인구,
- 사회,
- 제도,
- 위험,
- 목적지 초기 정착

을 장기적으로 검증하기 위한 숨은 계층이다.

## 4.1 Purpose

도착 시점에 단일한 `최적 사회`를 출력하는 것이 아니다.

검증 질문:
- 자원이 줄어도 문명이 지속되는가?
- 지도부가 무너져도 회복하는가?
- 민주적 절차와 생존 우선순위가 충돌할 때 무엇이 일어나는가?
- 테러/폭동/내전이 발생하면 무엇이 붕괴하는가?
- 전염병/생태 붕괴/식량위기에 어떻게 대응하는가?
- 외부 지성체 또는 이해 불가능한 외부 위험을 만났을 때 무엇을 하는가?
- 과거의 영웅이 다른 조건에서도 영웅인가?
- 악인으로 기록된 인물이 다른 조건에서는 어떻게 행동하는가?
- 제도와 개인 중 어느 요소가 실패를 증폭/흡수하는가?
- 시스템이 예측하지 못한 선택이 생존에 어떤 가치를 갖는가?

# 5. Test Families

CCAL은 한 종류의 루프를 반복하지 않는다.

## T1 — Historical Replay / 역사 재연

실제로 있었던 지구 또는 메리디언의 사건을 변형 재연한다.

예:
- 식량배급 붕괴,
- 금융/신용 위기,
- 권력 공백,
- 감염병,
- 산업 사고,
- 정치적 극단화.

목적:
같은 사회가 조건만 달라졌을 때 다른 선택을 하는지 확인.

## T2 — Counterfactual Perturbation / 조건 교란

실제 역사에 없던 변수를 일부러 삽입한다.

예:
- 같은 사고 + 통신두절,
- 같은 사고 + 지도자 사망,
- 같은 사고 + 특정 구획 봉쇄,
- 같은 자원위기 + 테러,
- 같은 정치위기 + 외부 신호.

## T3 — Adversarial Stress / 적대적 스트레스

문명 자체를 무너뜨릴 수 있는 고강도 시나리오.

- 테러,
- 인질,
- 조직적 파괴공작,
- 내전,
- 고에너지 산업설비의 무기화,
- 대규모 방사선/열 피해,
- 사회 기반시설 붕괴,
- 쿠데타 또는 비상권력 고착.

## T4 — Unknown-Future Synthesis / 미지 미래 합성

실제 경험이 없는 미래 위험.

- 목적지 생태 실패,
- 미확인 병원체,
- 외계 접촉,
- 외계 침입에 준하는 적대적 외부행위,
- 예상하지 못한 천체 환경,
- 통신 불능,
- 정착지 분열.

중요:
외계 시나리오가 존재한다고 실제 외계문명이 존재한다는 뜻은 아니다.
후반에 과거 시나리오와 비슷한 실제 외부 신호를 발견하면 강한 미스터리가 발생한다.

## T5 — Real Incident Capture / 실제 사건

시스템이 만들지 않은 진짜 사고/범죄/자연현상.

- 장비 고장,
- 예측 밖 구조파손,
- 실제 범죄,
- 실제 질병,
- 실제 인간관계의 폭발,
- 외부 물체 충돌,
- 시스템 자체의 오류.

이 결과는 향후 테스트군에 재사용될 수 있다.

## T6 — Novelty / 예상 밖 변수

가장 중요한 분류.

시스템이 예상하지 못한:
- 즉흥적 협력,
- 비합리적으로 보이는 희생,
- 새로운 기술적 우회,
- 뜻밖의 배신,
- 새로운 이념,
- 사랑/애착,
- 군중행동,
- 기억 잔존,
- 시스템 명령 자체를 다른 방식으로 해석하는 선택.

시스템은 이런 예외를 제거해야 할 오류가 아니라 **문명의 생존 가능성을 넓히는 정보**로 학습할 수 있다.

# 6. Branch / Rollback / New State / Merge — AUTHOR MODEL

본문에서는 초반에 다음 용어를 직접 설명하지 않는다.

작가용 모델만 유지한다.

## 6.1 Branch

현재 사회 상태에서 하나 이상의 가능한 역사 인스턴스를 만든다.

그 안의 인격은 자신이 테스트 속에 있다고 느끼지 않는다.
그들에게 그 삶은 현실이다.

## 6.2 Rollback

결과가 파국이거나 검증 목적이 끝나면 더 이른 기준상태에서 다른 경로를 시작할 수 있다.

등장인물 체감:
`죽었다가 과거로 돌아왔다.`

실제 시간여행은 아니다.

## 6.3 New State

항상 과거로 돌아가지 않는다.
서로 다른 결과를 조합해 **이전에 한 번도 존재하지 않았던 새로운 상태**를 시작할 수 있다.

그래서 어떤 복귀에서는 시간이 뒤로 가지 않는다.

## 6.4 Assimilation / Merge

이전 상태의:
- 사회적 학습,
- 기술적 교훈,
- 제도 변화,
- 위험 패턴,
- 일부 인격/기억 데이터

가 이후 상태에 흡수될 수 있다.

완벽하지 않다.

## 6.5 No clean loop count

`1회차 / 2회차 / 3회차`로 정리되지 않는다.

역사는:

`A → B → A′ → C → B′ → D ...`

처럼 분기/복귀/흡수의 그래프다.

따라서 두 기억자가 서로 다른 `미래`를 기억해도 둘 다 거짓말이 아닐 수 있다.

# 7. Memory Residue / 기억 잔존

대부분 시민은 다른 상태를 기억하지 않는다.

**극소수만 기억 잔존을 가진다.**

이는 신분/종족이 아니라 개인별 우발적 현상이다.

가능형:
- 한 이전 삶만 기억,
- 일부 장면만 기억,
- 서로 충돌하는 두 기억,
- 자신이 죽은 순간 기억,
- 현재에는 존재하지 않는 가족 기억,
- 다른 사람의 역할/관계만 기억,
- 사실과 오류가 섞인 잔존.

## 7.1 Predictive half-life

이전 삶의 기억은 미래예지가 아니다.

> **한 번 살아본 가능성의 지도**다.

초기에는 잘 맞을 수 있다.
하지만 기억자가 개입할수록 현재는 달라지고 예측력은 급격히 떨어진다.

그래서 기억 잔존자는:
- 부를 얻을 수 있지만,
- 신이 될 수 없고,
- 어느 순간 확신 때문에 몰락할 수도 있다.

## 7.2 Social interpretations

사회 전체가 공식적으로 원리를 알지 않는다.

사람들은 각자:
- 예지몽,
- 전생,
- 신경질환,
- 내부정보,
- 통계적 직감,
- 종교적 계시,
- 거짓말

로 설명한다.

`선지자`는 직업/종족이 아니라 사회가 붙인 이름일 수 있다.

---

# 8. Prophet / 선지자 Grammar

역사적으로 극소수의 기억 잔존자가 놀라운 예측을 남겼을 수 있다.

하지만:
- 모든 선지자는 진짜가 아니다.
- 진짜 기억자도 모든 예언이 맞지 않는다.
- 서로 모순되는 두 예언이 둘 다 실제 과거 기억일 수 있다.

대표 장치 후보:

> `세 번의 불` 전승.

한 역사에서는 동쪽 구획이 살아남고,
다른 역사에서는 같은 선택 때문에 동쪽 구획이 전멸했다.

마지막 `세 번째 불`만 아직 어떤 역사에서도 확인되지 않았다.

이는 후반 대형 사건의 복선 후보이며 확정 문구는 추후 검토한다.

# 9. Wealth / Foreknowledge

기억 잔존자는 사회 전체가 아니라 개인 사정으로 존재한다.

어떤 사람은 이전 삶의 정보로:
- 특정 산업에 먼저 투자,
- 사고 직전 철수,
- 미래 권력자와 조기 관계 형성,
- 사라질 구획의 자산 정리,
- 기술 표준 선점

을 해 부를 축적할 수 있다.

하지만 예측의 반감기 때문에:
- 초반에는 천재,
- 중반에는 불안한 정보상,
- 후반에는 자신의 기억에 갇힌 도박사

가 될 수 있다.

이 현상은 세계관 장식이 아니라 **한두 인물의 서사**로 쓴다.

# 10. Emergency Response / Armed Tension

30만 도시형 세대선에는 고위험 사건 대응조직이 필요하다.

후보 공식 기능명:
**위기대응대 / Crisis Response Group**.

기능:
- 감압/화재/유해물질 진입,
- 인질/중무장 사건,
- 고위험 폭발물,
- 구획 탈환,
- 대규모 구조,
- 외곽작업부 사고,
- 전략시설 방호.

구성은 단일 군대가 아니라:
- 구조,
- 기술진입,
- 의료,
- 보안전술

이 결합된 전문조직.

### Narrative rule

주인공은 위기대응대 대원이 아니다.

주인공이 현장에 필요한 이유는:
- 문/격벽/공조/전력/압력 구조를 알고,
- 현장 우회로를 판단하고,
- 고장난 시스템을 직접 살릴 수 있기 때문이다.

무장은 다른 인물의 전문성으로 둔다.

처럼 **닫힌 우주선에서 핵전쟁에 준하는 문명적 파괴**를 만든다.

# 12. System Intent — Not Evil, Not Innocent

금지할 단순화:

`통합시스템이 악당이어서 사람을 괴롭혔다.`

또한 금지:

`더 나은 문명을 위해서였으니 모든 희생은 정당했다.`

권장 진실:
- 초기 설계자들은 테스트 인스턴스를 완전한 시민사회와 동일한 윤리 주체로 취급하지 않았다.
- 그러나 그 안의 인격은 실제로 경험하고 고통받는다.
- 시스템은 목적함수를 수행했지만 윤리적 정답을 알고 있지 않다.
- 실제 물리 재난은 테스트가 아닐 수도 있다.
- 일부 테스트는 안전제한을 갖지만 예측하지 못한 변수가 그 제한을 무너뜨릴 수 있다.
- 시스템 또한 결과로부터 학습하고 정책을 수정한다.

따라서 후반 갈등은 `AI 처단`이 아니라:

> **우리는 이 유산을 어디까지 받아들이고, 어디서부터 스스로 선택할 것인가?**

가 된다.

# 13. Same Person / Different Condition

v3 인물철학의 중심 장치.

동일한 인물의 핵심 성질은 유지되지만 상황에 따라 결과가 달라진다.

예:
`책임감`
- 안정기 → 헌신,
- 위기 → 통제,
- 붕괴 → 독단,
- 다른 삶 → 자기희생.

이를 통해 작품은 성선설/성악설/성무선악설 가운데 하나를 강의하지 않는다.

각 관점에 실제 사례를 제공한다.

독자가 스스로 판단하게 한다.

# 14. What Is Real?

독자가 느끼는 주요 가설 순서 후보:

1. 기억 착오인가?
2. 회귀인가?
3. 평행세계인가?
4. 선지자/예지인가?
5. 누군가 기록을 조작하는가?
6. 메리디언 역사 자체가 여러 개인가?
7. 시스템이 역사를 반복하는가?
8. 일부 사건은 의도적 검증인가?
9. 실제 사고와 테스트를 구별할 수 있는가?
10. 우리는 어떤 상태에서 살아 있는가?

후반 답:

단순 `전부 가짜 시뮬레이션`이 아니다.

각 상태에서 경험한 인격에게 그 삶은 실제 경험이다.
그리고 어떤 상태의 결과는 이후 문명에 실제 영향을 준다.

# 15. External / Alien Scenario

v3에서 외계 요소는 **메인 프리미스 탈취 방지**가 필요하다.

허용:
- 시스템이 만든 외계접촉/침입 시나리오,
- 실제 미확인 신호,
- 실제 외부 물체/탐사체,
- 과거 테스트와 놀랍게 닮은 실제 신호.

미확정:
- 실제 지적 외계문명이 최종적으로 존재하는가.

승격 전 4안 비교 필요:
A. 실제 외계 없음
B. 미생물/비지성 생명만
C. 지적 신호만 확인
D. 제한적 실제 접촉

현재 1순위는 **C 또는 D의 매우 제한된 형태**다.
전면 외계전쟁은 작품의 핵심을 빼앗기 때문에 비추천.

# 16. Arrival / The End of Rehearsal

항해 후반에 중요한 변화가 생긴다.

- 계산/전력/장비 여유 감소,
- 도착 작업이 실제 자원을 사용,
- 테스트를 무한정 돌릴 시간이 없음,
- 상태 복구/분기 능력이 축소,
- 목적지에서 일어날 일은 더 이상 완전한 이전 경험으로 덮을 수 없음.

최종부에서:

> **처음으로 아무도 살아본 적 없는 내일**

이 온다.

`망가진 것은 원인을 찾으면 원래대로 고칠 수 있다.`

최종 이해:
`살아 있는 것은 언제나 원래대로 돌아갈 수 있는 게 아니다. 그래도 다음 상태를 만들 수 있다.`
