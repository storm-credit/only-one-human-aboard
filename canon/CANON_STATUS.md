# 3. Canon Core Premise

- 세대우주선 **메리디언**.
- 현재 시민 약 30만.
- 대부분 시민은 살아 있는 인간형 생물학적 몸과 뇌를 가진다.
- 옛 기술분류의 핵심 차이는 **인지발달 기원**.
- 대부분은 prenatal `발달 커넥톰 시드`를 거친 Seeded/Synthetic-Origin Cognition.
- 현재 active Natural/Bio-Origin Cognition은 1명.
- 그 인물은 **아마라 오코로**.
- 현대 시민사회는 두 기원 모두를 사람/시민으로 인정해 왔다.
- 제목의 `인간 한 명`은 legacy classification의 충격이지 서술자의 최종 인격판정이 아니다.

- 여러 세대에 걸친 Seed 의료표준화와 rights normalization

## Living World
- 1환 / 2환 / 3환 + Spine + Outer Works + Legacy areas
- Habitat caste 금지
- `Layered Commons + Market City`

## Destination
- Epsilon Indi A / 인디계
- 약 14년 본편 시간축
- local ISRU + ship industrial-capital bootstrap
- settlement path는 다원적이며 모두 비용 존재
