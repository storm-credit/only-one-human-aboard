# CANON STATUS

이 문서는 설정이 브레인스토밍에서 정본으로 조용히 승격되는 것을 막기 위한 상태표다.

상태:
- `CANON` — Freeze된 정본
- `PROVISIONAL` — 현재 1순위이나 변경 가능
- `CANDIDATE` — 비교 중인 후보
- `REJECTED` — 폐기, 재사용 시 이유 필요

## Operational Rules — CANON

| Item | Status | Note |
|---|---|---|
| 설계 Freeze 전 원고 집필 금지 | CANON | 프롤로그/1화/샘플 포함 |
| 주요 설계는 비교 후 선택 | CANON | 필요 시 3~4안 |
| Phase 종료 시 Red Team | CANON | P0는 진행 차단 |
| 변경 시 영향 범위 기록 | CANON | 캐릭터/Act/복선/세계규칙 |
| 20화 Reader Promise를 100/200화에도 유지 | CANON | 장기성 핵심 |
| 인간 선 / AI 악 이분법 금지 | CANON | 작품 기본 금지사항 |
| 하나의 반전만 장기 미루기 금지 | CANON | 미스터리 공개가 행동을 열어야 함 |

## Promotion Rule

`CANDIDATE → PROVISIONAL → CANON` 승격은 다음을 만족해야 한다.

1. Reader Promise 훼손 없음
2. Story Engine에 실제 사건을 제공
3. P0 논리구멍 없음
4. 기존 설정과 충돌 없음
5. 중반/후반에서도 기능함
6. Red Team 통과
7. 변경 영향 기록 완료
