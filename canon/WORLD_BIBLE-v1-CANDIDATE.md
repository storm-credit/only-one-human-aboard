# 1. Core Premise

## LOCK CANDIDATE
- 인류는 성간 세대우주선에서 수백 년째 항해 중이다.
- 현재 시민은 약 30만 명 규모다.
- 시민들은 실제로 태어나고, 가족을 만들고, 교육받고, 일하고, 병들고, 늙고, 죽을 수 있다.
- 시민 대부분의 몸과 뇌는 살아 있는 인간형 생물학적 조직이다.
- 차이는 **인지 발생 기원(cognitive origin provenance)** 에 있다.
- 현재 출항시대 옛 분류상 확인 가능한 `Natural/Bio-Origin Cognition` 시민은 한 명이다.
- 나머지 대부분은 `Seeded/Synthetic-Origin Cognition` 계열이다.
- 현재 사회에서는 둘 다 일반적으로 사람/인간으로 살아 왔다.

## Interpretive Rule
`우주선에는 인간이 한 명뿐이다`는 작품이 승인하는 절대 생물학 명제가 아니라 **출항시대의 좁은 인간분류가 현재 사회에 다시 적용될 때 생기는 충격문장**이다.

# 2. Biological Body / Cognitive Origin

## LOCK CANDIDATE
대부분 시민은 인간형 DNA·세포·장기와 살아 있는 생물학적 뇌를 가진다. 실제 대사·수면·음식·질병·부상·노화를 겪는다.

중앙컴퓨터가 30만 인격을 실시간 렌더링하지 않는다.

### Natural/Bio-Origin
초기 고차 인지회로가 Connectomic Seed 없이 발달.

### Seeded/Synthetic-Origin
임신 초기 critical window에서 computationally generated developmental prior/attractor가 초기 고차 자기모델·인지회로 형성조건에 관여.
