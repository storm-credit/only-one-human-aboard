# 4. Conflict Rules

## Domain owner wins
If the same fact is summarized in several v2 files, the designated owner module wins.

Examples:
- exact destination atmosphere → `DESTINATION-ARRIVAL-v2.md` / Quant module
- civil majority → `SOCIETY-v2.md` / Quant module
- exact episode POV → delegated locked POV Map, not Character module

## Locked story execution delegation
Canon v2 does not duplicate every 230-episode card.
Exact:
- POV,
- episode time/age,
- scene-level reveal timing,
- Deep Card microsequence
remain owned by existing locked execution files.

## Elastic does not mean undefined
An Elastic value must remain inside the mechanism/bounds in `CANON-v2-ELASTIC-REGISTRY.md`.

# 5. Fact Status Vocabulary

### LOCKED
Changing requires formal Canon reopening/change control + impact regression.

### BOUNDED
The model/range is Canon; exact value inside the range may vary.

### DELEGATED
Exact truth is owned by another named locked authority.

### ELASTIC
Scene-level or later microdesign choice inside explicit constraints.

### FORBIDDEN
Rejected direction cannot re-enter silently.
