# 7. Elastic Decision Test

Before inventing a detail during scene design, ask:
1. Is the governing mechanism already frozen Canon?
2. Does this choice stay inside numerical/social/legal bounds?
3. Does it create a new institution, privilege, technology class or ontology?
4. Does it change a locked character/reveal/future constraint?
5. Would it force many later episodes to change?

If:
- 1 = yes
- 2 = yes
- 3–5 = no

then:
`ELASTIC — choose locally`.

Otherwise:
run Canon Change Control or a narrow micropass.
