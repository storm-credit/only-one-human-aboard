Status: `CANDIDATE / NOT CANON`
Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
사주·타로·관상·점술·예언 문화가 메리디언에서 어떻게 살아남고, 왜 극소수 사례가 실제 기억 잔존/상태 불일치와 겹치는지 설명한다.

# 1. Cultural baseline

메리디언은 지구 문화를 보존·복제·변형했다.
따라서 수백 년 뒤에도 다음이 존재할 수 있다.

- 사주/명리 계열
- 타로/카드 점
- 관상/얼굴 읽기
- 꿈 해몽
- 별자리/점성술의 문화적 변형
- 종교적 예언
- 민간 징조
- 메리디언 고유의 신흥 점술

대부분은:
- 상담,
- 놀이,
- 심리 투사,
- 문화적 정체성,
- 미신,
- 자기서사 만들기

영역이다.

Hard:
**점술 체계 자체가 우주의 초자연 법칙은 아니다.**

# 2. Why some readings become uncannily accurate

극소수의 정확 사례는 하나의 원인이 아니다.

## D1 — Ordinary interpretation
상담기술, 콜드리딩, 통계적 일반화, 우연.

가장 흔함.

## D2 — Client-side latent residue
내담자 자신에게 다른 상태의 기억 조각이 남아 있고, 점술 행위가 연상/투사를 통해 그것을 끌어낸다.

예:
타로의 `탑` 이미지를 본 뒤 실제로는 기억하지 못하던 붕괴구획의 냄새/복도/사람 얼굴이 떠오름.

카드가 정보를 주는 것이 아니라:
**카드가 이미 남아 있던 조각을 불러낸다.**

## D3 — Reader-side residual recognition
점술가 본인이 기억 잔존자.

상대의:
- 얼굴,
- 말투,
- 이름,
- 몸짓,
- 생년 정보

등이 다른 상태에서 본 사람의 기억을 비자발적으로 자극한다.

점술가는 이를 `관상`, `기시감`, `신의 말`, `감`으로 해석할 수 있다.

## D4 — Archive / identity edge collision
극히 희귀한 경우, 오래된 개인 비서/기록도구/가계 아카이브/공공 정보질의가 상태 병합 뒤 남은 비정상 인덱스와 충돌한다.

사용자는 이를 시스템 버그로 이해하지 못하고 전승된 의식/점술 절차로 포장한다.

이것이 `시스템 우회`에 가장 가까운 사례다.

하지만:
- 재현률 낮음,
- 정보 단편적,
- 다른 사람 기록이 섞일 수 있음,
- 상태마다 키가 달라짐,
- 권한벽을 뚫는 만능 API 아님.

# 3. Saju / birth-data grammar

사주가 실제 천체운명 엔진이라는 설정은 채택하지 않는다.

다만 생년월일/출생시각은 문명 기록에서 실제로 자주 사용되는 약한 정체성 특징이다.

Author-side overlap 후보:
- 출생 시점
- 발생/부모 계보
- 초기 건강기록
- 거주구획
- 초기 발달 시퀀스

같은 정보가 legacy identity matching에서 일부 사용될 수 있다.

따라서 오랜 세월 동안 일부 점술가가:
`출생시각 + 가족계보 + 이름/얼굴 + 반복 질문`
조합에서 이상할 정도로 맞는 사례를 축적했을 수 있다.

그러나 생년월일만으로:
- 전생 조회,
- 미래 조회,
- HUMAN 판별,
- branch ID 판별

불가.

### Narrative use
사주가 `전생을 읽는다`는 소문이 있지만 실제로는:
- prior-state identity collision,
- client memory elicitation,
- reader memory residue

중 하나일 수 있다.

# 4. Tarot grammar

타로는 v3에서 가장 자연스러운 장치.

기능:
**symbolic elicitation / 기억 투사 인터페이스.**

카드 자체는 무력하다.

좋은 사용:
- 카드 그림이 감각기억을 자극.
- 점술가가 알 수 없는 구체적 문장을 말함.
- 나중에 다른 상태의 실제 사건으로 재맥락화.

나쁜 사용:
- 매번 정확한 미래예언.
- 카드가 branch를 고름.
- 카드가 HUMAN:1 위치를 알려줌.

### Example clue grammar
점술가:
`당신은 죽을 때가 안 보여요.`

주인공:
`왜요?`

점술가:
`이미 너무 많이 죽어서요.`

이 장면은 당시에는 사기/기묘한 직감/정신질환으로 해석 가능해야 한다.
후반에 주인공이 기억하지 못한 사망 상태가 확인되면 payoff.

# 5. Physiognomy / face-reading grammar

관상은 생물학적 범죄예측이나 선악판정으로 사용하지 않는다.

허용:
**prior-state visual recognition residue.**

예:
- 처음 보는 젊은 사람에게 늙은 얼굴이 겹쳐 보임.
- 살아 있는 사람에게 죽은 당시의 얼굴이 순간적으로 떠오름.
- `당신 얼굴을 전에 봤다`는 설명 불가능한 기시감.

이것은 얼굴 형태가 운명을 결정해서가 아니다.

Hard:
- 얼굴 생김새로 선악/범죄성/계급을 과학적으로 판정하지 않는다.
- 인종/신체특징에 운명성을 부여하지 않는다.

# 6. Prophet class

`선지자`는 공식 직업이나 초능력 계급이 아니다.

사회적 유형:

## P1 — Fraud / performer
점술을 생업으로 하는 평범한 사람.

## P2 — One-history rememberer
한 이전 상태를 기억해 예언처럼 말함.

초기 정확도 높고 divergence가 커지며 틀리기 시작.

## P3 — Fragmented multi-history rememberer
서로 모순되는 두세 삶의 조각을 기억.

예언 내용 자체가 모순될 수 있다.

## P4 — Accidental side-channel practitioner
특정 의식/질문법/아카이브 절차가 이상한 정보 조각을 가끔 반환한다는 것을 경험적으로 알고 있음.
원리 이해 없음.

## P5 — Institutional myth
과거 정확 사례가 후대 종교/민간전승 속에서 과장됨.

# 7. Predictive half-life

Prior-state memory is NOT future sight.

Rule:
**기억은 한 번 살아본 가능성의 지도다.**

정확도:
- 반복 시작 직후 상대적으로 높음.
- 기억자가 개입하면 divergence 증가.
- 다수 기억자 개입 시 급격히 저하.
- system-induced variable가 달라지면 핵심 사건 자체가 사라질 수 있음.

따라서 선지자는:
- 초반엔 신처럼 보이고,
- 중반엔 틀리기 시작하고,
- 후반엔 왜 틀리는지를 이해하지 못해 붕괴할 수도 있다.

# 8. Social consequences

드문 정확 사례가 수백 년 축적되면서:

- `먼저 아는 사람` 괴담
- 반복되는 죽음을 기억하는 종교적 설화
- 특정 가문이 운이 좋다는 소문
- 점술가 사기 단속
- 학계의 기억오류 연구
- 보험/시장 내부정보 의심
- 유산/가족 분쟁
- `내가 다른 삶에서 네 배우자였다` 같은 관계 갈등

이 생길 수 있다.

대부분의 사회는 underlying CCAL truth를 모른다.

# 9. Institutional response

현대 메리디언의 공식 기관이 전생/점술을 공인하지 않는다.

가능한 분류:
- 기억오류
- 외상
- confabulation
- fraud
- data contamination
- coincidence
- anomaly under study

일부 연구자/보안기관은 통계적으로 이상한 사례군이 있다는 사실을 의심할 수 있지만:
- 원인 합의 없음,
- 깨끗한 진단검사 없음,
- 재현성 낮음.

이 때문에 점술문화가 완전히 사라지지도, 과학적으로 정식 인정되지도 않는다.

# 10. Mystery guardrails

1. 점술가는 exposition machine이 아니다.
2. 한 번에 정답을 주지 않는다.
3. 정확한 말도 최소 2가지 해석이 가능해야 한다.
4. `틀린 예언`도 후일 다른 상태에서는 참이었다는 식의 재맥락화 가능.
5. 모든 점술가가 기억 잔존자가 아니다.
6. 모든 기억 잔존자가 점술가가 아니다.
7. HUMAN:1을 점술로 직접 찾을 수 없다.
8. branch/rollback 용어를 점술가가 정확히 알고 말하지 않는다.
9. 초자연적 가능성은 독자 가설로 열 수 있지만 작가 진실은 SF 원리에 머문다.
10. 점술 사건은 인물/관계/행동을 변화시켜야 하며 분위기용 떡밥만 남발하지 않는다.

# 11. Long-form placements — CANDIDATE

Early:
평범한 점술/문화 → 한두 문장만 이상하게 정확.

Early-mid:
주인공이 무시했던 예언 일부 적중.

Mid:
서로 모순되는 두 선지자 모두 일부 적중.

Mid-late:
점술가 한 명이 prior-state rememberer였음이 확인.

Late:
오래된 점술 전승 일부가 상태 병합/identity edge collision과 겹쳤음이 밝혀짐.

Final:
점술의 신비를 전부 설명해 없애지 않는다.
문화는 남는다.
사람들은 진실을 알아도 여전히 카드를 펼치고 미래를 묻는다.

이유:
**아무도 살아본 적 없는 미래에는 prior-memory도 답이 없기 때문.**
