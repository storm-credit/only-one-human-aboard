# 0. Ensemble Design Principle

이 작품의 400화급 길이를 버티게 하는 것은 세계 상태의 개수가 아니라 **사람의 축적**이다.

핵심 규칙:

1. 같은 인물을 여러 상태에서 다시 사용한다.
2. 인물의 핵심 성향은 유지한다.
3. 상황이 바뀌면 그 성향이 선/악/회색으로 다른 결과를 만든다.
4. 작품이 성선설/성악설/성무선악설 중 하나를 정답으로 선언하지 않는다.
5. 독자는 동일 인물의 여러 선택을 보고 스스로 판단한다.
6. 다른 상태의 인물은 `대체 스킨`이 아니라 다른 삶을 실제로 살아온 사람이다.
7. 대형 리셋 전에 독자가 충분히 사람을 알게 해야 한다.

# 2. Protagonist — Rowan Han / 로언 한 [CANDIDATE]

## Core
- male.
- 시작 37세 전후.
- 메리디언 생활환 기반 **시설 복구/신뢰성 현장기사**.
- 위기대응대가 아니다.
- 시스템 관리자 아니다.
- HUMAN:1 아니다.
- 다른 기억 잔존자 가운데 유일한 존재도 아니다.

## Professional range
다루는 것:
- 격벽,
- 압력,
- 공조,
- 전력 분기,
- 냉각,
- 접근로,
- 센서,
- 비상 우회,
- 낡은 구획의 실제 유지보수 이력.

그는 전체 시스템을 설계한 천재가 아니다.

장점은:
> **현장에서 무엇이 실제로 고장날 수 있는지 안다.**

이 때문에 특수대/보안/의료보다 약하지만 위험한 곳에 같이 들어갈 이유가 생긴다.

## Core belief

> `망가진 건 원인을 찾으면 고칠 수 있다.`

## False extension

> `고치면 원래대로 돌아간다.`

작품 전체에서 깨지는 믿음.

## Strengths
- 물리적 원인 추적,
- 공간 기억,
- 우회로 발견,
- 제한된 자원으로 응급수리,
- 공포 속에서도 손으로 할 일을 찾음,
- 거창한 이념보다 구체적 생존문제에 강함.

## Flaws
- 감정문제를 고장처럼 취급,
- 해결 가능한 문제를 그냥 두고 못 감,
- 책임을 떠안다가 타인 선택권 침범,
- 상황이 나빠질수록 통제욕 증가,
- 본인이 납득하지 못한 초자연/종교 설명을 지나치게 무시.

## Everyday temperament
- 승진욕 크지 않음.
- 위험 자체를 좋아하지 않음.
- 규정 밖 일 귀찮아함.
- 남을 구하고 싶다는 선언보다 `내가 할 수 있는데 두고 가면 잠 못 잔다`에 가까움.
- 농담은 건조하고 낮은 빈도.
- 사람에게 정이 들수록 오히려 잔소리가 늘어남.

## Past wound — delayed reveal
약 8~10년 전 신참 시절 구획 사고.

- 압력/화재 연쇄 위험.
- 로언은 규정대로 격벽을 닫음.
- 안쪽 동료 **Arun Kalev / 아룬 칼레브**가 남아 있었음.
- 공식 기록상 아룬 사망.
- 로언은 그 뒤 `감정적으로 문을 다시 열면 더 많이 죽는다`는 원칙을 가짐.

초반에는 전체 사연을 말하지 않는다.

후반 다른 상태의 인물이:

> `아룬은 그날 안 죽었는데?`

라고 말하면서 로언의 가장 확실한 과거까지 흔든다.

## Pressure transform

| Condition | Same core trait: 책임감 | Result |
|---|---|---|
| Normal | 끝까지 수리/확인 | 신뢰할 수 있는 동료 |
| Crisis | 결정권을 대신 짊어짐 | 보호적 통제 |
| Collapse | 모든 실패를 자기 책임으로 봄 | 위험한 집착/독단 |
| Alternate state | 자신이 희생하는 선택 | 영웅처럼 보일 수 있음 |
| Another alternate | 격벽을 닫아 다수를 살림 | 누군가에게는 살인자 |

### Philosophical function
로언 하나만으로도 `같은 사람이 선한가/악한가/상황의 산물인가`를 단정할 수 없게 한다.

## Long arc
`고치면 돌아간다`
→ `이번에는 알고 있으니 막을 수 있다`
→ 기억과 현실 불일치
→ 자신이 기억하는 과거도 유일하지 않음
→ 다른 삶의 자기 흔적과 대면
→ 원래 상태 자체가 없을 수 있음을 인정
→ 마지막에는 되돌릴 수 없음을 알면서 선택.

# 3. Mira Solano / 미라 솔라노 — Relationship Anchor

## Role
- 36세 전후.
- 운송/배치/자원 스케줄링 실무자.
- 로언의 전 연인 또는 오래된 연인관계가 끝난 사이 후보.
- 처음부터 연애 서사의 보상물이 아니다.

## Core trait
**자율성**.

## Normal
- 자기 일/시간/관계를 스스로 결정.
- 로언의 과잉책임을 싫어함.

## Crisis
- 타인의 보호명목 통제에 강하게 반발.
- 위험을 감수하고 독립 행동.

## Collapse
- 사람을 버리는 냉정한 분리 판단을 할 수도 있음.

## Alternate-state value
어떤 상태에서는:
- 로언과 결혼했을 수 있고,
- 다른 상태에서는 만나지 않았고,
- 다른 상태에서는 로언 때문에 누군가를 잃었을 수 있다.

하지만 `로언을 사랑하는가` 하나로 캐릭터를 정의하지 않는다.

### Series function
로언이 `관계를 원래대로 복구`하려는 충동을 가장 직접적으로 깨뜨리는 인물.

# 17. Multi-State Character Harness

핵심 인물마다 최소 네 종류의 상태를 설계한다.

1. **Stable** — 평범한 사회에서의 성격.
2. **Crisis** — 재난/테러 아래 선택.
3. **Collapse** — 제도가 무너진 상태.
4. **Counterfactual** — 다른 과거에서의 반대처럼 보이는 선택.

Hard:
Counterfactual에서 아무 이유 없이 성격을 뒤집지 않는다.

모든 차이는:
- 가족 생존 여부,
- 이전 상처,
- 권한,
- 자원,
- 동료,
- 경험,
- 시스템 개입

같은 구체적 조건으로 설명 가능해야 한다.

# 20. Character Density Rules for 400 Episodes

1. 첫 대형 `세계 손실/복귀` 전에 핵심 인물 6~8명을 독자가 생활 속에서 충분히 알아야 한다.
2. 충격용 핵심 사망은 가능한 한 최소 20~40화 이상의 관계 누적 후 사용.
3. 한 액트마다 기존 인물 재사용률이 신규 중요인물 투입률보다 높아야 한다.
4. Act 7 이후 새 `Core` 인물 추가 금지 후보.
5. 대형 상태변화는 최소 3명의 기존 인물 의미를 바꿔야 한다.
6. 한 인물의 다른 상태는 동일한 말투/습관/핵심성향 중 최소 2개를 유지한다.
7. 죽은 인물의 재등장은 감정 무효화가 아니라 `다른 삶의 다른 사람`임을 보여준다.
8. 동일 인물을 상태마다 죽이고 살리는 쇼크 반복 금지.
