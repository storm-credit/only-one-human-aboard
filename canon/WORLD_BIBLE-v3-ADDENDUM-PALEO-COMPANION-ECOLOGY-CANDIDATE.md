Project: 《우주선에는 인간이 한 명뿐이다》

Purpose:
공룡·고생물·포켓몬처럼 느껴지는 수집/교감형 생물 문화를 메리디언에 넣되, 기존 SF·폐쇄공간·문명검증 엔진을 해치지 않도록 원인과 상한을 정한다.

# 1. Core distinction

두 요소를 분리한다.

## A. Paleo-life / 공룡·고생물
`정확한 고대 생물 복제`가 아니라 **고생물학적 복원 모델 / 합성 생물학적 재현 / 교육용 생태 모델**을 우선한다.

이유:
- 실제 공룡 DNA를 완전하게 확보해 그대로 복제했다는 설정은 과학적 부담이 큼.
- 메리디언의 제한된 생태/자원 안에서 대형 포식 공룡 상시 사육은 비효율적.

권장 구현:
1. AR/혼합현실 고생태관.
2. 로봇/바이오메카닉 복원체.
3. 조류·파충류·합성유전체 기반의 `dinosaur-inspired` 생물.
4. 고해상도 문명 인스턴스 안에서만 존재했던 완전 생태 시나리오.

Hard:
`티라노사우루스가 생활환을 돌아다니는 일상 세계`는 기본안으로 채택하지 않는다.

---

# 2. Companion Ecology — 포켓몬 같은 감각의 오리지널 생물문화

실제 포켓몬 종/이름/디자인을 복제하지 않는다.

메리디언에는 수백 년 동안 폐쇄생태계와 인간 정신건강에 맞춰 개발된 **소형 합성 반려생물 계통**이 존재할 수 있다.

Reader-facing 느낌:
- 다양한 종,
- 외형 차이,
- 사람과의 교감,
- 돌봄/훈련,
- 어린이·청소년 문화,
- 동호회/대회,
- 희귀 계통,
- 세대별 유행.

하지만 기능은 현실 생물학에서 확장한다.

예:
- 생물발광,
- 피부색 변화,
- 점착성 발바닥,
- 저중력 방향감각,
- 약한 생체전기 감지,
- 냄새/오염 감지,
- 수분상태 감지,
- 단순한 도구학습,
- 사람 감정/심박 반응 학습.

금지:
- 불/번개/초능력을 무기로 난사.
- 전투가 사회 핵심 스포츠가 되어 작품 장르를 대체.
- 소형 생물이 인간 수준 지능을 가진 채 소유물 취급되는 윤리구멍.

# 3. Why Meridian would preserve/create them

단순 장난감이 아니다.

가능한 역사적 목적:
- 장기항해 정신건강.
- 아동 발달/돌봄 교육.
- 생태감수성 유지.
- 해충/오염/곰팡이 조기감지.
- 농업/생태 구획 보조.
- 저중력 환경에서 반려동물 대체.
- 목적지 생태계 정착 전 인간-비인간 상호작용 훈련.

수백 년이 지나며 실용 계통이 문화/반려/취미 계통으로 분화.

# 4. Narrative value

## 4.1 World attachment
첫 100화에서 아이와 어른들이 특정 반려생물을 기르는 모습을 보여주면 메리디언이 `시설`이 아니라 `집`으로 느껴진다.

## 4.2 State contrast
같은 인물이 다른 상태에서 다른 반려생물을 기르거나, 이전 상태에서 죽은 반려생물이 현재 살아 있을 수 있다.

작은 차이가 큰 역사 차이의 감정적 증거가 된다.

예:
- 로언이 기억하는 미라의 반려생물은 회색 계통이었는데 현재는 존재한 적 없는 품종.
- 아이는 `지난번에는 이 애가 나를 물었어`라고 말하지만 현재 처음 만남.

## 4.3 Disaster sensor
합성 반려생물이 사람보다 먼저:
- 공기 오염,
- 압력변화,
- 특정 독성물질,
- 전자기 이상
등에 반응하면서 재난의 초기 단서가 될 수 있다.

단, 만능 감지기 금지.

## 4.4 Memory residue
특정 생물의 냄새/울음/촉감이 prior-state memory를 강하게 자극할 수 있다.

## 4.5 Moral mirror
사람들이 문명 스트레스 상황에서 반려생물/생태계를 어떻게 취급하는지도 성선/성악/성무선악 압박에 사용 가능.

- 식량위기에서 보호하는 사람.
- 버리는 사람.
- 생태 전체를 위해 개체를 희생하는 사람.
- 위험을 감수하고 종자를 구하는 사람.

# 5. Paleo arc candidates

## P1 — 어린이 고생태관
정상 메리디언의 생활감과 지구 문화 기억을 보여주는 평범한 장소.

후반 다른 상태에서는 이 장소가:
- 피난소,
- 임시 병동,
- 폐쇄구역,
- 폭동 거점
중 하나로 변해 있을 수 있다.

같은 `공룡 전시`가 상태차를 보여주는 시각적 앵커.

## P2 — Lost Paleo Habitat
폐쇄된 실험 생태구역에서 합성 고생물 계통이 예상 밖으로 생존.

완전 쥬라기공원식 액션이 아니라:
- 길 찾기,
- 생태 통제,
- 봉쇄,
- 사람이 만든 생물에 대한 책임
을 중심으로 한 5~12화 중형 아크 후보.

## P3 — Branch-only dinosaurs
어떤 고해상도 문명 상태에서는 목적지 생태 대응 훈련을 위해 훨씬 과격한 고생물/대형동물 생태가 존재했음.

현재에는 흔적/기억만 남음.

이 경우 `공룡이 실제 있었나?`라는 괴담이 상태미스터리와 연결 가능.

# 6. Companion culture candidates

가칭 분류어:
- `동반종 / Companion Line`
- `생활동물 / Civic Companion`
- `소형생태종`

최종 명칭은 별도 네이밍 패스에서 결정.

문화:
- 어린이 돌봄 자격.
- 등록/예방접종/생태안전.
- 품종 동호회.
- 비전투 기술대회.
- 장애인 보조 계통.
- 구조/탐지 계통.
- 오래된 혈통/지역 계통.

`수집`은 소유개수 경쟁보다:
- 관찰기록,
- 생태도감,
- 교감/훈련 인증,
- 다양한 계통과의 경험
으로 표현하는 편이 작품 톤에 맞다.

# 7. Long mystery hooks

1. 현재 공식 도감에 없는 동반종을 기억하는 아이.
2. 죽은 사람의 반려생물이 주인공을 알아봄.
3. 다른 상태에서만 존재했던 품종이 폐쇄구획에서 발견됨.
4. 특정 반려생물이 HUMAN:1 보존구획 근처에서만 이상 행동 — 단, 위치 추적 키로 쓰지 않음.
5. 고생태관의 오래된 전시 설명문 날짜가 공식 역사와 맞지 않음.
6. 어떤 선지자가 사람보다 생물의 반응을 더 신뢰함.
7. 초토화 상태에서 멸종한 동반종이 현재에는 평범하게 살아 있음.

---

# 8. Blindspots / Guardrails

1. 귀여운 생물 IP가 메인 미스터리를 덮지 않는다.
2. 실제 포켓몬과 유사한 이름/외형/속성전투 체계를 만들지 않는다.
3. 공룡은 정확한 DNA 복원이라고 쉽게 선언하지 않는다.
4. 대형 포식생물 상시 사육은 자원/안전상 특별한 이유 없이는 금지.
5. 반려생물이 매번 재난을 먼저 알아채는 만능 경보기 금지.
6. 합성생물의 복지/소유/폐기 윤리를 세계관에서 무시하지 않는다.
7. 상태가 바뀔 때 생물도 `배경소품`이 아니라 기억과 관계의 일부가 된다.
8. 포켓몬식 전투수집물이 아니라 **메리디언 특유의 생태문화**로 독자적 디자인.

Current recommendation:
- **Companion Ecology = 적극 채택 후보.**
- **Paleo culture = 적극 채택 후보.**
- **실물 대형 공룡 = 제한적/branch 또는 특수구획 후보.**

이 요소의 주 기능은 `설정 과시`가 아니라 **메리디언에 정들게 만들고, 상태가 바뀌었을 때 무엇을 잃었는지 작게 체감시키는 것**이다.
